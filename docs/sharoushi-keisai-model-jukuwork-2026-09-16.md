# 社労士掲載の料金設計の参考: 塾ワーク「求人出稿案内」(2026-09-16 記録)

出典: https://www.jukuwork.com/Contact/ad(株式会社教育情報サービス。有料職業紹介 25-ユ-300144)
塾専門の求人サイトの、塾側(広告主)向け料金ページ。当サイトの「社労士掲載」に構造ごと転用できる。

## 1. 塾ワークの料金体系(税抜)

### 契約の4コース — 「月額+成約」「月額のみ」「短期一括」「成果のみ」の4型
| コース | 向き | 月額 | 成約費 | 期間 | 範囲 |
|---|---|---|---|---|---|
| A | 年間多数採用 | 25,000円/月(1年) | 22,500円/名 | 1年 | 複数都道府県 |
| B | 年5名まで | 初月22,500円、2〜12か月目17,500円 | 0円 | 1年 or 5名採用まで | 1都道府県 |
| C | 短期・お試し | 100,000円/3か月 一括 | 0円 | 3か月 or 3名採用まで | 1都道府県 |
| S | 初期費用ゼロ | 0円 | 学生5万/社会人8万/正社員13万 円/名 | 1年(更新料なし) | — |

### 制作費(新規契約時は無料)
アイキャッチ2,000円/1種、要項ページ10,000円/1要項、画像2枚10,000円+3〜4枚目3,000円/枚、単画像5,000円/枚、動画1本目20,000円・2本目〜10,000円/本。

### バナー広告(月額)
S 300×180 = 70,000円 / M 634×180 = 120,000円 / L = 200,000円 / 特集ページ内 600×200 = 20,000円(単月)。新規契約時 S を1か月無料。

### 売り文句(ページ冒頭の6点)
1. 求人検索エンジンへの一括掲載(追加費用なし) 2. 企業単位の掲載(教室の羅列を避ける) 3. 季節の特集に無料で載る 4. ワンクリック応募なし=応募の質 5. 専門家が原稿を作る(3〜5営業日で公開) 6. スカウト機能(Aコース付帯)

### 問い合わせフォームの項目
塾名・ふりがな / 担当部署 / 担当者名・ふりがな / 郵便番号・都道府県・市区町村・住所 / 電話・FAX・メール(確認用) / 希望する案内方法(オンライン打合せ or 資料メール) / 問い合わせ内容 / プライバシーポリシー同意 / (任意)どこで知ったか

## 2. 当サイトへの転用案(社労士掲載)

### 構造はそのまま使えるもの
- **4コース制**。当サイトなら: A=月額+相談成約費 / B=月額のみ(件数上限) / C=3か月お試し一括 / S=初期費用0・成果報酬のみ。「まず S で入ってもらい B/A に上げる」という導線も同じ。
- **1都道府県 / 複数都道府県**の範囲区分。社労士は地域性が強いので、そのまま効く。`/dougu/madoguchi` の市区町村検索と結びつく。
- **「事務所単位の掲載」**(教室の羅列を避ける、の言い換え)。1事務所1ページ。
- **制作費を新規無料**にして入口を下げる。掲載ページの原稿を当方が書く(専門家が原稿を作る、の言い換え)。
- **問い合わせフォームの項目**はほぼ流用可。「塾名」→「事務所名」、「担当部署」は不要、「社労士登録番号」「対応地域」「障害年金の取扱実績(件数か年数)」を足す。
- **「どこで知ったか」**の任意設問。

### 転用できない・変えるもの
- 塾ワークは**有料職業紹介の許可**を取っており、成約費は法的にその枠。当サイトの成約費は「相談の申込1件あたり」の広告費として設計し、**紹介・あっせんの形にしない**(/ads の「推薦・選定しない」と矛盾させない)。
- 金額の水準は塾業界の相場なので参考にしない。社労士の障害年金の報酬(着手金+成功報酬=年金額の2か月分程度)から逆算して、月額は 1〜3万円、成約は 5,000〜15,000円/件 が現実的な出発点(要検証)。
- バナー広告は当サイトの方針(判定しない・中立)と相性が悪い。**やらない**。載せるなら掲載型のみ。
- 「応募の質」の主張は、当サイトでは「読者が制度を理解したうえで相談に来る」に置き換えられる(読者は8ステップと必要書類を見てから来る)。これは社労士にとっての本物の価値で、塾ワークの「ワンクリック応募なし」より強い。

### 当サイトが先に持っている材料
- 掲載の条件と開示: `/ads`、`/tokushoho`(DRAFT)、フッターの広告開示、`lib/ads.ts` の `SHOW_LISTINGS`
- 掲載枠の置き場: トップ末尾の `Listings`(`SHOW_LISTINGS` で出る)、`/erabu/*`(自分でやるか頼むか)
- 読者の動線: `/erabu/jibun-ka-irai` → `/erabu/erabikata`(社労士の選び方) → 掲載一覧
