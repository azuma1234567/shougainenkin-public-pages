# 75.3% の読み違いを、サイト全体で直す — 2026-09-27

## 何が間違っていたか

厚生労働省「令和6年度の障害年金の認定状況についての調査報告書」(令和7年6月11日)p.5–6 の内訳はこうです(精神障害・新規裁定・不支給85件)。

| 区分 | 件数 | 割合 |
|---|---|---|
| ア. 目安より下位等級に認定され不支給(障害基礎: 目安が2級以上、障害厚生: 目安が3級以上) | 32件 | 37.6% |
| イ. 目安が2つの等級にまたがるもの(「2級又は3級」など)について、下位等級に認定され不支給 | 32件 | 37.6% |
| ウ. 目安どおりの不支給(障害基礎: 目安が3級以下、障害厚生: 目安が非該当) | 11件 | 12.9% |
| エ. その他(てんかんなど) | 10件 | 11.8% |

ア+イ=75.3%。つまり **75.3% は「診断書から出る目安では等級に届いていた(または届く可能性があった)のに、総合評価で非該当になった」事案**です。診断書の丸がもともと非該当の位置にあったのは、ウの 12.9% だけ。令和5年度の同じ割合は 44.7% で、報告書はこの上昇が非該当率(8.4%→13.0%)の上昇に寄与したとしています。報告書は同時に、令和6年度以降の精神の不支給事案を点検し、必要なものは処分を取り消して支給決定し直すとしました(点検結果は fushikyuu-shinsa-seikyu と nayami-fushikyu が既に載せている 14,841件中444件)。

サイトの多くの記事はこれを **「不支給の75.3%は診断書が目安表の軽い側だった=診断書が軽く書かれたから落ちた」** と逆に読んでいました。正しく読んでいたのは fushikyu-85ken・fushikyuu-shinsa-seikyu・shinsa-shikumi-nintei-i(本文)・hattatsu-shougai(本文)・shinsatsu-mae-memo(9/27 修正済)だけです。

読み違いは、記事の主張の向きも変えます。誤: 「丸を上げれば通る」「頼んでも実態の重さは変わらない」。正: **「丸は届いていた人が落ちている。落としたのは総合評価(就労の実態・援助の状況・診断書の記述欄とカルテ・申立書との整合)。だから、丸のうしろの記述欄と申立書を、同じ生活で埋めることが要る」**。この向きなら、診察前メモ・申立書・整合の記事の主張はすべて成り立ち、むしろ強くなります。
