## #2 新 h2(h2「障害状態確認届は「簡略版の診断書」— だから1項目の重みが増す」の直後)

```
## 審査側は更新をどう扱うと決めているか — ガイドラインの「再認定時の留意事項」

更新が怖いのは、何を見られているか分からないからです。分かっている範囲を、原文で置きます。

精神の障害に係る等級判定ガイドラインには、「(4) 再認定時の留意事項」という項があります。

> ガイドライン施行後の再認定にあたっては、提出された障害状態確認届(診断書)の記載内容から、下位等級への変更や2級(又は3級)非該当への変更を検討する場合は、前回認定時の障害状態確認届(診断書)や照会書類等から認定内容を確認するとともに、受給者や家族、診断書作成医への照会を行うなど、認定に必要な情報収集を適宜行い、慎重に診査を行うよう留意する。

つまり、下げる・止めるときは、今回の診断書だけで決めない。前回の診断書を見て、必要なら本人や家族や医師に聞く。それが決まりです。「1枚の診断書で突然止まる」という恐れは、制度の建て付けとしては当たっていません。

もう一つ、平成28年9月のガイドライン施行より前に受給が決まった人には、別の規定があります。

> 既認定者の障害の状態が従前と変わらない場合については、当分の間、等級非該当への変更は行わないことを基本とする。

施行前の認定も当時の基準と医学的知見で行われたものだから、状態が変わっていなければ非該当にはしない、という趣旨です。「ガイドラインができて更新が厳しくなった」と聞いて不安な人は、この一文を知っておいてください。

この運用が守られているかは、国が確かめています。令和7年6月の厚生労働省の調査報告書は、令和6年度の再認定10,000件を抽出し、内訳を継続96.8%・増額改定1.4%・減額改定0.8%・支給停止1.0%とし、支給停止105件について「ガイドラインの上記記載を踏まえた対応が行われているかを確認したが、認定調書等には、判断の理由が明確に記載されているなど、特段の問題点等は確認できなかった」と書いています。同じ調査で新規請求の側には課題が指摘されたのと対照的で、更新の運用は、確かめた範囲では決まりどおりでした。

報告書には、更新の審査の手順も書かれています。新規請求では職員が「事前確認票」を作って等級案を書きますが、再認定ではそれを作らず、認定医が前回の認定も参考にしながら医学的に判断します。前回の診断書と今回の診断書を、認定医が並べて読む。だから、変わっていないことは変わっていないと書いてもらう、が更新の要点になります。
```

```
**Q. 止める前に、年金機構から本人や医師に問い合わせはありますか?**
A. ガイドラインは、等級を下げたり非該当にしたりするときは「前回認定時の障害状態確認届や照会書類等から認定内容を確認するとともに、受給者や家族、診断書作成医への照会を行うなど、認定に必要な情報収集を適宜行い、慎重に診査を行う」と定めています。必ず電話が来るという意味ではありませんが、今回の診断書1枚だけで決めない建て付けです。令和6年度の支給停止105件を国が確認した結果、判断の理由は明確に記載されていました。

**Q. 平成28年より前に受給が決まりました。ガイドラインで更新が厳しくなりましたか?**
A. ガイドラインは、施行(平成28年9月)前に認定された人について、「障害の状態が従前と変わらない場合については、当分の間、等級非該当への変更は行わないことを基本とする」としています。状態が変わっていなければ、ガイドラインを理由に非該当にはしない、という規定です。変わっていないことを、診断書に変わっていないと書いてもらってください。

**Q. 提出した診断書に、実態と違う記載があったと後で気づきました。**
A. 修正診断書を出す道があります。社会保険審査会は、更新で等級を下げた処分について、提出された修正診断書を採用して2級の継続を認め、処分を取り消した例があります(r07-03_04)。まず主治医に事実と違う点を伝え、修正した診断書を年金事務所に提出してください。審査請求の期限(決定を知った日の翌日から3か月)は別に進むので、期限内に審査請求も出しておくのが安全です。
```
