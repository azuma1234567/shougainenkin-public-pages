## #2 新 h2(h2「方法5:第三者証明を使う」の直後、h2「同じ状況の人が、どうなったか」の前)

```
## 日付が分からなくても「この期間のどこか」で認められる規則

方法1〜5を尽くしても「◯年◯月◯日」が出てこない人へ。もう一つ、知られていない規定があります。

平成27年9月28日の厚生労働省通知(年管管発0928第6号)は、初診日を明らかにする書類が添えられない場合の取扱いを定めていて、その中にこう書かれています。**初診日が一定の期間内にあることが参考資料で確認でき、その期間中のどの時点でも保険料納付要件を満たしているなら、その期間の中で請求者が申し立てた初診日を認めることができる。**

つまり、審査側が本当に確かめたいのは「何月何日か」ではなく、「その日に、どの年金制度に入っていて、納付要件を満たしていたか」です。期間のどこを取っても答えが同じなら、日付を1つに絞る必要がありません。

使える条件は、機構の案内ではこうなっています。

- 期間の全部が同じ年金制度で、どの時点でも納付要件を満たしている(たとえば、ずっと会社員で厚生年金、その間に未納がない)
- 期間の全部が20歳前(厚生年金の期間を除く)
- 期間の全部が60〜65歳で、納付要件を満たしている
- 期間中に制度が変わっていても、どの時点でも納付要件を満たし、かつ申し立てた初診日について参考資料がある

このとき用意するのは、「期間の始まり」を示す資料と、「期間の終わり」を示す資料の2つです。

- 始まり(まだ発病していなかった証拠): 就職時の健康診断書、人間ドックの結果、発病していないことが分かる診断書、事故など原因が起きた時期の資料
- 終わり(遅くともこの日には受診していた証拠): 2番目以降の病院の受診状況等証明書や診療録、障害者手帳の申請時の診断書、福祉サービスの受給開始の記録

裁決にも、この考え方で認められた例があります。古い診療録が無くても、あとの病院の診療録、入院中に届いた消印付きの手紙、院内の大会の賞状から「遅くともこの日には精神科病院に入院していた」と認定された事案です(r02_03-12_03)。日付そのものではなく、「遅くとも」で通っています。

年金事務所で相談するときは、「初診日を1日に特定できないのですが、◯年◯月から◯年◯月の間であることは資料で示せます。この期間はずっと国民年金(または厚生年金)で、納付要件は満たしています」と伝えてください。この言い方で、担当者は通知のどの規定に当たるかを見ます。
```

## #5 h2「「初診日が2つ候補にある」ときの考え方」の末尾に追加

```
もう一つ、裁決から。不支給の決定が出たあとに「実は別の日が初診日でした」と資料を出しても、審査会は「もとの請求で初診日を変更したとは扱えない」として、新たな初診日で請求をやり直すべきだと判断しています(r02_03-12_06)。候補が2つあるなら、出す前に年金事務所で両方を検討し、どちらで申し立てるかを決め切ってから出してください。出したあとの差し替えは、請求のやり直しになります。
```

## #6 FAQ(3 問追加。「Q. 第三者証明があれば、それだけで初診日は認められますか?」の直後に)

```
**Q. 初診日を「◯年◯月ごろ」までしか絞れません。それでも申請できますか?**
A. できる場合があります。厚生労働省の通知は、初診日が一定の期間内にあることが参考資料で確認でき、その期間のどの時点でも保険料納付要件を満たしているなら、その期間内で申し立てた初診日を認めることができるとしています。期間の始まり(発病前の健診結果など)と終わり(2番目の病院の記録など)を示す資料をそろえて、年金事務所で「期間で示せる」と伝えてください。

**Q. 第三者証明を書いてくれる人が1人しか見つかりません。**
A. 原則は2名ですが、通知は「単数の第三者証明であっても、医療機関の受診にいたる経過や医療機関におけるやりとりなどが具体的に示されていて、相当程度信憑性が高いと認められるものであれば」認めるとしています。1人しかいないなら、その人に、いつ・どこで・何を見聞きしたかを具体的に書いてもらってください。初診日ごろの医療従事者なら1名で足ります。

**Q. 通院をやめていた期間があります。再受診した日を初診日にできますか?**
A. 原則できません。それは「社会的治癒」という例外的な認定で、公表裁決で争われた4件はすべて退けられています。復職して働いていた期間にも症状と治療が続いていた、治療法がなく緩やかに進む病気だった、といった理由です。初診日は、その病気で最初に医師にかかった日です。通院をやめたからといって動きません。
```
