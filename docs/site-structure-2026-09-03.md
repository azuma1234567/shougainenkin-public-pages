### 1-2 同じものが3か所で3通りに分類されている
「探す軸」は5つ(病気・悩み・状況・お金・選ぶ)あるが:

| 場所 | 出ている軸 | 見出しの語 |
|---|---|---|
| ナビ | 2つ(病気・悩み) | 「病気から探す」「悩みから探す」 |
| トップ | 4つ(病気・悩み・状況・お金)+「自分でやるか、頼むか」は別セクション | 「どこから探しますか」 |

**状況・お金・選ぶの3軸がナビから辿れない。** 同じ「選ぶ」が、トップでは独立セクション、フッターでは探す軸の1つ。
見出しの語も「どこから探しますか」「探す」「◯◯から探す」と3通り。

## §2 提案する構造

### 2-1 3層に分ける
利用者が取る行動で3つに分ける。**この3語を、ナビ・トップ・フッター・パンくずの全部で使う。**

| 層 | 語 | 中身 | 目的 |
|---|---|---|---|
| 1 | **探す** | 5軸のハブ 44件 + 索引5 | 自分に近いページに着く |
| 2 | **確かめる** | 5機能(/dougu) | 自分の場合の数字と位置を出す |
| 3 | **読む** | /hajimete /shinsei /gokai /jitsurei /suuji /columns /yougo | 制度と実例を知る |

いまバラバラな「どこから探しますか」「調べる道具」「その心配、誤解かもしれません」を、この3語の下に入れる。

### 2-2 「探す」5軸に主従をつける
厚みと、申請の時系列に沿って **主3・従2**。

**主(ナビに出す)**
1. **病気から**(21) — 検索流入の受け皿。診断名で来る人が最も多い
2. **状況から**(9) — 働きながら・20歳前・一人暮らしなど、審査の見られ方が変わる条件
3. **悩みから**(6) — すでにつまずいている人の駆け込み先

**従(ナビに出さない。トップとフッターと各索引から辿る)**
4. **お金**(3) — /dougu/kingaku があるので、確かめる層と役割が重なる
5. **自分でやるか、頼むか**(5) — 申請を決めたあとの分岐。入口ではない

### 2-3 ナビ(7項目)
```
はじめて / 自分の場合 / 病気から / 状況から / 悩みから / 実例と数字 / コラム
```
- 「申請の流れ」をナビから外し、**/hajimete の中の主要導線**にする(はじめての人が最初に読むものなので、並列に置くと重複する)
- 「自分の場合」は現状どおり2番目(hero の問いに答える位置)
- 「◯◯から探す」→「◯◯から」に短縮(7項目が375pxで収まる)

### 2-4 トップの並び
```
1 hero(問い + 検索)
2 自分の場合を、確かめる      … 5機能
3 障害年金、はじめてですか？   … 3枚
4 探す                        … 5軸(主3を大きく、従2を小さく)
5 その心配、誤解かもしれません … 3枚 + /gokai へ
6 一度「不支給」でも…          … 実例
7 はじめての方は、8つのステップで
8 自分でやるか、頼むか
```
- 4番の見出しを「どこから探しますか」→**「探す」**にする(フッター・ナビと同じ語)
- 4番の中に**5軸すべて**を入れる。主3は大きいカード、従2は小さいカード。いまトップで独立している「自分でやるか、頼むか」(8番)は、4番の中の従として1回だけ出す **→ 8番のセクションは削除**
- 5番の3枚に /gokai/{slug} へのリンクを付ける(2026-09-03 に対応済み)

### 2-5 フッター(4列)
```
探す              確かめる                読む            このサイトについて
 病気から          自分の場合を確かめる    はじめての方へ   運営者情報
 状況から          私は何級くらい？        申請の流れ       情報の品質について
 悩みから          いくらもらえる？        よくある誤解     お問い合わせ
 お金の話          何をそろえればいい？    実例と数字       プライバシーポリシー
 自分でやるか、頼むか  どこに出せばいい？    数字で見る…     利用規約
                   申立書を、自分で書きたい コラム           広告掲載について
                                          用語辞典         無料iPhoneアプリ
                                                          アプリの利用規約…
```
見出しは §2-1 の3語 + 「このサイトについて」。**この4語がサイトの最上位の分類**になる。

### 2-6 パンくず
```
トップ / 探す / 病気から / うつ病・双極性障害
トップ / 確かめる / 私は何級くらい？
トップ / 読む / コラム / 記事名
```
いまは「トップ / 病気から探す / …」のように層が抜けている。**3語を必ず2段目に入れる。**
※ ただし既存47記事の BreadcrumbList は `lib/columns.ts` が持っており、変更は構造化データにも及ぶ。実装時は §4-2 の順で。

## §3 決めること(運営者が答える)

1. **主従の分け方**(§2-2)。主を「病気・状況・悩み」の3つにする案でよいか。
   - 別案A: 主を「病気・悩み」の2つにして、状況も従へ(ナビ6項目に収まる)
   - 別案B: 5軸すべてを主にして、ナビを9項目にする(375pxで確実に折り返す)
2. **「申請の流れ」をナビから外す**(§2-3)ことの可否。/hajimete と /shinsei の関係をどうするか。
3. **トップの「自分でやるか、頼むか」の独立セクションを消す**(§2-4)ことの可否。
4. **パンくずに3語を入れる**(§2-6)。既存47記事の構造化データが変わるため、URL は変わらないが Google の表示は変わりうる。

## §4 実装の順番(§3 が決まってから)
