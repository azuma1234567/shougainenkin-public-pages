# 「社労士を探す」無料掲載 v0 — 20〜50事務所で始めて、有料化の材料を貯める (2026-09-04)

前提(決定済み): 紹介・斡旋はしない。情報掲載・広告業として設計する(`/ads` の規約 第9条に明記済み)。成果報酬は使わない。判定・ランキング・口コミはしない。アフィリエイトは据え置き。

---

## §1 いちばん大事な前提: 事務所側に「載せる理由」がまだ無い

Search Console の実測はクリック30件/3か月。事務所にとって、いまのサイトに載る価値は「無料で、手間がかからず、載せておいて損がない」以上ではない。だから募集の設計は次の一点に尽きる。

**事務所の手間をゼロにする。**フォームに入力してもらわない。メールで6項目を返信してもらうか、事務所サイトから運営者が下書きを作って「これでよいですか」と送る。承認の返信1通で掲載する。

数字は正直に言う(「立ち上げ期で、月間クリックは二桁」)。盛らない相手にしか、有料化の交渉はできない。

## §2 掲載の中身(v0)

### 2-1 プロフィールの項目

| 項目 | 必須 | 決まり |
|---|---|---|
| 事務所名・代表者名 | ○ | |
| 社労士登録番号 | ○ | **連合会の名簿で運営者が確認**してから掲載(名簿にない・確認できない事務所は載せない) |
| 所在地(都道府県・市区町村まで) | ○ | 番地は任意 |
| 対応地域 | ○ | 都道府県の複数選択 + 「全国(オンライン・郵送)」 |
| 得意な障害の種類 | ○ | 精神 / 知的・発達 / 内部 / 外部(肢体・視覚・聴覚) の複数選択 |
| 初回相談 | ○ | 無料 / 有料 / 事務所に確認 |
| 料金の型 | ○ | 着手金の有無、成功報酬の計算方法(月数か遡及分の割合か)、不支給時の費用、審査請求まで含むか — **`/erabu/hiyou-souba` の「契約前に確認する3点」と同じ軸**。金額は事務所が書きたければ書く(書かなくてよい) |
| 連絡手段 | ○ | 電話番号 / メール / 事務所サイトURL(最低1つ) |
| 一言(200字まで) | 任意 | 事務所の言葉。運営者は添削しない |
| 更新日 | 自動 | 掲載日と、事務所が内容を直した日 |

**載せないもの**: 受給率・受給実績の件数(検証できない)、「必ず」「確実」「全国No.1」の類、他事務所との比較、口コミ・星、運営者による評価やおすすめ。プロフィールの責任は事務所(規約 第3条)。

### 2-2 ページ

| URL | 中身 |
|---|---|
| `/sharoushi` | 一覧。都道府県 × 障害の種類 × 対応形態(来所/オンライン)で絞る。**並び順は更新日の新しい順**(順位づけをしない。同日は五十音)。冒頭に3行: 「掲載は事務所の申告です / 当サイトは紹介・斡旋をしません / 連絡は事務所へ直接」 |
| `/sharoushi/<都道府県>` | 都道府県ごとの一覧。`/dougu/madoguchi` の年金事務所一覧と相互リンク(「この年金事務所の近くの社労士」) |
| `/sharoushi/<slug>` | プロフィール1枚。電話・メール・サイトの3ボタン。`/erabu/jibun-ka-irai` と `/erabu/hiyou-souba` へのリンクを本文の上に置く(**依頼するかどうかを決めていない人を、決める前に事務所へ送らない**) |

導線: `/erabu/*` の5本の末尾、`/nayami/fushikyu`、`/dougu/madoguchi` の各事務所ページ、トップの「決める」の帯。**記事本文には入れない**(47記事は触らない)。

### 2-3 データ

`data/sharoushi/offices.json`(事務所ごとに1レコード、上記項目 + `registeredAt` + `verified: {registryCheckedOn}`)。JSON-LD は `LocalBusiness`(`@type: "ProfessionalService"`)+ `BreadcrumbList`。noindex にしない(検索されてこそ材料になる)。

## §3 計測 — これが有料化の交渉材料

送るのは操作の事実だけ。閲覧者の情報は一切送らない(現行の方針どおり)。

| イベント | 値 |
|---|---|
| `sharoushi_list_view` | 都道府県・絞り込み条件(障害の種類・対応形態) |
| `sharoushi_profile_view` | 事務所ID |
| `sharoushi_tel_tap` | 事務所ID |
| `sharoushi_mail_tap` | 事務所ID |
| `sharoushi_site_click` | 事務所ID |
| `sharoushi_from` | どのページから一覧に来たか(erabu / nayami / madoguchi / top / search) |

**やらないこと**: 計測用の電話番号(コールトラッキング)。通話の中身に運営者が関わる形になり、仲介に近づく。タップ数で足りる。

### 月次レポート(事務所ごと・メール1通)

毎月1日に、各事務所へ「先月のあなたのページ: 閲覧◯件 / 電話タップ◯件 / サイトクリック◯件 / 都道府県一覧の表示◯件」を送る。**数字が小さいうちから送る。**小さい数字を隠さず送り続けた相手だけが、数字が伸びたときに払う。

サイト全体の材料は `docs/metrics/sharoushi-YYYY-MM.md` に月次で残す(一覧到達数、プロフィール閲覧の合計、タップ合計、都道府県別の需要)。

## §4 募集

### 4-1 だれに(優先順)

1. **「障害年金専門」を名乗っている事務所**(検索露出に関心がある。載る動機が最も強い)
2. eNENKIN.net に無料掲載している事務所(「載せる」判断を一度している)
3. Xで障害年金の情報発信をしている社労士(発信者は露出の価値を知っている)
4. `/dougu/madoguchi` で表示が多い都道府県の事務所(需要のある地域から埋める)

1〜4を合わせて候補60〜80件のリストを作る(事務所名・都道府県・専門・連絡先・出所)。**リストは repo に置かない**(第三者の連絡先の一覧になる)。ローカルで管理する。

### 4-2 いつ・いくつ

| 週 | やること | 見込み |
|---|---|---|
| 第1週 | §2 の実装(codex)と、規約の「無料掲載」条の確認。候補リスト作成 | — |
| 第2週 | 第1便 30通 | 返信率20〜30% → 6〜9事務所 |
| 第3週 | 第1便の掲載 + 第2便 30通。掲載した事務所に「掲載しました」を送る(SNSで告知したければどうぞ、の一言つき) | 累計 12〜18 |
| 第4〜6週 | 第3便 + リマインド(1回だけ) | 累計 20〜30 |
| 第8週 | 第1回 月次レポート送付 | — |
| 第12週 | 累計 30〜50。有料化の設計に入るかを §6 で判断 | — |

返信が無い事務所には**リマインドは1回だけ**。断られたら追わない(将来の広告主候補でもある)。

## §5 法的な確認(募集の前に1つ、有料化の前に1つ)

| いつ | 何を |
|---|---|
| 募集の前 | 最初に掲載を承諾した社労士に、**「情報掲載のみ・斡旋なし・成果報酬なし」の設計で問題がないか**を非公式に聞く(社労士側の広告規制=連合会の倫理規程との整合も)。1人でよい |
| 有料化の前 | 都道府県の社労士会へ、固定の掲載料で情報を掲載する事業についての見解を**文書で**確認する。回答は `docs/legal/` に残す |

プロフィールに事務所が書く内容にも規制がある(社労士の広告に関する連合会の指針)。「受給率」「必ず」の類を載せない決まり(§2-1)は、そのためでもある。

## §6 有料化の判断ライン(12週後)

次の**どれか**に達したら、有料枠の設計に入る。達していなければ、募集を続けて材料を貯める(掲載数を増やすより、`/erabu` と `/dougu` からの到達を増やすほうが効く)。

- 事務所あたりの月間プロフィール閲覧が **中央値で50件**
- 電話タップ + サイトクリックの合計が **月100件**(サイト全体)
- 掲載事務所から「上に出したい」「地域で目立ちたい」という**問い合わせが自発的に来る**

有料枠の候補(順に)= 都道府県ページの上部枠(エリアスポンサー)、プロフィールの「注目」表示、事例掲載。**一覧の並び順は有料でも変えない**(中立が商品価値)。

## §7 やらないこと(v0)

- ランキング、おすすめ、星、口コミ
- 相談フォーム、LINE、運営者経由の連絡(仲介になる)
- コールトラッキング番号
- 受給率・実績件数の掲載
- 掲載の代わりに記事監修を頼むこと(v0では関係を「掲載だけ」に保つ)
- 47記事の本文への社労士導線の挿入
