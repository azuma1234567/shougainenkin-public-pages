第2項: 次を上の額から控除する。
- 第1号: 雑損控除、医療費控除、社会保険料控除、小規模企業共済等掛金控除、配偶者特別控除、特定親族特別控除(地方税法第34条第1項第1号〜第4号・第10号の2・第12号)

**道具で入力させるのは社会保険料控除だけ。** 指示書 §A-2 の 5 にあった「本人の障害者控除(該当 / 特別障害者 / なし)」は、条文で本人が除かれているので**入力欄を置かなかった**(画面にその理由を1行書いた)。27万円・40万円の額は扶養している障害者の分として `amounts.ts` に残してあるが、指示書に無い入力なので使っていない。

## 指示書と違えたところ(理由つき)

1. **本人の障害者控除の入力欄を置かなかった**(上記。施行令 第6条の2 第2項第2号)。
2. **全額停止の線の加算は1人38万円だけ**(施行令 第5条の4 第2項)。
3. `/jukyuugo` の年表「1〜5年ごと」の行への道具カードは置いていない。年表は `lib/hub-index.tsx` の `timeline`(いつ / 起きること / リンク1本)で、行に道具カードを挟む部品が無い。新しい部品を作らない約束なので、`/jukyuugo` へは `/shinsei` ステップ8・`/nayami/koushin`・`/jukyuugo/hataraku` のカードで届く形にした(§0 の表のうち、この1か所だけ)。
4. `/gokai/hataraitara-make` は誤解カード(`data/gokai.ts`)で、道具カードを差し込む仕組みが無い。記事・ハブ・ステップの3つの仕組みの外なので置いていない(§0 の表のうち、この1か所)。
5. 日付の帯: `/jitsurei` と `data/hubs/byoki-hattatsu, byoki-tekiou-fuan, byoki-tougou, byoki-utsu-soukyoku, erabu-jibun-ka-irai` の日付を 2026-09-06 にした。今日の数字の混在の修正(`ebcc888`)で出典の文が変わっていたが日付を上げていなかったため、prelaunch C-6 が指摘した(この道具とは無関係の直し)。
