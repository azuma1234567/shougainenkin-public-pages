## §0 背景(数字)

サチコ 9/14–20 と 9/7–13 の比較で、表示回数が 1,530 → 913 に落ちて見える。ただし内訳は 9/7–10 の4日間だけに出た「掲載順位 4〜5・クリック 0・クエリ非表示」の表示(トップ 82、/gokai/shufu-mushoku 74、/columns/jukyuugo-tetsuduki 70、/columns/koushin-kakuninhodo 64 など)が消えただけで、クリックは 25 → 29、CTR は 1.6% → 3.2% に上がっている。トップページは 9/19 にクロール済み・登録済み・正規 URL も本人指定どおり。**順位が落ちたページはない。この指示書で順位の対策はしない。**

やることは2つ。どちらも今日確かめた事実に基づく。

1. Bing ウェブマスターツールが「meta description が短すぎるページが多い」と出している。実際に、ハブ 49 本のうち 15 本は description が 80 字未満で、しかも **本文の Markdown の `**` がそのまま meta description・og:description・Article.description に出ている**(例: /byoki/utsu-soukyoku の description は `うつ病でも双極性障害でも、**障害年金は請求できます。**`)。コラム 57 本のうち 14 本も 80 字未満。
2. サチコの URL 検査で、トップページの「参照元ページ」が `https://shougainenkin-public-pages.vercel.app/` になっている。Vercel の既定ドメインが 200 で配信され、Googlebot がそちらを巡回している。canonical は本番ドメインを指しているので重複にはなっていないが、クロールが割れているので 301 で寄せる。

## §1 vercel.app → 本番ドメインの恒久リダイレクト

`next.config.ts` の `redirects()` の先頭に、ホスト条件つきのリダイレクトを1つ足す。

```ts
// Vercel の既定ドメインは本番ドメインへ恒久リダイレクト(SEO 2026-09-23 §1)。
// Googlebot が vercel.app 側を巡回していたため。プレビュー(*-git-*.vercel.app)は host が違うので対象外。
{
  source: "/:path*",
  has: [{ type: "host", value: "shougainenkin-public-pages.vercel.app" }],
  destination: "https://shougainenkin-note.net/:path*",
  permanent: true,
},
```

- 既存の4件のリダイレクトはそのまま。順番は先頭。
- `permanent: true` は 308 になる。301 に固定する必要はない(Google は 308 も恒久として扱う)。

### 検証1
デプロイ後に本番で確かめる(ローカルでは host 条件が付かないので確かめられない)。

```
curl -sI https://shougainenkin-public-pages.vercel.app/gokai/kiso-ni-haiguusha | grep -i "^HTTP\|^location"
```
→ `HTTP/2 308` と `location: https://shougainenkin-note.net/gokai/kiso-ni-haiguusha`。
`curl -sI https://shougainenkin-note.net/` は今までどおり 200。

## §2 ハブの description — Markdown を剥がし、短いものに metaDescription を持たせる

### §2-1 `HubContent` に `metaDescription?: string` を足す
`lib/hub-content.ts` の型: `{ title; metaTitle?; metaDescription?; dateModified; breadcrumb; source }`。コメントは metaTitle と同じ調子で、「meta description・og:description・Article.description に使う。本文の1行目が短い(80 字未満)ハブだけに持たせる。h1 や本文には出さない」。

### §2-2 `hubDescription()` を直す(`lib/hub-jsonld.ts`)
```ts
export function hubDescription(hub, content = getHubContent(hub.path)): string {
  if (content?.metaDescription) return content.metaDescription;
  const line = content?.source.split("\n").find((l) => l && !l.startsWith("#")) ?? hub.label;
  return stripInlineMarkdown(line);
}
```
`stripInlineMarkdown` は同じファイルに置く小さな関数。剥がすのは `**強調**`→`強調`、`*強調*`、`` `code` ``、`[文字](URL)`→`文字` の4つだけ。それ以外(全角の記号、「」)は触らない。
