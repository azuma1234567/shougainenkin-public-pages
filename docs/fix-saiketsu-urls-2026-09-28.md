mhlw 側の「主な裁決例」ページ(`/topics/bukyoku/shinsa/syakai/05.html` → `r2_r3.html`)を読み直したところ、令和2・3年度のディレクトリは **`dl/05-r02_03/`** です。data の `dl/05-r2_r3/` は最初から誤記で、消えたのではありません。

| 状態 | 件数 | 内容 |
|---|---|---|
| 200 | 76 | r07 14・r06 11・r04_05 23・h30_31 6・h28_29 22 |
| 404 | 17 | `05-r2_r3/` の 17 件(05_01〜05_07・12_01〜12_10) |

`05-r02_03/` に置き換えた 17 件はすべて 200 を確認しました(ファイル名は同じ)。h27 は 05.html の一覧が h28_29 以降しかなく移動先不明。excluded なので今回は触らず、`note` があれば「URL 未確認」と残してください。

## 2. 作業

1. `data/saiketsu-cases-2026-08-26.json`: `dl/05-r2_r3/` → `dl/05-r02_03/` を 17 件置換。id(`r02_03-…`)は変えない。
2. `scripts/check-saiketsu-urls.mjs` を追加: data の全 url に HEAD を打ち、200 以外を一覧表示して非 0 終了。`package.json` に `check:saiketsu-urls` を追加。CI には入れず、手動と prelaunch の説明に「四半期に1回」と書く程度でよい(mhlw は curl を弾くことがあるので、失敗時は User-Agent を付けて再試行)。

```
審査請求の対象は「支給停止(または減額)の決定」です。同じ時期に届く年金額改定の通知のほうを対象にして申し立て、不適法として却下された裁決があります。そのときには支給停止処分の不服申立期間(3か月)も過ぎていて、もう争えませんでした。通知の名称と日付を確かめ、期限内に出してください。
```
