## §1 なぜ作るか
「障害年金 いくらもらえる」は最大級のクエリで、**AI Overviewsが必ず出ます**(`docs/metrics/ai-baseline-2026-09-02.md`)。記事では読まれずに終わる。そして**競合はどこも記事だけで、計算機を持っていません**(`docs/feature-gap-analysis-2026-09-02.md`)。とくに**障害厚生年金の報酬比例部分**を計算できる所が見つかりませんでした。ここが本当に知りたいところです。

目安ツール(`/dougu/mitate`)と直結します。「2級の目安 → では2級はいくらか」が1クリックでつながる。

## §2 絶対条件
1. **受給できるかを判定しない。**「あなたは2級です」ではなく「2級ならこの額です」。
2. 入力をサーバーへ送らない。AIを使わない。
3. **金額は `data/amounts.ts` 経由**。4月の改定で一斉に変わる。ハードコード禁止。
4. **概算であることを、結果の隣に必ず置く**(§7)。断定しない。
5. 3級には障害基礎年金が無い、障害基礎年金には配偶者加算が無い——**制度の違いを落とさない**。

## §4 計算式(1行も変えないこと)

### 4-1. 障害基礎年金(初診日が国民年金 or 厚生年金の1・2級)
```
1級 = KISO_1                     // 令和8年度 1,059,125円
2級 = KISO_2                     // 令和8年度   847,300円
3級 = 0                          // 障害基礎年金に3級は無い
子の加算 = 243,800 × min(子,2) + 81,300 × max(子-2,0)
```

### 4-2. 報酬比例部分(初診日が厚生年金のときだけ)
```
月数_旧 = 平成15年3月以前の被保険者期間の月数
月数_新 = 総月数 - 月数_旧
A = 平均標準報酬月額 × 7.125 / 1000 × 月数_旧
B = 平均標準報酬額   × 5.481 / 1000 × 月数_新
報酬比例 = A + B
// ★300月みなし: 総月数が300未満なら、総額を 300/総月数 倍する
if (総月数 < 300) 報酬比例 = 報酬比例 × 300 / 総月数
if (等級 === 1) 報酬比例 = 報酬比例 × 1.25
```
**300月みなしを落とすと、若い人の金額が実際より大幅に低く出ます。**この計算機の存在意義がここにあります。

### 4-3. 配偶者加給年金額
```
配偶者加給 = (制度 === 厚生 && 等級 ≤ 2 && 配偶者あり) ? 243,800 : 0
```
※ 障害基礎年金にはありません。3級にもありません。

### 4-4. 3級の最低保障
```
if (制度 === 厚生 && 等級 === 3 && 報酬比例 < SAITEI_3) 支給額 = SAITEI_3   // 635,500円
```

### 4-5. 合計
```
年額 = 障害基礎年金 + 子の加算 + 報酬比例 + 配偶者加給
月額 = round(年額 / 12)
偶数月の振込 = round(年額 / 6)
```

### 4-6. 年金生活者支援給付金(参考として別枠で出す)
```
1級 = 7,025円/月   2級 = 5,620円/月   3級 = 対象外
```
**障害基礎年金の受給者が対象**なので、**障害厚生年金3級のみの人には出ません。**所得の条件があります。金額の合計には入れず、「上乗せの可能性」として別に置く。

### 4-7. 実装上の注意
- 端数は**最後にまとめて**四捨五入する。途中で丸めない。
- 平均標準報酬額・月数が未入力なら、**報酬比例部分は「—」**と出す。0円と出さない。

## §5 「平均標準報酬額が分からない」への答え(ここが親切さの分かれ目)
入力欄の下に、常時たたんだ状態で置く。開くと:
- **ねんきん定期便**(毎年の誕生月に届くハガキ)の「これまでの年金加入期間」と「これまでの保険料納付額」の見かた
- **ねんきんネット**で見る手順(登録が要ること、基礎年金番号が要ること)
- **年金事務所**で聞けること
- ざっくり知りたい人向けに「**厚生年金に入っていた頃の、月々の給与とボーナスを12で割った額**をおおよそで入れると、目安になります」

## §6 出力(内訳を必ず見せる)
合計だけ出すと検算できません。**必ず内訳の表**を出す。

```
年額  1,091,100円     月あたり 約90,900円     偶数月の振込 約181,850円

内訳
  障害基礎年金 2級          847,300円
  子の加算(1人)             243,800円
  報酬比例部分                    —      (初診日が国民年金のため)
  配偶者加給年金額                0円     (障害基礎年金にはありません)
```
- 0円の行も**理由つきで表示する**(消すと「なぜ無いのか」が分からない)。
- 3級で最低保障が適用されたときは「**最低保障額が適用されています**」と明示。
- 300月みなしが効いたときは「**加入月数が300月未満のため、300月として計算しています**」と明示。

## §7 結果に必ず添えるもの
- **これは概算です。**実際の額は日本年金機構が決定します。とくに障害厚生年金は、機構が**従前額保障**という別の計算とも比べて、高いほうで決定するため、**ここで出した額より高くなることがあります。**
- 金額は**毎年4月に改定**されます。表示中の年度を出す。
- 生活保護・傷病手当金・労災・老齢年金との**調整があります**(自動計算はしない。`/okane/chousei` へ送る)。
- 障害年金は**非課税**ですが、健康保険の扶養認定では収入に数えます(誤解カード5番へ)。

## §9 完了条件(○×で報告)
1. `/dougu/kingaku` が動く。`/dougu` から行ける。
2. **300月みなし**が効いている(加入120月・平均標準報酬額30万・2級で検算し、報酬比例が約493,290円になること)。
3. 国民年金 × 3級 が**選べない**。
4. 3級で報酬比例が635,500円を下回ると**最低保障が適用**され、その旨が表示される。
5. 障害基礎年金に**配偶者加給が出ない**。3級に**子の加算・配偶者加給が出ない**。
6. 年金生活者支援給付金が、**3級では出ない**。合計額に含まれていない。
7. 未入力のとき報酬比例が「—」で、**0円になっていない**。
8. 金額がすべて `data/amounts.ts` 経由(`847,300` 等の直書きを grep して0件)。
9. 内訳表に**0円の行も理由つきで**出る。
10. §7 の4つの但し書きがすべて出る。
11. ネットワーク送信0件。
12. モバイル375pxで横スクロールなし。キーボードだけで操作できる。

## 執筆メモ(サイトに載せない)
- 300月みなしを完了条件に検算値つきで入れたのは、ここを落とす実装が多いから。30万 × 5.481/1000 × 120 = 197,316 → ×300/120 = 493,290。
- 従前額保障を計算に入れなかったのは、改定率が年度ごとに変わり、確認できない値を使うと嘘になるため。「ここより高くなることがある」と書くほうが誠実で、実害もない(低めに出るので落胆させない)。
- 0円の行を消さないのは、「なぜ自分には配偶者加算が無いのか」がこの制度の最頻出の疑問だから(誤解カード42番)。計算機が答えられる。
