初診日とは

障害の原因となった病気やけがで、初めて医師の診療を受けた日です。転院していれば、いちばん最初の病院での診療日。納付要件も障害認定日も、この日を起点に決まります。

出典: 日本年金機構 ・ 確認日 2026-08-19初診日がわからないとき →

受給の3要件

①初診日が特定できる ②保険料の納付要件を満たす ③障害の状態が等級に該当する。手続きも、この順番で確認していくのが基本です。

出典: 日本年金機構 ・ 確認日 2026-08-193つの確認をはじめる →

納付要件は2つのルート

①初診日の前々月までの加入期間の3分の2以上が納付済みか免除、または ②初診日の前々月までの直近1年間に未納がない(令和18年3月末までの特例)。どちらか一方で足ります。

出典: 日本年金機構 ・ 確認日 2026-08-19納付要件の確認 →

障害認定日とは

原則として、初診日から1年6か月を過ぎた日です。この日の障害の状態で等級が審査されます。初診日が決まると、認定日も自動的に決まります。

出典: 日本年金機構 ・ 確認日 2026-08-19認定日請求と事後重症 →

20歳前の初診なら、納付要件は問われない

初診日が20歳より前なら、保険料の納付要件はそもそも問われません。20歳前は年金制度への加入義務がないためです。代わりに、本人の所得による調整があります。

出典: 日本年金機構 ・ 確認日 2026-08-1920歳前に初診日があるとき →

診断書は「単身・援助なし」を想定して評価される

精神の障害用の診断書では、単身で生活し援助を受けていない場合を想定して日常生活能力を評価します。家族や職場の援助の中身が主治医に伝わっていないと、「一人でできる姿」として評価されることがあります。

出典: 厚生労働省 診断書記載要領 ・ 確認日 2026-08-19主治医に伝えること →

働いていること自体は、等級を下げる理由にならない

等級判定ガイドラインは、労働に従事していることをもって直ちに日常生活能力が向上したものと捉えない、と明記しています。見られるのは、どんな援助の中で、どう働けているかです。

出典: 精神の障害に係る等級判定ガイドライン ・ 確認日 2026-08-31働きながら申請する →

結果に不服があるときは、期限がある

不支給などの決定に不服がある場合、決定を知った日の翌日から3か月以内に審査請求ができます。その決定にも不服なら、2か月以内に再審査請求。期限が短いので、まず日付を確認してください。

誤解「貯金があると通らない」

貯金や資産は審査に関係ありません

障害年金は保険の給付なので、貯金・資産・持ち家は要件に含まれず、審査もされません。所得の制限があるのは20歳前傷病の場合だけです。

誤解「入院してないと無理」

入院は要件ではありません

通院だけでも、在宅で過ごしていても、日常生活や労働にどれだけ支障があるかで判断されます。

出典: 障害認定基準 / 等級判定ガイドライン ・ 確認日 2026-08-31くわしく見る →
誤解「会社や周りに知られる」

勤務先を経由しない手続きです

請求は本人(または家族)が年金事務所や市区町村に出す手続きで、勤務先を経由しません。受給が始まっても、年金機構から会社へ通知されることはありません。戸籍・住民票・運転免許にも記載されません。
