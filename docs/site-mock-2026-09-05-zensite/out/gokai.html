誤解の一覧(先頭12件)

「障害者手帳がないと、障害年金はもらえない」

手帳と年金は別の制度で、手帳がなくても年金は請求できます。等級も別々に決まり、手帳3級で年金2級の人もいます。

「働いていたら、障害年金は無理」

働いていること自体は対象外の理由になりません。国のガイドラインは「労働に従事していることをもって直ちに日常生活能力が向上したものと捉えない」としています。

くわしく見る →
「一人暮らしができているなら、自立していると見られる」

一人暮らしそのものは等級を下げる理由になりません。ガイドラインは、独居の場合はその理由や時期を考慮し、家族や福祉サービスの支援で生活できている場合はその状況を踏まえて判断する、としています。

くわしく見る →
「適応障害・パニック障害は対象外だから、申請できない」

認定基準は神経症を「原則対象外」としつつ、同じ段落で「精神病の病態を示しているものは気分障害に準じて扱う」としています。門は病名ではなく、いまの病態で開閉します。

くわしく見る →
「障害年金は非課税だから、収入ゼロとして扱われる」

税金はかかりませんが、健康保険の扶養認定では収入に数えます。障害年金を受けられる程度の障害がある人は年収180万円未満が扶養の基準です。

くわしく見る →
「貯金や持ち家があると、障害年金はもらえない」

障害年金は保険の給付なので、貯金・資産・持ち家は要件に含まれず、審査もされません。

くわしく見る →
「親に収入があるから、20歳前の障害年金はもらえない」

20歳前傷病の所得制限で見られるのは、本人の前年所得だけです。親や配偶者の収入は関係ありません。

くわしく見る →
「初診日は、病名がついた日」

初診日は、その症状で初めて医師の診療を受けた日です。診断名が確定した日ではありません。眠れなくて内科に行った日が初診になることもあります。

くわしく見る →
「カルテが残っていないなら、もう申請できない」

カルテがないケースは制度側も想定済みで、「受診状況等証明書が添付できない申立書」という公式の様式と、お薬手帳・診察券・第三者証明などによる認定の道があります。

くわしく見る →
「更新で等級が下がったら、もらった分を返さないといけない」

返しません。変わるのはその後の支払い分で、それまで正しく受け取っていた年金をさかのぼって返すことはありません(不正の場合は別)。

くわしく見る →
「初診日が何十年も前だから、時効で申請できない」

申請そのものに時効はありません。初診日が30年前でも、要件を満たせば請求できます。時効があるのは「さかのぼって受け取れる分」で、直近5年分までです。

くわしく見る →
「症状を重く見せないと、通らない」

重く見せる必要はなく、そうすべきでもありません。必要なのは、普段の状態が「漏れなく・事実のまま」診断書と申立書に載ることです。
