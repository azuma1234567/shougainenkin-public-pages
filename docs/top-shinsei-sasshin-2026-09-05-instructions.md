## §1 トップ(/) — 目的: 10 秒で自分の入口を見つける

### 1-1 いまの問題
- 「探す」の 5 ブロックが全部チップの羅列。入口ごとの違いが見た目に出ない(原則 §3「型は内容で選ぶ」に反する)。
- ヒーローの 4 つの数字(21 / 91 / 48 / 全件)は**サイトの在庫数**。訪問者の判断を変える数字ではない。

### 1-2 直す形
1. **ヒーロー**: 検索はそのまま。数字の行を、訪問者にとって意味のある 2 つ + 在庫 2 つに入れ替える(数字は黒、いまの `.p-stat` の組版のまま):
   - **87.0%** 支給に至った割合(令和6年度)
   - **70.3%** 精神の障害の割合
   - **91** 結論が分かれた実例(原文つき)(`SAIKETSU_COUNTS.all`)
   - **全件** 公的資料の出典・確認日つき
   数字の下に 1 文(原則 §1-6): 「10人のうち7人が精神の診断書で申請しています。」
   JSON-LD `WebSite` に `SearchAction`(`/?q={search_term_string}`)。
2. **申請の流れ**: 別指示書で済み。
3. **数字で見るのセクションは新設しない。** 「実例と数字」への導線は既存の実例の帯に「数字で見る障害年金 →」を 1 本足すだけ。
4. **はじめてですか？**: そのまま。
5. **探す**を 2 列にし、**型を内容で変える**:
   | 入口 | 型 | 中身 |
   |---|---|---|
   | 病気から | チップ。上位 10 + 「…ほか11」 | 「21の病気 →」 |
   | いまの状況から | チップ 9 つ | 「9つの状況 →」 |
   | 悩みから | **1 行リスト**(左: 悩み / 右: 小さな数字・黒)。不支給と言われた(期限 3か月)/ 初診日がわからない・カルテがない(争点 N件)/ 診断書で困っている(争点 N件)/ 更新が不安・支給が止まった(継続 96.8%)/ さかのぼって請求したい(最大5年) | N は `SAIKETSU_CASES` から |
   | お金の話 | **金額 2 つを数字の組版で**(タイルにしない): 「障害基礎年金 2級 **847,300円**/年」「上乗せ 給付金 2級 **5,620円**/月」+ 1 文「税金はかからず、貯金があっても関係ありません」 | `AMOUNTS_2026` |
   | 自分でやるか、頼むか | 2 枚の小カード(自分で進める / 専門家に頼む)+ 費用の相場へ | |
6. 誤解 / 実例 / 専門家: 構造はそのまま。実例の帯のカードは刷新後の `CaseCard`。

## §2 /shinsei — 目的: 8 ステップを途中で投げ出さずに進む

### 2-1 いまの問題
- ステップカード 8 枚が各 600〜700px、同じ見た目で 5,000px 以上。現在地が分からない。
- 「この段階ですること」がやったかどうかを残せない。閉じて戻った人が続きから始められない。

### 2-2 直す形
1. **ヒーロー**: h1 + intro + StepFlow(横並び)。
2. **つまずくのは 3 か所**: そのまま。
3. **2 カラム**(1000px 以上): 左 220px に**固定の目次**(番号 + `short`。現在地を `IntersectionObserver` で強調。チェック済みは番号が `--c-ok` の ✓。上に「進み具合 N/8」と細い棒)。1000px 未満は横スクロールのチップ列(sticky)。
4. **ステップカード**を圧縮(各 380〜450px): `header`(番号 / h2 + `oneLine` / 右端にデータ 1 つ) → `body` → 2 列(左「この段階ですること」チェック式、右「つまずきやすいところ」`--c-warn` 左罫線)→ `footer`(道具チップを先頭に、関連記事チップ、右端「次へ」)。**文は削らない**。
5. **右端のデータ**(黒。検証済みだけ。無いステップは出さない):
   | 1 初診日 | 初診日が争点の裁決 **N件** |
   | 2 納付要件 | 納付要件が争点 **N件** |
   | 5 診断書 | 診断書が争点 **N件** |
   | 7 提出 | 標準処理期間 **3か月** |
   | 8 結果 | 支給に至った割合 **87.0%** |
6. **チェック**: `localStorage`(`shougainenkin-note:shinsei-progress:v1`)。**送信なし**。上部に「この端末だけに保存されます → [リセット]」。JS 無しなら普通の箇条書き。
7. 金額の表 / 自分でやるか / しんどくなったら(`--c-ok` 左罫線)/ アプリ / 誤解 / FAQ: そのまま。
8. JSON-LD: `HowTo` は既存。FAQ があれば `FAQPage`。
