# 「何をそろえればいい？」と「どこに出せばいい？」を答えが先に見える形に直す — Codex 指示書 (2026-09-03)

2つとも、ロジックとデータは検証済みなので**画面の順番と言葉だけ**を直す。方針は他の3つと同じ:「答えを先に、質問は後に。役所の言葉は画面に出さない。primary 1色と灰色」。

## 変えないもの
- `data/shorui.ts` の分岐(when)・様式のURL・文書料の金額を書かないこと・様式番号の空欄。`lib/shorui.ts` の選別と保存。
- `data/madoguchi/*` と `lib/madoguchi*`(制度別の管轄・split の扱い・取得日・街角の注記)。
- 印刷(A4 2枚以内、書き込める箱)。既存の verify:shorui / verify:madoguchi の項目は通し続ける。
- 記事側のカード、記事本文。

---

# A. 何をそろえればいい？(/dougu/shorui)

## A-1 いまの問題
見出し「質問」→ 1〜7の番号つきの質問(3問目が「本来請求／事後重症／遡及」)→ 答え終わるまで書類が1枚も見えない。**共通の6つは最初から決まっているのに。**

## A-2 画面の順番(上から)
```
h1 何をそろえればいい？
1行: 誰にでも要る書類を先に出しています。下の質問に答えると、あなたの場合に要るものが足されます。

【そろえる書類】  ← 最初から共通6件が出ている。質問に答えるたびに行が増える
   □ 年金請求書 …(様式は制度で決まる。未回答なら両方併記 — 既存)
   □ 病歴・就労状況等申立書
   □ 診断書 …(種類は未回答なら「種類を選ぶと様式が決まります」)
   □ 基礎年金番号がわかるもの
   □ 振込先の口座がわかるもの
   □ 本人確認書類
   (回答で足される行は、薄い primary の背景で「あなたの場合」と小さく印)

【あなたの場合に足すもの】  ← 質問。全部飛ばせる(既存)。番号を消す
   初診日のとき、会社員でしたか(厚生年金)        [はい] [いいえ] [わからない]
   診断書を書いてもらう障害は                      [精神] [肢体] [眼] [聴覚・言語] [内部(心臓・腎臓など)] [血液] [その他]
   初診の病院と、いま診断書を書いてもらう病院は     [同じ] [違う] [違ううえ、カルテが無いと言われた] [わからない]
   家族(あてはまるものすべて)                      [18歳までの子がいる] [65歳未満の配偶者がいる] [どちらもいない]
   初診日から1年6か月たった頃の状態も書いて、さかのぼって請求しますか  [する] [しない] [まだ決めていない]
   交通事故など、ほかの人の行為が原因ですか         [はい] [いいえ]
   初診日は20歳より前でしたか                      [20歳より前] [20歳以降] [わからない]

【年金事務所へ行く日の持ち物】 (既存)
【窓口で聞くこと】 (既存)
[この1枚を印刷する]
「保存について」(折りたたみ。チェックはこの端末に残す／共用なので残さない／消す)
【ここからできること】 → どこに出せばいい？ / → 申立書を、自分で書きたい
```

## A-3 文言の対応(内部の値は変えない)
| いま | これから |
|---|---|
| 1. 初診日に入っていた制度は / 国民年金・厚生年金・わからない | 初診日のとき、会社員でしたか(厚生年金) / はい・いいえ・わからない(はい=kousei, いいえ=kokumin) |
| 3. 請求のかた / 本来請求・事後重症・遡及・まだ決めていない | 初診日から1年6か月たった頃の状態も書いて、さかのぼって請求しますか / する=sokyuu・しない=jigo・まだ決めていない=mitei。**「本来請求」は選択肢から外す**(認定日に近い時期の請求は「する」と同じ2通の扱いになるかを `when` で確認し、違えば「する」の中で分ける。既存の分岐は1行も変えない) |
| 7. 交通事故など、第三者の行為が原因ですか | 交通事故など、ほかの人の行為が原因ですか |
| 「質問」の見出し | 「あなたの場合に足すもの」 |
| 「選び直す」 | 「答えを消す」(質問の下、小さく) |

質問の順番は「本人が知っていること」から: 会社員か → 障害の種類 → 病院 → 家族 → さかのぼり → 事故 → 20歳前。

## A-4 見た目
- 書類の一覧が最上部。共通6件は白、回答で足された行は薄い primary(#e8f4fc)背景 + 「あなたの場合」の小さな印。
- 質問はチップ。番号なし。黄色の箱なし。
- 375px で、スクロールなしに書類の一覧の最初の3行が見える。

## A-5 検証(番号つきで○×)
1. 開いた直後、質問に答えなくても共通6件が出ている
2. 「質問」「1.」〜「7.」「本来請求」「事後重症」「遡及」が画面に無い
3. 「会社員でしたか」の はい/いいえ が kousei/kokumin に対応し、様式(107/104)の出方が既存と同じ
4. 「さかのぼって請求しますか」の する/しない/まだ が、既存の 遡及/事後重症/未定 と同じ書類の出方(診断書2通など)。本来請求の扱いを報告
5. 回答で足された行に「あなたの場合」の印がある
6. 375px でスクロールなしに一覧の3行が見える
7. verify:shorui の11項目が○(文言変更に合わせて更新)
8. 保存・共用・消す が「保存について」の中だけ

# B. どこに出せばいい？(/dougu/madoguchi)

## B-1 いまの問題
「1. 提出先を調べる」で制度と20歳前の2問 → 「2. 窓口を探す」で都道府県 → 市区町村。**本人が確実に知っているのは住所**なのに、それが2番目。番号つきの5節。

## B-2 画面の順番(上から)
```
h1 どこに出せばいい？
1行: お住まいの市区町村を選ぶと、管轄の年金事務所が出ます。日本年金機構の公表(2026-09-03 取得)によります。

【お住まい】  ← 最初の操作。前回の選択が残っていればそれを既定に(既存)
   都道府県 [選択]   市区町村 [選択]

【あなたの年金事務所】  ← 市区町村を選んだ瞬間に出る。質問はまだしない
   会社員だった方(厚生年金)の請求・相談 → ◯◯年金事務所(住所・電話 tel:・アクセス・機構ページ)
   国民年金の方の相談             → ◯◯年金事務所(同上)
   (同じ事務所なら1枚にまとめ「厚生年金・国民年金とも」。違うなら2枚並べて「相談と提出で行く場所が違うことがあります」— 既存)
   (split の市区は既存どおり両方 + 機構の管轄表へのリンク)
   1行: 国民年金だけの請求(障害基礎年金)は、お住まいの市区町村の国民年金の窓口にも出せます。20歳前に初診日がある方も同じです。
        初診日が第3号被保険者(会社員の配偶者)の期間にある方は年金事務所へ。

【街角の年金相談センター】 (既存。県内一覧 + 注記)

【予約のしかた】 (既存 §4。電話は tel:)
【行く日の持ち物】【窓口で聞くこと】 (既存。折りたたみにして見出しだけ出す)
[この紙を印刷する]
【ここからできること】 → 何をそろえればいい？ / → 申立書を、自分で書きたい
```

## B-3 消すもの
- 「1. 提出先を調べる」の節と、制度・20歳前の2問。**提出先の判定は、B-2 の「あなたの年金事務所」の1行(国民年金だけなら市区町村の窓口にも／第3号は年金事務所)に畳む。** 質問して分岐するより、両方を並べて1行で説明するほうが、間違えない。
- 節の番号「1.」〜「5.」

## B-4 見た目
- 都道府県・市区町村の選択が最上部。選んだ瞬間に事務所のカードが出る。
- 事務所カードは白地、左に 4px の primary。電話は大きく(tel:)。
- 375px で、市区町村を選んだあと、スクロールなしに1件目の事務所名と電話が見える。

## B-5 検証(番号つきで○×)
1. 最初の操作が都道府県の選択で、その前に質問が無い
2. 市区町村を選ぶと事務所が出る。横浜市南区で 厚年=横浜中 / 国年=横浜南 の2枚と「相談と提出で行く場所が違うことがあります」
3. 水戸市で split の2枚と機構の管轄表へのリンク
4. 「1.」〜「5.」「提出先を調べる」が無い
5. 国民年金だけ／20歳前／第3号 の1行が事務所カードの下にある
6. 375px で、選択後にスクロールなしに1件目の名前と電話が見える
7. verify:madoguchi の12項目が○(§3 の判定4通りは、質問を消したので「1行の説明が出ている」に検査を置き換え、設計書 §8-2/8-3 を書き換える)
8. 電話 tel:、機構リンク、取得日、街角の注記 が既存どおり
