# 障害年金サイトは上場できるのか — ChatGPT壁打ち結論の精査

作成: 2026-09-03 / 対象: 「サイト運営だけで上場できるのか？まとめ」(ChatGPT) と shougainenkin-note.net・アプリの現状

---

## 0. 先に結論

**「障害年金のサイト(＋アプリ)を主力にした上場」は、現時点の見込みとしては極めて低い。** 理由は努力量や戦略の良し悪しではなく、次の3つの構造要因が重なっているため。

1. **市場の天井が低い。** 障害年金で「お金が動く」のは社労士報酬(年50〜100億円規模の概算)で、そこから広告として取れるのは多く見ても年2.5〜10億円。1社で全取りしても上場基準の売上に届かない。
2. **法律で収益の取り方が縛られる。** 社労士法27条により、申請書類の作成・提出を「報酬を得て」行えるのは社労士だけ。ユーザー課金で申請支援を売ること、成功報酬・紹介料で社労士とつながることの両方が使えない。価格.comの「購入先につないで手数料を得る」構造はそのまま持ち込めない。
3. **上場基準そのものが上がった。** 東証グロース市場は2030年3月以降、「上場5年で時価総額100億円」が求められる(旧: 10年で40億円)。上場は「小さく上場して育てる」場ではなくなった。

ChatGPTの文書は「サイトか・アプリか」という形式論から離れ「入口を握る・独自データを持つ」という方向自体は正しい。ただし「上場できるか」という問いへの答えとしては、**市場規模と法規制の検算が一切入っていない**ため、結論の「可能」は根拠のない楽観になっている。

**現実的な到達点**は、(a) 年商数千万〜数億円の高収益なニッチメディア＋道具の事業、(b) 士業系・HR系企業への売却(M&A)、(c) 障害年金を「楔」にして隣接領域(傷病手当金・労災・休職・障害者雇用・介護)や社労士向けB2Bへ広げた先での上場検討。**上場を目標に置くなら、(c)の拡張を最初から設計に入れる必要があり、それは「障害年金サイト」とは別の事業計画になる。**

## 1. 「上場」の実際のハードル

| 項目 | 内容 | 出典 |
|---|---|---|
| グロース市場 上場維持基準(改正) | 上場後5年で時価総額**100億円以上**(旧: 10年で40億円)。2030年3月1日以降に迎える事業年度末から適用 | JPX 2025年9月決定 |
| 時価総額100億円の目安 | 売上10億円×PSR10倍、または営業利益5億円×PER20倍程度が必要 | 一般的な評価倍率からの逆算 |
| IPOの実務 | 監査法人による2期監査、主幹事証券、内部管理体制、取締役会・監査役、従業員数十名規模、億単位の準備コスト | 一般的なIPO実務 |

「サイト運営だけで上場」した例(価格.com・クックパッド)は、①国民の大半が消費者となる巨大市場、②取引連動の手数料モデル、③2000年代の上場基準、の3条件がそろっていた。障害年金はこの3つのどれも満たさない。

なお「上場」という言葉だけを満たすならTOKYO PRO Marketという選択肢はある(基準が緩い)が、一般投資家は売買できず資金調達や知名度の効果は限定的。ここでは目標として扱わない。

## 2. 市場の天井を数字で置く

### 2-1. 人の数
- 新規裁定 146,225件、非該当 18,982件 → **年間の申請(裁定)は約16.5万件**(令和6年度)
- 再認定(更新)約30万件/年
- 障害年金の受給権者は200万人超(概数)。ただし受給中の人はサイトの主な収益対象ではない

### 2-2. お金の流れ
障害年金でユーザー側から専門家へ動くお金は、実質「社労士報酬」だけ。

| 前提 | 値 |
|---|---|
| 年間申請件数 | 約16.5万件 |
| 社労士への依頼率(仮定) | 20〜30% → 3.3〜5万件 |
| 1件あたり報酬(着手金＋成功報酬 年金2か月分等の相場) | 15〜20万円 |
| **社労士の障害年金報酬市場(概算)** | **年50〜100億円** |
| 社労士が広告・集客に回す割合(仮定 5〜10%) | **年2.5〜10億円** |

つまり「障害年金の社労士広告市場」は、**日本中の全社労士の広告費を1社で集めても年2.5〜10億円**。弁護士ドットコムの集客支援(月2万円〜)を100事務所に売って年2,400万円、300事務所で7,200万円という以前の試算は、この天井の中では現実的な数字だが、上場の売上規模(10億円〜)とは一桁以上離れている。

### 2-3. ChatGPT文書の「月間100万UU × 年500円 = 5億円」の検算
- 年間の申請者16.5万人＋更新30万人＋家族を足しても、**能動的に情報を探す人は年間で数十万〜100万人程度**。月間100万UUは母集団の規模を超えている。
- 無料メディアの広告収益は1,000PVあたり数百円が相場。年5億円をAdSense等で作るには年10〜25億PVが必要で、この領域の検索需要では到達しない。
- 「年500円/人」を課金で作るなら申請支援を売ることになるが、これは次章の法規制に当たる。

## 3. 法規制が収益モデルをどう縛るか

| やりたいこと | 可否 | 根拠・注意 |
|---|---|---|
| 記事・道具(申立書ツール・金額計算機等)を**無料**で提供 | ○ | 報酬を得ないので社労士法27条の対象外 |
| 申立書作成・申請サポートを**有料**で提供(アプリ課金含む) | × | 社労士法27条(業務独占)。「サポート」「添削」と呼んでも実質が書類作成なら同じ |
| 社労士から**成功報酬・紹介料**を受け取る | △〜× | 社労士法23条の2・26・27条まわりのリスク。県会が紹介料ビジネスを問題視。以前の整理どおり「情報掲載・固定広告料」に限定するのが妥当 |
| 社労士から**固定の掲載料・広告料** | ○ | 弁護士ドットコム型。ただし市場天井は§2のとおり |
| アプリのAI相談・記録機能の**サブスク** | ○ | 申請書類の作成代行に踏み込まなければ独占業務外 |
| 「あなたに近い事例428件、支給率74%」の提示(ChatGPT案) | 要注意 | 病歴は要配慮個人情報。本人同意・匿名加工・保存設計が必須。さらに支給率の表示は「審査請求すれば6割通る」型の誤読を生む(既に「受給決定率は掲示しない」と決めた方針と矛盾)。等級判定に見える出力は避ける設計と衝突 |

結論: **ユーザーから取れるお金がほぼ無く、専門家からも取引連動で取れない**。これが価格.com・弁護士ドットコムとの決定的な違いで、ChatGPT文書が触れていない最大の穴。

## 4. 弁護士ドットコムと比べて何が違うか

| | 弁護士ドットコム | 障害年金サイト |
|---|---|---|
| 創業→上場 | 2005年→2014年(約9年) | — |
| 直近売上 | 162.9億円(2026年3月期、+15.7%) | — |
| 売上の中身 | クラウドサインARR等145.9億円が柱。メディア事業は来期計画98億円で、**弁護士・税理士・企業法務まで含む** | 障害年金1領域 |
| 課金の取り方 | 弁護士の有料掲載＋一般ユーザー有料会員(Q&A閲覧)＋SaaS | 固定広告のみ(§3) |
| 領域の広さ | 法律問題全般(離婚・相続・借金・労働・刑事…) | 社労士業務の中の1分野 |

弁護士ドットコムが上場・成長できたのは「法律相談」という巨大な入口と、後から作った電子契約SaaS(クラウドサイン)の2本柱。**メディア単体でも「社労士版」ではなく「士業全般版」の規模**で、障害年金はその中の1コマに相当する。

## 6. ChatGPT文書の論点別評価

| ChatGPTの主張 | 評価 | 補足 |
|---|---|---|
| 単なる記事サイトでは上場は難しい | 妥当 | ゼロクリック68%・AI Overviews常態の現状ではさらに厳しい |
| サイト・アプリ・AI・社労士紹介・事例データを一つにつなぐ | 方向は妥当 | ただし「社労士紹介」は紹介料モデル不可。「掲載」に言い換える必要 |
| 障害年金版の価格.com | 比喩として不適切 | 価格.comは取引連動手数料。障害年金では法的に同じ構造が組めない(§3) |

| 「このサービスを通らないと意思決定しづらい」ポジション | 妥当(事業目標として) | これは上場ではなく「強いニッチ事業」の目標。両者を混ぜないほうがよい |

## 7. それでも上場を視野に入れるなら(拡張の条件)

障害年金は「働けなくなった時の社会保障」の入口として非常に良い楔。上場規模を狙う場合、次のような拡張が**最初から**計画に入っている必要がある。

1. **領域の横展開**: 傷病手当金・労災・休職・復職・障害者雇用・障害者手帳・介護保険・生活保護など。対象人口が一桁増え、社労士以外(企業人事・医療機関・自治体)も顧客になる。ただし拡張ごとに社労士法・弁護士法・他士業との境界確認が必要。
2. **社労士向けB2B**: 障害年金を扱う社労士事務所向けの業務ソフト(申立書ドラフト支援・診断書チェック・裁決例検索・進捗管理)。社労士本人が業務を行うので27条に抵触せず、月額課金が成立する。今アプリで作っている申立書・見立てロジックはここに転用できる。
3. **医療機関・支援機関向け**: 病院・就労移行・相談支援事業所は障害年金相談の3割の入口(NPO実績)。診断書作成を楽にする道具は「主治医を楽にしたい」という当初動機とも一致する。
4. **データ事業**: 匿名化された申請・審査の統計を年次白書として発行し、報道・研究・行政・社労士会に引用される立場を取る。直接収益は小さいが、上記1〜3の信用の土台になる。

この4つを合わせて初めて「売上10億円の絵」が描ける。逆に言えば、**障害年金の消費者向けメディア単体で上場の絵を描こうとすると、必ず§2の天井に当たる**。

## 8. 12か月の判断ライン(提案)

上場の是非ではなく、まず事業として立つかを見る指標。

| 時期 | 見る数字 | 続行/見直しの目安 |
|---|---|---|
| 3か月後 | 月間UU、指名検索数、社労士無料掲載数 | 月間UU 1万・無料掲載20事務所に届かなければ集客設計を見直す |
| 6か月後 | 有料掲載の初契約、道具の利用数 | 有料掲載3〜5事務所(月3万円前提)・道具利用月1,000件 |
| 12か月後 | 月商、AI引用数、UU | 月商50万円・月間UU10万。ここに届けば「事業」。届かなければメディアは維持コストで回し、時間の重心をB2B(§7-2)へ移す |
| 24か月後 | 年商・領域拡張の着手 | 年商3,000万円超かつ隣接領域に1つ以上展開できていれば、初めて資金調達・上場の議論を始める |

## 9. 一言でまとめると

ChatGPTの結論「サイトを主力にして上場することは可能」は、**一般論としては真、この事業においては偽**。障害年金は「困っている人が多く、情報が壊れている」という意味で事業機会は本物だが、上場に必要な「お金の流れの太さ」と「法的に取れる収益の形」が無い。目指すべきは「上場できるサイト」ではなく、**「この領域で最も信頼される小さく強い事業」を12〜24か月で証明し、その信用を隣接領域とB2Bに広げるかどうかを、その時点の数字で決める**こと。上場はその先の選択肢の一つであって、今日決める目標ではない。
