## F-1 75.3% の読み直し(#0 lead 3 項目目・#3・#10・冒頭の decision box に関わる箇所すべて)

事実関係の整理(data/stats/nintei-chousa-r06.json):
- 抽出調査 1,000 件のうち非該当 130 件(13.0%)。前年度 8.4%。
- 精神の不支給 85 件のうち、「目安より下位」32 件+「目安が 2 等級にまたがり下位」32 件=64 件(75.3%)。これは **診断書から出る目安が「等級あり」または「等級ありと非該当のあいだ」だったのに、非該当になった事案**。診断書の丸がもともと非該当の位置にあったのは「目安どおり」の 11 件(12.9%)だけ。
- したがって正しい読みは「診断書が軽く書かれていたから落ちた」ではなく、「**丸の位置では等級に届いていたのに、総合評価で落ちた**」。総合評価で見られるのは、就労の実態、援助の状況、診断書の記述欄の具体性、申立書との整合。→ この記事の主張は「メモは丸を動かすため」ではなく「**丸のうしろにある記述欄(日常生活の状況・就労状況・現症)と申立書を、同じ実態で埋めるため**」に置き直す。fushikyu-85ken と矛盾しなくなる。

```

ここで、数字の読み方を一つ。精神の障害で不支給になった85件のうち、64件(75.3%)は、診断書の7項目と「程度」から出る目安表の位置では、等級に届いていた事案です。目安どおりに非該当だったのは11件(12.9%)しかありません。つまり不支給の大半は「丸が軽かった」からではなく、丸は届いていたのに、総合評価で落ちています。総合評価で見られるのは、就労の実態、家族や支援者の援助の状況、診断書の記述欄(日常生活の状況・現症・就労状況)にどれだけ具体的に書かれているか、そして申立書と食い違っていないか、です([不支給85件の中身](/columns/fushikyu-85ken))。

だから、このメモの役目は丸を動かすことではありません。医師が記述欄に「母が薬を並べている」「週の半分は昼まで起きられない」と書けるだけの材料を渡すこと。そして同じ生活を、あなたの申立書にも書くこと。診断書と申立書が同じ実態を指していれば、総合評価はそのまま通ります。診察室の数分で何が伝わるかが、そのまま結果に効きます。大げさな話ではなく、これが構造です。
```

## F-2 調査元の表出を外す(#6 全体を差し替え、出典から医療機関 2 件を削除)

h2「医師の側から見ると — 年金の診断書は、いつもの診察と違う情報が要る」の本文を次に差し替え。「X」「動画」「体験記」「2ページ/16ページ」「8割」はすべて消す。

```
メモを渡すことに気が引ける人へ。医師の側の事情を知っておくと、少し楽になります。

障害年金の診断書は、医師にとって、普段の診察で集めている情報とは別の情報が要る書類です。診察で見ているのは症状と薬の効き。診断書で問われるのは、入浴は週に何回か、通帳は誰が持っているか、インターホンに出られるか。カルテには、たいてい書いてありません。だから医師は、書こうとした瞬間に材料が足りないことに気づきます。

患者向けの案内に「診断書を頼むときは、日常生活の困りごとをメモにして持ってきてください」と書いている医療機関もあります。医師の側が、メモを求めている場面があるということです。あなたが渡すメモは、迷惑ではなく、医師が診断書を書くための材料です。

いちばんの損は、嫌がられそうだからと頼まないことです。診断書を断る医師はいますが、その多くには「初診から日が浅い」「通院が空いていて直近の状態が分からない」という医学的な理由があります。材料がそろっていれば、書ける医師のほうが多い。

分厚い資料は要りません。A4一枚か二枚。医師が診察の合間に読める量が、いちばん読まれます。

費用も先に知っておいてください。障害年金の診断書料は医療機関ごとに違い、5,000〜10,000円くらいが多いです。保険はききません。更新のたびにかかります。記述欄が空欄だらけの診断書に1万円払って、実態より軽く読まれる。それを防ぐのが、この一枚です。
```

## F-4 渡すタイミングの矛盾(#7 の h3「渡すタイミング」を差し替え)

```
### 渡すタイミング

- 渡すのは診察の冒頭です。最後に出すと、医師は読む時間のないまま診察を終えます。「最近の様子をメモにしてきました。先に読んでいただけますか」と、座ってすぐに出します
- 診断書を頼む日だけでなく、普段の診察から渡していくと、カルテに実態が積み上がります。頼む日に初めて渡すより、2〜3回前の診察から始めるのが確実です
- 診断書を頼む日は、混んでいる時間帯を避け、冒頭でメモを渡し、未記入の診断書用紙もいっしょに出します
- 病院によっては、診断書用の独自の聞き取りシートがあります。受付で「診断書を頼むときに書く用紙はありますか」と先に聞いてみてください。あれば、メモはそのシートの材料になります
```
