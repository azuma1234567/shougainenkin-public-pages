ガイドラインの表2「④就労状況」の原文を、そのまま置きます。審査側が読んでいる文言です。

- 「精神障害による出勤状況への影響(頻回の欠勤・早退・遅刻など)を考慮する」
- 「仕事場での臨機応変な対応や意思疎通に困難な状況が見られる場合は、それを考慮する」

## B-4 同じ h2 の末尾(「障害者雇用や就労支援(A型・B型)での就労は…」の前)に、調査報告書のヒアリング例を追加

```
審査の側で、就労がどう読まれるかの実例があります。令和7年6月の厚生労働省の調査報告書に載っている、審査を担当した職員の説明です。「障害等級の目安では2級とされていたが、カルテに症状は落ち着いていること、買い物等ができるとの記載があったほか、一般企業に一般雇用されているものの業務内容は単純作業であり、しばしば休むということを総合的に判断し、就労に制限がある状態として3級とした」。

目安では2級。それが「一般雇用で働いている」と「カルテに買い物ができる」で3級に動いた例です。ここで見てほしいのは、同じ事実が表2では逆の材料にもなることです。「業務内容は単純作業」「しばしば休む」は、表2の「専ら単純かつ反復的な業務」「頻回の欠勤・早退・遅刻」に当たり、2級の可能性を検討する側の材料です。どちらに読まれるかを分けるのは、診断書の就労欄と申立書に、援助・配慮・欠勤の実態がどれだけ具体的に書かれているか。「一般雇用・週5日」とだけあれば前者、「一般雇用だが、上司が毎朝手順を紙で渡し、月に3〜4日欠勤、帰宅後は食事を取らず寝る」とあれば後者です。
```
