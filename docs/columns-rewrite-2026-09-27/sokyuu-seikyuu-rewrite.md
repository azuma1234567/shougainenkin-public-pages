## #2 新 h2(h2「遡及請求の3つの関門」の直後)

```
## 遡及請求の「成功率」はあるのか

「遡及請求 成功率」で検索する人は多いのですが、先に答えます。**公的な成功率は公表されていません。** 日本年金機構の業務統計は、認定日請求と事後重症請求を分けた支給・不支給の件数を出していません。「成功率○%」と書いてあるページは、その事務所の受任分の数字か、根拠のない数字です。

代わりに、根拠のある数字を3つ置きます。

**1. 全体の非該当率。** 令和6年度の抽出調査で、新しく請求した1,000件のうち非該当は13.0%(精神障害12.1%)。これは認定日請求も事後重症も混ざった数字で、遡及だけの数字ではありませんが、「請求の8〜9割は何らかの等級に決まっている」という土台です。

**2. 公表されている裁決の結論。** 厚生労働省が公開している社会保険審査会の裁決のうち、当サイトが読んだ94件の中で、障害認定日請求を含むものは24件。結論は容認15件・一部容認1件・棄却8件でした。争点は「障害の程度・等級該当性」16件、「診断書の信頼性・整合性」7件、「初診日」5件、「手続その他」4件、「納付要件」2件。注意してほしいのは、裁決は一度不支給になって不服を申し立てた人の記録だということです。全体の成功率ではありません。ただ、**何が争われ、何で覆り、何で覆らなかったか**は、ここにしか書いてありません。

**3. 覆らなかった理由の型。** 棄却された認定日請求の理由は、読んでいくと1つに集約されます。**認定日ごろの状態を、当時の診療録で確かめられない。** 診断書を書いた医師が当時は診ていなかった、診療録に日常生活能力の記載がない、認定日から5か月後の診断書と知人の申述しかない、21年後の状態と一字一句同じ内容の診断書が出てきた。逆に、覆った事案は、当時の診療録や客観的な資料から認定日の状態が読めた事案です。6件の型は、このあとの「同じ状況の人が、どうなったか」に置きました。

つまり遡及請求の「成功率」は、あなたの病気の重さで決まるのではなく、**認定日ごろの記録が残っているか、その記録に生活の実態が書かれているか**で決まります。関門3が最大の壁、という意味はこれです。
```

## #3 h3「関門3: 認定日の診断書」

箇条書きのあと、「必要書類の全体は…」の前に追加:

```
「3か月以内」の根拠は、日本年金機構の請求案内です。障害認定日請求の診断書は「障害認定日より3か月以内の現症のもの」、そして認定日と請求日が1年以上離れている場合は「年金請求日前3か月以内の現症のもの」もあわせて必要、とされています。

ただし、絶対の壁ではありません。社会保険審査会は令和7年の裁決で、認定日から3か月を超えた現症日の診断書しかない事案について、感染症への不安で通院できなかった事情などから「その診断書で判断できる」として、不支給処分を取り消しています(r07-07_02)。3か月を超えていても、通院できなかった理由と、前後の記録から認定日の状態が読めるなら、門は閉じていません。ただしこれは例外的な認定で、まず3か月以内の受診記録を探すのが先です。
```

## #4 h2「認定日ごろのカルテがない・通院していないとき」の (1)

「カルテの法定保存は5年ですが、…」の段落を次に差し替え:

```
カルテ(診療録)の保存義務は、医師法24条2項で5年です。健康保険を使った診療の記録は、保険医療機関及び保険医療養担当規則9条で「完結の日から3年」。つまり法律上は、最後の受診から5年を過ぎると病院はカルテを廃棄してよいことになります。ただ、実際にはもっと長く保管している医療機関が少なくありません。電子カルテに移行した病院では紙の時代の記録が残っていることもありますし、大きな病院ほど保存期間を長く定めています。電話で「破棄しました」と言われても、受付の即答と実際の保管状況が違うことがあるため、「診療録の保存の有無を確認してほしい」と文書で照会する価値はあります。診療録そのものがなくても、レセプト(診療報酬明細)の控え、紹介状の写し、検査結果が残っている場合もあります。
```

**統合失調症・障害認定日請求(平成28〜29年、h28_29-16_05)** — 障害認定日から21年後の状態と全く同じ内容で作成された認定日の診断書は不自然で、当時の診療録から日常生活能力を具体的に認定できないとして、原処分が維持されました。現在の診断書を写した認定日の診断書は、見抜かれます。

**強迫性障害・障害認定日請求(令和2〜3年、r02_03-12_02)** — 診断書を作成した医師は当時本人を診察しておらず、基礎となった診療録にも現症日の病状や日常生活能力を裏付ける記載がないため、認定日の状態を認定できないとして、原処分が維持されました。

### 通った診断書 — 記録から認定日の状態が読めた

**自閉スペクトラム症・障害認定日請求(令和7年、r07-07_02)** — 認定日から3か月を超えた現症日の診断書では認定できないとした処分について、感染症への不安で通院できなかった事情などから、その診断書で判断できるとして、原処分が取り消されました。3か月ルールの例外が認められた例です。

**下垂体機能低下症・器質性情緒不安定障害・障害認定日請求(令和6年、r06-07_02)** — 認定日の精神障害を示す診断書がないことも根拠に不支給とした処分について、精神科を標榜しない医師でも当時診察していたならその診断書の適格性を当然には否定できず、提出の機会を与えなかった手続も不適正として、原処分が取り消されました。認定日ごろに通っていたのが内科や心療内科でも、当時診ていた医師の診断書には意味があります。

### 認定日は通らず、現在分だけ通った

**気分変調症・障害認定日請求と事後重症請求(平成28〜29年、h28_29-07_13)** — 障害認定日の時点は等級非該当とされましたが、裁定請求日にはヘルパーを要する生活状況などから2級に該当するとされ、事後重症部分を3級とした原処分が取り消されました。認定日請求と事後重症請求をセットで出す意味が、ここにあります。

## #6 h2「「認定日からもうすぐ5年」の人へ — 緊急度の目安」の冒頭に追加

```
時効の根拠は、国民年金法102条1項と厚生年金保険法92条1項です。年金を受ける権利(基本権)は5年で時効にかかり、各支払期の年金を受ける権利(支分権)も5年。裁定前でも支分権の時効は各支払期から進む、というのが最高裁の判断で、社会保険審査会もそれに従っています(上の r04_05-06_02)。だから、認定日から5年を超えている人にとっては、請求が1か月遅れるごとに、いちばん古い1か月分が確定的に消えます。
```

## #7 FAQ(2 問追加。「Q. 遡及請求と事後重症請求は同時に出せますか?」の直後に)

```
**Q. 遡及請求の成功率はどのくらいですか?**
A. 公表されていません。日本年金機構の業務統計は、認定日請求と事後重症請求を分けた支給・不支給の件数を出していないため、「成功率○%」と書いてあるページは、その事務所の受任分か、根拠のない数字です。代わりに使える根拠は、令和6年度の非該当率13.0%(請求全体)、公表裁決のうち認定日請求を含む24件の結論(容認15・一部容認1・棄却8)、そして退けられた理由がすべて「当時の診療録に裏付けがない」だったことです。成功率は病気の重さではなく、認定日ごろの記録が残っているかで決まります。

**Q. 認定日のころに通っていたのが精神科ではなく内科です。その診断書でも遡及できますか?**
A. 可能性はあります。社会保険審査会は、精神科を標榜しない医師でも当時診察していたなら、その診断書の適格性を当然には否定できないとして、不支給処分を取り消した例があります(r06-07_02)。当時の内科の診療録に、不眠・食欲不振・出勤できない日などの記載があれば、それが認定日の状態の裏付けになります。まず、その病院に診療録が残っているかを確かめてください。
```
