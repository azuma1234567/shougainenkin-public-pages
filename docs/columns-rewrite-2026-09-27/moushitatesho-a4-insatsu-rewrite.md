## まず手順。3つの刷り方

理屈はあとに回します。先に、A4で刷る手順です。どの方法でも、様式は日本年金機構の配布ページから最新版を使います(ページ名は「病歴・就労状況等申立書を提出するとき」。PDF版とエクセル版、続紙、記載要領が並んでいます)。

### 自宅のプリンターで(5分)

1. 日本年金機構のページから「病歴・就労状況等申立書」のPDFを保存する。期間が多くなりそうなら「続紙」のPDFも
2. PDFを開いて印刷。用紙サイズをA4にする
3. 「用紙に合わせる」「ページに合わせて縮小」をオフにして、倍率100%にする。A3原稿を2枚に分ける機能(「ポスター印刷」「分割印刷」など、名前はメーカーで違う)があれば使う。なければ、PDF閲覧ソフトの印刷設定で「複数ページに分割」に当たる項目を探す
4. まず1枚だけ刷って、端の記入欄と項目名が切れていないかを見る
5. 大丈夫なら、必要枚数を刷る

### コンビニで(A3の原寸で刷れる)

1. スマートフォンかパソコンに申立書のPDFを保存する
2. セブン‐イレブンなら「かんたんnetprint」、ファミリーマート・ローソンなら「ネットワークプリント」にPDFを登録し、予約番号(またはQRコード)を受け取る
3. 店のマルチコピー機で番号を入れ、用紙サイズ(A3かA4)と倍率100%を指定して刷る
4. 出てきた紙を、その場で見る

## #8 FAQ(3 問追加。「Q. 控えのコピーは何を取ればいいですか?」の前に)

```
**Q. 年金事務所ではA3の用紙を渡されました。A4で刷ったものと混ぜて出していいですか?**
A. 構いません。本紙はもらったA3、続紙は自宅でA4、という組み合わせで受け付けられています。それぞれの紙に「No.1－3枚中」のように順番と枚数を書いて、順番どおりに重ねてください。不安なら提出先に一言確認を。

**Q. エクセル版に入力して印刷したら、文字が潰れました。**
A. 公式のエクセル様式は、そのまま印刷すると印刷範囲の設定で崩れることがあります。エクセルから「PDFとして保存」し、そのPDFを印刷してください。表面と裏面でシートが分かれているので、両方をPDFにします。

**Q. 鉛筆や消せるボールペンで書いてもいいですか?**
A. 提出書類なので、黒のボールペンが基本です。窓口の予約相談で提出する場合は、鉛筆書きを受け付けてもらえたという話もありますが、郵送では消えない筆記具が必要です。鉛筆で下書きしてボールペンで清書し、乾いてから消しゴム、が遠回りに見えて確実です。
```
