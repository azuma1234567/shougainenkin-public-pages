## #4 新 h2(h2「診察室で起きていること」の直後、「→ 「入院していないと…」」の誤解リンクの下)

```
## 「家族がやってくれるから大丈夫」とは書かない — 一人で生活するとしたら

ここが、家族と暮らしている人がいちばん落ちる穴です。

厚生労働省の記載要領は、医師にこう指示しています。7項目の判断は「単身で生活するとしたら可能かどうか」で行うこと。家族との同居や施設で支援が常態化し、生活が安定している場合でも、「単身でかつ支援がない状況で生活した場合を想定」して書くこと。

つまり、母が薬を並べてくれるから飲めている人は、診断書の上では「飲めている」ではありません。「助言や指導があればできる」です。母が通帳を管理しているから滞納がない人は、「金銭管理ができる」ではありません。家族の手がなければどうなるか、が問われています。

なのに本人は、診察でこう言ってしまいます。「食事は母が作ってくれるので、ちゃんと食べています」。医師の耳には「食べられている」だけが残ります。メモに「母が用意して、声をかけてくれるので食べる。声かけがない日は食べない」と書けば、医師は正しい欄に丸をつけられます。

同居を伝えると不利になるのでは、と心配する人がいます。逆です。同居していること自体は判断材料ではなく、「同居していなかったら何が起きるか」が判断材料です。隠す必要はなく、家族が何をしているかを、そのまま書いてください。

一人暮らしの人も同じ理屈で守られます。「一人で暮らせている=日常生活能力が高い」ではありません。訪問看護が週に来ている、実家から食材が届く、督促状を放置して電気が止まったことがある。一人暮らしの中の「回っていない部分」を、そのまま書きます([一人暮らしは不利?](/columns/hitorigurashi-furi))。
```

## #5 h2「「できる」と書かれないための言い換え」

冒頭の「原則は3つです。」を「原則は5つです。」に変え、原則3 の下に次を追加。末尾の段落「この3つが入っていれば…」は「この5つが入っていれば…」に。

```
### 原則4:波は「平均」と「いちばん悪い週」で書く

×「日によります」 → ○「起き上がれない日が月に12日くらい。いちばん悪かった先々週は、5日間ほぼ布団の中で、食事は母が枕元に置いた」

波があると、診察日は調子を整えて行ける日になりがちです。医師が見るのは山の日だけ。谷の日を、日数と場面で書いておきます。「放っておくとどうなるか」も1行あると、医師は「時に援助が必要」か「多くの援助が必要」かを判断しやすくなります。

### 原則5:飲んでいない薬があるなら、理由を書く

×(何も書かない) → ○「○○は、過量服薬が心配で先生が処方を止めています。いまは頓服だけです」

服薬していないと「軽い」と読まれることがあります。医師の判断で減らしている、副作用で中止した、飲めない事情がある。理由が書いてあれば、審査側は「服薬なし」を「軽症」と読みません。
```

## #6 新 h2(h2「同じ状況の人が、どうなったか」の直後)

```
## 医師の側から見ると — 年金の診断書は、いつもの診察と違う情報が要る

メモを渡すことに気が引ける人へ。医師の側の事情を知っておくと、少し楽になります。

障害年金の診断書は、医師にとって「普段の診察で集めている情報とは別の情報」が要る書類です。診察で見ているのは症状と薬の効き。診断書で問われるのは、入浴は週に何回か、通帳は誰が持っているか、インターホンに出られるか。カルテには、たいてい書いてありません。だから医師は、書こうとした瞬間に材料が足りないことに気づきます。精神科医が自分の動画で「患者さんと一緒に作る過程が要る」「紙に書いて持ってきてほしい」と話しているのは、そのためです。

実際に、患者向けの案内で「診断書を頼むときは、日常生活の困りごとをメモにして持ってきてください」と書いているクリニックがあります。医師の側が、メモを求めています。あなたが渡すメモは、迷惑ではなく、医師が診断書を書くための材料です。

Xで当事者や支援者が繰り返し書いていることも同じ方向です。医師の多くは診断書の作成に前向きで、いちばんの損は「嫌がられそうだから」と頼まないこと。もう一つ、口下手で社労士も頼まずに申請した人の体験記があります。最初にA4で2ページ、直近の困りごとだけをまとめて渡したら、医師はその場で「これなら書ける」と引き受けた。その人はあとで16ページの資料も作りましたが、医師の態度を決めたのは最初の2ページでした。

分厚い資料は要りません。A4一枚か二枚。医師が診察の合間に読める量が、いちばん読まれます。

費用も先に知っておいてください。障害年金の診断書料は医療機関ごとに違い、5,000〜10,000円くらいが多いです。保険はききません。更新のたびにかかります。空欄だらけの診断書に1万円払って、実態より軽く書かれる。それを防ぐのが、この一枚です。
```

## #7 h2「渡し方に、特別な言葉は要らない」

見出し直下(いまの箇条書きの前)に次を追加。

```
### 頼むときの一言

診断書をお願いするときの言い方は、これで足ります。

- 「日常生活と仕事のことで困りごとが続いていて、障害年金の申請を考えています。診断書をお願いできますか」
- 「治療に専念するために、生活の土台を整えたいと思っています」

言わないほうがいいのは「年金をもらいたいので書いてください」「2級で書いてください」。前者は目的が年金だけに聞こえ、後者は医学的判断への介入です。どちらも医師の警戒を招きます。

### 言いにくい人の言い方

「できません」と口にするのがつらい人は、言い方を変えて構いません。「一人でお風呂に入れるようになりたいのですが、いまは母に言われてやっとです」。できないことを言う代わりに、できるようになりたいことを言う。医師には同じ情報が伝わり、診察の空気は壊れません。

### 渡すタイミング

- 診断書を頼む日だけでなく、普段の診察から渡していくと、カルテに実態が積み上がります
- 頼む日は、混んでいる時間を避け、診察の最後に、未記入の診断書用紙とメモをいっしょに渡します
- 病院によっては、診断書用の独自の聞き取りシートがあります。受付で「診断書を頼むときに書く用紙はありますか」と先に聞いてみてください。あれば、メモはそのシートの材料になります
```

## #8 新 h2(h2「受給後も続く話」の直前)

```
## 受け取ったら、その場で封を開ける

診断書は、渡す前より、受け取ったあとのほうが取り返しがつきません。提出してしまうと、原則として直せないからです。

受け取ったら、封をしたまま持ち帰らず、その場か帰り道で開けて、4か所を見ます。7項目の丸が、メモに書いた実態と合っているか。「日常生活能力の程度」が、家族の手がない前提で書かれているか。就労欄に、配慮や欠勤が書かれているか。空欄がないか。

合っていないところがあれば、医師の判断を否定しない言い方で聞きます。「この欄について、先生の見立てをもう少し伺ってもいいですか。家ではこういう状態で……」。事実の伝え漏れなら、多くの医師は直してくれます。見るべき場所の詳しい一覧は、[診断書を受け取ったら確かめる7つのポイント](/columns/shindansho-kakunin)にあります。
```

```
**Q. メモに決まった様式はありますか? どんな形式でもいいですか?**
A. 決まった様式はありません。A4で1〜2枚、生活の場面ごと(食事、清潔保持、買い物と金銭、服薬と通院、対人関係、危機対応、手続き、就労)に、事実と頻度と誰の助けがあるかを書けば十分です。手書きでもスマホ印刷でも構いません。この記事の冒頭の「空欄の型」をそのまま使ってください。10枚の手記は読まれません。
```

次の 4 問を追加(「Q. 主治医が障害年金の診断書を書きたがりません」の前に):

```
**Q. 家族と同居していると、不利になりますか?**
A. なりません。診断書の7項目は「単身で生活するとしたら可能か」で判断する決まりです。同居していることではなく、家族の手がなければ何が起きるかが見られます。家族が何をしてくれているかを、そのまま書いてください。「母がやってくれるので大丈夫です」とだけ伝えるのが、いちばん損です。

**Q. 薬を飲んでいないと、軽いと見られますか?**
A. 理由が伝わっていないと、そう読まれることがあります。医師の判断で減らしている、副作用で中止した、過量服薬を防ぐために処方を止めている。理由をメモに1行書いておけば、「服薬なし」は「軽症」と読まれません。

**Q. 診断書代はいくらですか?**
A. 医療機関ごとに違い、5,000〜10,000円くらいが多いです。保険はききません。更新(障害状態確認届)のたびにかかります。遡及請求で認定日のころの診断書も頼むなら、もう1枚分かかります。

**Q. メモは、診断書を頼む何回前の診察から渡せばいいですか?**
A. 早いほどいいです。頼む日に初めて渡すより、2〜3回前の診察から渡していくと、カルテに実態が積み上がり、医師は「書ける」状態で依頼を受けられます。いまから始めるなら、次の診察に1枚持っていってください。
```
