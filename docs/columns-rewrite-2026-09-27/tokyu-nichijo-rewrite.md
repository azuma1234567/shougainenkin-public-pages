## A-4 h2「目安表の外側 — 「総合評価」で見られていること」を、表2 の原文中心に差し替え

見出しはそのまま。本文を次に:

```
ガイドラインには目安表と並んで、「総合評価の際に考慮すべき要素の例」(表2)が示されています。目安表の数字を出発点に、次の5分野の要素を加味して最終判断される建て付けです。ここは原文で読んでください。審査する人が見ているのは、この文言だからです。

### ① 現在の病状または状態像

統合失調症は「療養及び症状の経過(発病時からの状況、最近1年程度の症状の変動状況)や予後の見通し」、陰性症状が長期間持続し自己管理能力や社会的役割遂行能力に著しい制限があれば1級または2級の可能性。気分(感情)障害は「現在の症状だけでなく、症状の経過(病相期間、頻度、発病時からの状況、最近1年程度の症状の変動状況など)」、適切な治療でも重い症状が長期間持続または頻繁に繰り返すなら1級または2級の可能性。ひきこもりは、病状の影響で継続して日常生活に制限が生じていれば考慮する。

### ② 療養状況

「通院の状況(頻度、治療内容など)」、薬物治療の「種類・量・期間」と「服薬状況」。通院や薬物治療が困難または不可能なら「その理由や他の治療の有無」を考慮する。在宅で家族や重度訪問介護等から常時援助を受けて療養していれば、1級または2級の可能性。

飲んでいない薬があるなら理由が要る、というのはここから来ています。

### ③ 生活環境

「独居であっても、日常的に家族等の援助や福祉サービスを受けることによって生活できている場合(現に家族等の援助や福祉サービスを受けていなくても、その必要がある状態の場合も含む)は、それらの支援の状況(または必要性)を踏まえて、2級の可能性を検討する」。「入所施設やグループホーム、日常生活上の援助を行える家族との同居など、支援が常態化した環境下では日常生活が安定している場合でも、単身で生活するとしたときに必要となる支援の状況を考慮する」。独居の場合は「その理由や独居になった時期」も。

### ④ 就労状況

「労働に従事していることをもって、直ちに日常生活能力が向上したものと捉えず」、仕事の種類・内容・就労状況・職場で受けている援助・他の従業員との意思疎通を確認して判断する。「援助や配慮が常態化した環境下では安定した就労ができている場合でも、その援助や配慮がない場合に予想される状態を考慮する」。就労継続支援A型・B型、障害者雇用制度による就労は1級または2級の可能性を検討する。一般企業でも同程度の援助を受けていれば2級の可能性。「精神障害による出勤状況への影響(頻回の欠勤・早退・遅刻など)」、「臨機応変な対応や意思疎通に困難な状況」を考慮する。1年を超えて働いていても、就労の実態が不安定ならそれを考慮する。

### ⑤ その他

「「日常生活能力の程度」と「日常生活能力の判定」に齟齬があれば、それを考慮する」。そして、「「日常生活能力の判定」の平均が低い場合であっても、各障害の特性に応じて特定の項目に著しく偏りがあり、日常生活に大きな支障が生じていると考えられる場合は、その状況を考慮する」。7項目のうち1つだけ4点、あとは1〜2点、という人が、平均だけで切られない根拠がこれです。

重要なのは、これらの要素はすべて診断書と申立書に書かれている範囲でしか考慮されないということです。障害者雇用で手厚い配慮を受けていても、その事実が書面になければ「一般就労と同じ」に見えます。援助を受けながらの生活も、援助の記載がなければ「自立した生活」に見えます。総合評価とは、書面に載った情報の総合なのです。7項目それぞれで何を書けば伝わるかは、[日常生活能力の判定7項目の記事](/columns/nichijo-seikatsu-7koumoku)にまとめてあります。
```

## A-5 新 h2「審査の裏側 — 事前確認票と認定医」(h2「目安どおりにならないのは、なぜか」の直前に追加)

```
## 審査の裏側 — 事前確認票と認定医

あなたの書類が障害年金センターに着いてから、何が起きるのか。令和7年6月の厚生労働省の調査報告書に、手順が書かれています。

まず職員が、納付要件などを確認し、「事前確認票」を作ります。認定に必要な事項を整理した文書で、令和4年4月から使われています。ここには職員の「等級案」を書く欄があります。次に、障害認定審査医員(認定医)が、その事前確認票も参考にしながら、診断書・申立書・カルテの写しなどから、医学的な観点で等級を判断します。精神の障害では、目安表の位置を出発点に、表2の要素を診断書等の記載から読み、総合評価します。

報告書が問題にしたのは、ここからです。令和6年度に「目安では届いていたのに非該当」になった64件のうち、約9割(58件)は職員の事前の等級案どおりの結果でした。そして、表2の「生活環境」「就労状況」に当たる記載が事前確認票や認定調書に書かれていたのは、85件中26件。調書の記載は「⑩ウ(イ)、カルテ、就労状況より3級」のように、単語や記号の列挙にとどまるものが見受けられた、と報告書は書いています。判断の理由が明確に残っていない、ということです。

審査を担当した職員のヒアリングには、こんな例があります。「障害等級の目安では2級とされていたが、カルテに症状は落ち着いていること、買い物等ができるとの記載があったほか、一般企業に一般雇用されているものの業務内容は単純作業であり、しばしば休むということを総合的に判断し、就労に制限がある状態として3級とした」。目安2級の人が、カルテの「買い物ができる」と就労の事実で3級に動いた例です。同時に、一般雇用で単純作業・しばしば休むという事実は、表2では「2級の可能性を検討する」側の材料でもあります。同じ事実が、どちらに読まれるか。それを決めるのが、診断書の記述欄と申立書に、援助や配慮や欠勤の実態がどれだけ具体的に書かれているかです。

この調査を受けて、運用は変わりつつあります。報告書は、職員が等級案を書く必要性は高くないとし、全ての不支給事案を複数の認定医が審査することとし、不支給の理由の記載を丁寧にすることとし、令和6年度以降の精神の不支給事案を点検して、必要なものは処分を取り消して改めて支給決定するとしました。点検の結果(不支給14,841件のうち444件が支給に)は、[審査請求の記事](/columns/fushikyuu-shinsa-seikyu)にあります。日本年金機構の業務実績報告でも、「医学的な総合判断を特に要する事例について複数の認定医が関与する仕組み」を続けていること、認定医会議で認定事例と基準の考え方を共有していることが書かれています。

あなたにとっての意味は2つです。一つ、目安表で2級の帯にいても、記述欄と申立書が薄ければ、下に動く。二つ、令和6年度以降に不支給だった人は、点検の対象です。通知が来ていなくても、審査請求の期限(決定を知った日の翌日から3か月)は別に動いています。
```

## A-7 FAQ(3 問追加。「Q. 目安表で2級の帯なのに…」のような既存の並びの末尾に)

```
**Q. 目安表で「3級」と出ました。障害基礎年金だとどうなりますか?**
A. 非該当です。表1の「3級」は、障害基礎年金を認定する場合には「2級非該当」と置き換える、とガイドラインに書かれています。3級があるのは障害厚生年金だけです。初診日に国民年金だった人は、判定平均と程度の組み合わせで2級の帯に入るかどうかが分かれ目になります。

**Q. 目安が「2級または3級」の帯でした。どちらになりますか?**
A. 決まっていません。ガイドラインは、目安が複数になる場合は「総合評価の段階で両方の等級に該当する可能性を踏まえて、慎重に等級判定を行う」としています。この帯では、表2の要素、つまり援助の状況・就労の実態・診断書の記述欄・申立書との整合が、そのまま結果を分けます。令和6年度に非該当になった85件のうち32件は、この帯から下に動いた事案でした。

**Q. 認定医は何人で見ているのですか?**
A. 基本は認定医1人が、職員の作った事前確認票を参考に判断します。医学的な総合判断を特に要する事例は複数の認定医が関与し、令和7年6月の厚生労働省の報告書は、全ての不支給事案を複数の認定医が審査することとしました。意見が分かれた事案は障害認定審査委員会に付議されます。
```
