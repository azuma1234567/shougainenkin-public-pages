# 就労移行支援・就労継続支援 紹介サイトの収益モデルと競合（調査メモ 2026-09-16）

障害年金サイトと並立させる「就労支援事業所を探すサイト」を作る前提で、LITALICO仕事ナビほか競合がどう稼いでいるかを一次資料（決算資料・プレスリリース・各サイト）で確認した。

## 1. 結論

- LITALICO仕事ナビは「広告業」というより **事業所向けBtoB課金のプラットフォーム**。利用者は無料。収入は (a) 事業所の定額課金（掲載＋請求ソフト等のSaaS）、(b) 成約課金（利用者獲得・採用の成果報酬）、(c) 人材紹介手数料。加えて自社の就労移行支援（LITALICOワークス164施設）への集客装置でもある。
- 事業所が広告費を払える理由は、利用者1人が公費で月17〜24万円前後（定員20名・報酬単価8,800〜12,000円/回×週5通所の概算）の収入になるから。就労移行は2年上限のフロー型で常に新規獲得が必要。だから見学1件1万円のアフィリエイト単価が成立する。
- 就労継続支援（A型・B型）は事業所数が就労移行の6〜7倍、利用者は10倍だが、1事業所あたりの広告予算は小さくアフィリエイト案件はほぼ無い。稼ぎ方は「少額の直接掲載課金」か「サイト自体の集客力を武器にした成果報酬」になる。

## 4. 就労継続支援（A型・B型）

- B型：2024年9月時点で18,094事業所・373,661人（2015年の9,698事業所から約1.9倍）。平均工賃月額17,031円（R4）、上位25%は28,377円、下位25%は6,328円と4.5倍の差。事業所が増えすぎ、都市部では利用者獲得競争が激化（Web集客の需要はある）。
- A型：2024年4月の報酬改定（生産活動収支が赤字の事業所を減点）で閉鎖が続出。2024年3〜7月で少なくとも4,279人解雇、9月時点で約5,000人。厚労省の2025年度中間評価でも、A型の求人数は前年比−1.2%、A型への就職件数は−10.3%。A型は縮小局面。
- 事業所側の懐事情：B型の報酬単価は移行より低く、広告費より相談支援事業所・病院・ハローワーク経由の紹介に依存。個別事業所からの月額課金は取れても数千円〜1万円台が現実的。
- 2025年10月から「就労選択支援」（移行かA型かB型かを利用前にアセスメントする新サービス）が開始。「自分はどれを使うべきか」という検索需要が構造的に生まれる。

## 5. 障害年金サイトと並立させる場合の示唆

1. 収益の三層：(a) 就労移行のアフィリエイト（単価高い・提携済み案件あり・首都圏大手中心）、(b) A型・B型は直接掲載の少額課金またはプレミアム枠（fukushi-navi型）、(c) 事業所向けの成果報酬「見学予約1件○円」は、サイトに送客実績が出てから交渉する。
2. 差別化は「全事業所の一次データ＋当事者目線」。厚労省の情報公表システムのデータで全国約25,000事業所のページを機械生成し（裁決例91件と同じ方法）、工賃・定着率・定員などの公表値を並べる。LITALICOも25,000施設情報を載せているが、営業契約した5,350拠点が上に来る構造。中立の当事者運営はまだ空いている。
3. 障害年金との接点は「受給しながら働く」：B型の工賃と年金の併用、A型の給与と年金の所得制限（20歳前障害基礎年金）、就労が更新に与える影響。この導線は年金サイトの幹10（受給が始まってから）とそのまま接続できる。
4. 気をつける点：企業求人の紹介まで踏み込むと有料職業紹介の許可が要る（theoriesは取得済み）。福祉サービス事業所の紹介・見学予約の取次は職業紹介ではないが、見学予約フォームを自前で持つなら個人情報の扱いを/privacyに追記する。
