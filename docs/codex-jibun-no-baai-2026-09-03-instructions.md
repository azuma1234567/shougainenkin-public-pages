# 「自分の場合を確かめる」— 5つの機能の名前・入口・見た目を作り直す (Codex 指示書, 2026-09-03)

## なぜ作り直すか(運営者の指摘、そのまま)
- `/dougu` の h1 が「道具の置き場所」になっている。これは開発中の比喩がそのまま出たもので、利用者には意味が通らない。
- トップの帯を見ても、パッと見で「何ができる機能か」が分からない。色も無く、周りの記事カードに埋もれている。
- 「等級の目安をしらべる」は、**初めて申請する人でも、国が公表している目安表に自分を当てはめて、おおよその位置が測れる**ということ。その価値が伝わっていない。
- 5つの機能は、悩んでいる人の目線で見れば**サイトの入口に置くべきもの**。いまはトップの4番目の帯にあり、ナビにも無い。
- 「公開中」のタグは要らない(準備中の段階の名残)。

## 全体方針(先に読む)
トップの h1 は「自分の場合はどうなる？」に、根拠つきで答えます、になっている。**この5つは、その問いへの直接の答え**。だから:

1. 名前は **「自分の場合を確かめる」**。誤解カード48枚の中で使っている節の名前と同じにして、サイト全体で言葉を揃える。
2. 置き場所は **hero の直下**。「はじめてですか？」より上。
3. カードの見出しは、**利用者が心の中で言っている言葉**にする。「私は何級くらい？」「いくらもらえる？」。機能名ではなく問い。
4. 色をつけて、記事カードと**別物だと一目で分かる**ようにする。
5. ナビとフッターに入れる。

URL `/dougu` と、コード内の `dougu` という識別子は**変えない**(公開済み・sitemap 収録済み・5つの検証記録が参照している。変える利益より壊す危険が大きい)。変えるのは**利用者に見える文字と見た目**だけ。

コミットは4つ。順番どおり。

## §1 言葉を全部差し替える

### 1-1 カテゴリ名
| 場所 | いま | これから |
|---|---|---|
| `/dougu` の h1 | 道具の置き場所 | **自分の場合を、確かめる** |
| `/dougu` の title / パンくず / og:title | 道具の置き場所 | 自分の場合を確かめる |
| トップの帯の見出し | 調べる道具 | 自分の場合を、確かめる |
| 各機能ページのパンくず2段目 | 道具 | 自分の場合を確かめる |
| ナビ(§3で追加) | — | 自分の場合 |
| フッターの列見出し(§3) | — | 自分の場合を確かめる |
| `data/dougu.ts` の見出し系の文字列 | 道具 | 上に合わせる |

「道具」「置き場所」「ツール」という語は、**利用者に見える文字から全部消す**。grep で `道具` を検索し、表示文字列に残っていれば直す(コードの識別子・コメント・docs は対象外)。

### 1-2 カードの文言(`data/dougu.ts` の TOOLS を書き換える)
5枚とも、`question`(見出し) / `what`(何が出るか) / `basis`(何に基づくか) / `time`(所要) の4つを持つ。文言は**このまま**使う。

| id | question | what | basis | time |
|---|---|---|---|---|
| mitate | 私は何級くらい？ | 診断書に書かれる2つの欄を選ぶと、国の目安表のどこに当たるかが出ます。 | 国が公表している「精神の障害に係る等級判定ガイドライン」の目安表。判定ではなく、公開されている基準に自分を置いてみるためのものです。 | 約3分 |
| kingaku | いくらもらえる？ | 等級・初診日に入っていた制度・家族の状況から、年額と月額を内訳つきで出します。 | 日本年金機構が公表している令和8年度の年金額と計算式。 | 約2分 |
| shorui | 何をそろえればいい？ | 7つの質問に答えると、自分の場合に必要な書類だけが並びます。持ち物と窓口で聞くことも一緒に印刷できます。 | 日本年金機構の様式と案内。 | 約3分 |
| madoguchi | どこに出せばいい？ | 初診日の制度で提出先が変わります。お住まいの市区町村から、管轄の年金事務所と予約のしかたを出します。 | 日本年金機構が公表している全国の窓口と管轄区域(2026-09-03 取得)。 | 約1分 |
| moushitatesho | 申立書を、自分で書きたい | 発病から今までを期間ごとに入力すると、公式様式に重ねて印刷できる下書きになります。 | 日本年金機構の様式(病歴・就労状況等申立書)。 | 30分から |

共通の1行(全カードの下、または帯の見出し直下に1回): **「入力した内容は、この端末の中だけで処理します。サーバーには送りません。」**

`/dougu` のリード(h1 の下):
```
「自分の場合はどうなるのか」に、公開されている基準と数字で答える5つの機能です。
どれも、国や日本年金機構が公表しているものに、あなたの状況を当てはめるだけです。このサイトが判定したり、予測したりはしません。
```

`/dougu` に「どれから使うか」の短い案内を h1 の下・カードの上に置く(3行):
```
申請を考え始めたばかりなら → 「私は何級くらい？」「いくらもらえる？」
申請すると決めたら → 「何をそろえればいい？」「どこに出せばいい？」
書き始めたら → 「申立書を、自分で書きたい」
```

### 1-3 消すもの
- `dougu-status`(「公開中」「準備中」のタグ)を表示から消す。5つとも公開済みなので不要。未公開の状態は今後も `isPublishedInternalPath` で判定し、未公開なら**カードごと出さない**(タグで表現しない)。
- カードの「01」〜「05」の番号を消す(順番は並びで分かる)。
- `/dougu` の「まだ公開していない道具は『準備中』と表示しています」の1文を消す。

コミット: `content(dougu): 「自分の場合を確かめる」に名前を改め、5つの機能を利用者の問いで言い直す`

## §2 見た目を作り直す(トップの帯と `/dougu` で共通の部品)

### 2-1 部品
`components/platform/JibunCard.tsx` を新設(いまの `DouguCard` は記事内の小さなカード用に残す。用途が違う)。

構造:
```
<a class="jc jc--{id}" href=...>
  <span class="jc-q">私は何級くらい？</span>        … 見出し。heading フォント、20〜22px、太字
  <span class="jc-what">診断書に書かれる…</span>    … 14.5px
  <span class="jc-meta">
    <span class="jc-time">約3分</span>
    <span class="jc-basis">国の目安表に当てはめる</span>   … basis を短くした1語句(下の表)
  </span>
</a>
```
`jc-basis` の短縮形: mitate「国の目安表に当てはめる」/ kingaku「令和8年度の年金額で計算」/ shorui「機構の様式に沿って」/ madoguchi「機構の管轄区域で」/ moushitatesho「公式様式に重ねて印刷」

### 2-2 色
帯全体を **`--platform-band`(#eef6fc) の背景**にして、周りの白い記事カードと切る。カードは白、**左に 6px の色の縦線**、hover で薄い同色の背景。

| id | accent | hover bg |
|---|---|---|
| mitate | `#0284c7`(= --platform-primary) | `#e8f4fc` |
| kingaku | `#059669` | `#e6f6ef` |
| shorui | `#d97706` | `#fdf3e3` |
| madoguchi | `#7c3aed` | `#f0eafb` |
| moushitatesho | `#0e7490` | `#e4f3f6` |

色は `app/platform.css` の `:root` に `--jc-mitate` 等で定義し、`.jc--mitate { --jc-accent: var(--jc-mitate) }` で当てる。見出し `jc-q` の色も accent。本文は `--platform-text`。**アイコン・イラストは入れない**(文字で十分に区別がつく。増やすと安っぽくなる)。

### 2-3 並び
- 1行目に **2枚を大きく**: 「私は何級くらい？」「いくらもらえる？」(申請を考え始めた人が最初に持つ問い)。
- 2行目に **3枚**: 「何をそろえればいい？」「どこに出せばいい？」「申立書を、自分で書きたい」。
- モバイル(≤760px)は1列、同じ順。
- `/dougu` とトップの帯は**同じ部品・同じ並び**。

### 2-4 各機能ページの上部
5つの機能ページ(`/dougu/*`)の hero に、`jc-meta` と同じ **所要時間 と 送信しません のチップ**を h1 の下に足し、一覧との連続感を出す。h1 と本文は変えない。パンくず2段目のラベルだけ「自分の場合を確かめる」に変える。

コミット: `feat(dougu): 「自分の場合を確かめる」のカードを色つきの共通部品にして、トップと一覧で揃える`

### 3-1 トップ
- 帯を **hero の直下**(「障害年金、はじめてですか？」の上)へ移す。見出し「自分の場合を、確かめる」、その下に共通の1行(送信しません)。

### 3-3 フッター

## 付記: 判断の理由(Codex は読むだけでよい)
- 「確かめる」は、48枚の誤解カードの節名として利用者がすでに見ている言葉。新しい言葉を増やさない。
- 「私は何級くらい？」という問いを見出しにしても、ページの中身は「国の目安表に当てはめる」のままで、判定はしない。問いは利用者の言葉、答えは国の基準、という分担。
- 2+3 の並びは、申請の時間順。最初の2つは「申請するかどうか」を考える段階の問いで、ここがサイトの入口になる。
