社労士事務所の掲載のご案内

最終更新日: 2026年9月16日現在の掲載料: 無料

「障害年金申請サポート」は、障害年金の申請を考えている人とその家族が読むサイトです。読者は、申請の流れ、必要書類、診断書の頼み方、自分で申請するか専門家に頼むかを、このサイトで確認してから相談先を探します。

このページは、障害年金を扱う社会保険労務士・社会保険労務士法人に向けた掲載のご案内です。掲載は現在無料です。営業の電話やメールは行っていません。掲載を希望される事務所が、このページから申し込む形にしています。

掲載の6つの特徴

  1. 読者は制度を理解してから相談に来ます。当サイトの読者は、8つのステップ、必要書類、診断書の依頼のしかたを読んだうえで相談先を探します。「障害年金とは何か」から説明する時間が減ります。
  2. 原稿は運営者が作ります。事務所の情報を6項目お送りいただければ、当サイトの型に合わせて運営者が下書きを作ります。事務所の作業は、下書きを確認して返信する1通だけです。
  3. 年金事務所のページとつながります。都道府県ごとの一覧は、当サイトの「年金事務所を探す」と相互にリンクします。提出先を調べている人が、同じ地域の事務所を見つけます。
  4. 順位づけをしません。一覧は更新日の新しい順です。おすすめ・ランキング・口コミ・星は置きません。有料の掲載枠を設けた場合も、一覧の順序は変えません。
  5. 毎月、数字をお送りします。事務所ページの閲覧数、電話番号のタップ数、事務所サイトへのクリック数を、毎月1日にメールでお知らせします。数字が小さいうちからお送りします。
  6. 紹介料・成果報酬はありません。当サイトは相談者と事務所の仲介・斡旋をしません。相談者は事務所へ直接連絡します。相談件数や受任に連動する費用は、いまも将来も設定しません。

掲載料

現在、掲載料は無料です。無料掲載の期間は、掲載開始から最低6か月です。

無料掲載に含まれるもの: 事務所ページ1枚の作成と公開、都道府県一覧への掲載、原稿の下書き作成、掲載内容の通常の更新、毎月の数字の報告。

将来、有料の掲載枠を設ける場合は、次の内容を事前にご案内します。金額、開始日、契約期間、支払方法、更新方法、掲載終了の方法。ご案内のうえで、記録が残る方法(メールまたはウェブ上の同意操作)で明示の同意をいただきます。同意なく有料に切り替えて請求することはありません。同意されない場合は、有料期間が始まる前に掲載を終了できます。先に掲載いただいた事務所には、優先してご案内します。

有料化した場合の対価は、情報掲載・原稿作成・サイト運営の役務です。相談者の紹介、問い合わせ件数、面談件数、受任、報酬額、支給結果に連動する費用は設定しません。

「対応できる相談」の9分類は、当サイトで読者が困りごとから探す入口と同じ分け方です。読者は困りごとのページから、その相談に対応できる事務所の一覧へ進みます。

  • 申請の前の相談(対象になるか、何から始めるか)
  • 初診日・受診歴の確認
  • 診断書・申立書の準備
  • 働きながらの申請
  • 家族からの相談
  • 精神の障害・発達障害
  • 身体の障害・内部の病気
  • 不支給になったあと(審査請求・再請求)
  • 更新・支給停止のあと

載せないもの

次の内容は、事務所からの希望があっても掲載しません。読者に誤解を与えないためと、社会保険労務士の広告に関する指針に沿うためです。

  • 受給率・受給実績の件数(運営者が検証できないため)
  • 「必ず」「確実」「100%」など、支給や等級を約束する表現
  • 「全国No.1」「最安」など、他の事務所との比較
  • 他の事務所を批判する表現
  • 相談者の不安をあおる表現
  • 口コミ・体験談・星の評価

掲載までの流れ

  1. 申込み。下のフォームから6項目をお送りください。フォームは事務所のメールソフトを開き、入力内容を本文にした状態で運営者宛てのメールを作ります。そのまま送信してください。
  2. 確認。運営者が社労士登録番号と所属会を公開情報で確認します。確認できない場合は掲載できません。
  3. 下書き。運営者が事務所ページの下書きを作り、メールでお送りします。申込みから5営業日以内です。
  4. 承認。下書きを確認し、直す点があれば返信してください。「これでよい」の返信をもって公開します。
  5. 公開と報告。公開したURLをお知らせします。以後、毎月1日に前月の数字をお送りします。内容の修正はいつでもメールで受け付けます。

掲載事務所へのお願い

掲載後、次の点にご協力ください。

  • 掲載内容を正確で最新の状態に保つこと(変更はメールでご連絡ください)
  • 対応できない相談を「対応できる」と表示しないこと
  • 相談者に、支援の範囲・費用・契約条件を依頼の前に説明すること
  • 障害年金の支給や等級を保証する説明をしないこと
  • 診断書について、医師に事実と異なる記載や特定の等級に合わせた記載を求めないこと
  • 相談で知った病歴・生活状況などの情報を、事務所の責任で適切に管理すること
  • 長期間問い合わせに対応できない場合は運営者へ連絡すること
  • 当サイトの名前を使って営業しないこと
