# デザイン刷新の精査メモ — /suuji を真似ない (2026-09-05)

対象の指示書 4 本を、この順で読み直した:
`stepflow-yokonarabi` → `hub-index-sasshin` → `hajimete-jitsurei-sasshin` → `top-shinsei-sasshin`。
**このメモが 4 本より優先。** 食い違う箇所は、このメモの指定に置き換える。

## §1 何を反省したか

/suuji の「数字のタイル 4 枚」を、/hajimete のヒーロー・/jitsurei のヒーロー・トップの新設セクションに**そのまま持ち込んでいた**。これは真似であって抽出ではない。同じタイル列が 3 ページの頭に並ぶと、サイト全体が別の意味で単一になる。そして /hajimete に来た人の最初の問いは「自分は対象か」「いくらか」「最初に何を」で、「年に何件決まるか」ではない。ヒーローの数字はその問いの邪魔になる。

## §2 /suuji から抽出するもの(これだけ)

| 抽出 | 中身 | 使い方 |
|---|---|---|
| A | **1 ブロック = 1 つの主張** | 1 枚のカードに、見出し・1 文・(必要なら)1 つの数字。2 つ以上の主張を同居させない |
| B | **数字には上下に文脈**(上にラベル、下に 1 行の注) | 数字を裸で置かない。「146,225件」だけでなく「新しく決まった件数 / 障害基礎+障害厚生」 |
| C | **数字の直後に、それを読み解く 1 文**(「10人のうち7人が精神の診断書で申請しています」) | 数字を見せたら、必ず読者の言葉に翻訳する文を続ける |
| D | **罫線・角丸・余白が全ページで同じ** | `--platform-border` 1px、角丸 12〜14px、カード内 padding 18〜22px、カード間 12〜14px。これを 4 ページ共通の定数にする |
| E | **色ではなく大きさで階層をつくる** | 数字 26〜30px、見出し 17〜20px、本文 14〜15px、注 12.5px |

## §3 /suuji から**持ち込まない**もの

- ページ頭の「数字タイル 4 枚」の列。**どのページにも置かない**。数字は、その数字が答えになるセクションの中に置く。
- 数字の色が primary 青であること。**数字は黒**(§4)。
- ページ全体を「1. 2. 3.」の番号見出しで並べる形。

## §4 数字は黒

- 数字(件数・割合・金額)の色は `var(--platform-heading)`(#14425e。実質の黒)。**primary 青は使わない**。
- 意味の色(`--c-ok` `--c-warn` `--c-danger`)も**数字には塗らない**。意味は左罫線かバッジで示し、数字は黒のまま。
  - 例: /jitsurei の「結論が変わった 59件」は、バッジが緑・数字は黒。
- リンクとしての数字(「21の病気 →」など)だけは、リンク色でよい。

## §5 ページごとの置き換え

### /hajimete(`hajimete-jitsurei-sasshin` §1-2 の 1 を置き換え)
- ヒーローの数字タイル 4 枚は**やめる**。ヒーローは h1 + リード + ページ内ナビだけ。
- 「なに？」の注記(146,225件・304,456件)は**いまのまま残す**(抽出 B・C を満たしている: 数字の後に「数十万人が受け取っている、めずらしくない制度です」が続く)。
- 「いくら？」の金額タイル 4 枚は**残す**。これは真似ではなく、そのセクションの問い(いくら?)への答えそのもの。数字は黒。
- ほかは指示書のとおり(3 列の高さ揃え、安心の注記に `--c-ok`、期限の注記に `--c-danger`)。

### /jitsurei(同 §2-2 の 1 を置き換え)
- ヒーローのタイル 4 枚は**やめる**。代わりに、リードの直下に**帯グラフ 1 本**(横 1 本のバーを 結論が変わった / 認められなかった で 2 色に分け、凡例に件数。抽出 B・C)。その下に 1 文「通ったものだけを並べていません。」(既存の文)。
- 「いちばん多い争点」はサイドバーの棒グラフが既にやっているので、ヒーローでは繰り返さない。
- ほかは指示書のとおり(読み方 3 タイル、絞り込み 3 群、カードの左罫線、番号つきページ送り)。

### トップ(`top-shinsei-sasshin` §1-2 の 3 を置き換え)
- 「数字で見る障害年金」セクションのタイル 4 枚は**やめる**。代わりに、**2 行の文と帯グラフ 1 本**:
  - 文: 「令和6年度、障害年金は146,225件が新しく決まり、87.0%が支給に至りました。そのうち70.3%は精神の障害の診断書によるものです。」+「数字で見る障害年金 →」
  - 帯: 支給 87.0% / 非該当 13.0%(黒の数字、帯の色は primary と `--platform-band` の 2 段階。意味の色は使わない)
  - 高さ 120px 以内。StepFlow の直下ではなく、**「探す」の直後**に置く(トップの最初の問いは「どこから入るか」なので、入口の後で実態を見せる)。
- 「探す」の型分け(チップ / 1 行リスト / 金額タイル / 2 カード)は**残す**。これは /suuji の真似ではなく、抽出 A(1 ブロック 1 主張)の適用。お金のタイルの数字は黒。
- 「悩みから」の右の小さな数字(期限 3か月 / 争点 35件 …)は**残す**。数字は黒、12.5px。

- 目次の ✓ の緑は「完了」の意味なので可。

## §6 4 ページ共通の定数(抽出 D・E を CSS にする)

`platform.css` に 1 か所で:
```
--card-border: 1px solid var(--platform-border);
--card-radius: 14px;
--card-pad: 20px 22px;
--card-gap: 14px;
--num-size: 28px;     /* 数字 */
--num-color: var(--platform-heading);
```
新しく作るカード・タイルは全部これを使う。ページごとに値を変えない。

## §7 検証に足すもの(4 本すべて)

- 新規 CSS で `color: var(--platform-primary)` が**数字要素**(`.tile strong` 等)に当たっていない(grep で確認して報告)。
- 各ページの最初の 1 画面(1400×900)に、数字が **3 つ以下**しか出ていない(/jitsurei の帯の凡例 2 つを除く)。スクリーンショットで確認。
- 4 ページのカードの角丸・罫線・padding が §6 の定数を使っている(ハードコードの `border-radius: 12px` 等が新規に増えていない)。
