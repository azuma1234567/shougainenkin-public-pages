## 1. まず広い grep を

Claude Code の grep(`Xの声|Xに|Xで|Xには`)は「Xを読むと」「という投稿もあります」を拾っていません(zaitaku の 12 行目・96 行目にあります)。7 記事の正本 md に対して次で拾い直し、全件を表にして報告してから直してください。

```
grep -nE "X(を|の|に|で|には|には|上|では)|投稿|表示され|万回|収集|リポスト|いいね" <7 記事>.md
```

「Excel」「XLSX」「FAX」など英字の一部の X は除外。

## 2. 置換ルール(この順で当てる)

| 型 | 例 | 置換 |
|---|---|---|
| A. 出どころだけの言及 | 「Xには〜という投稿が、何万回も表示されています」「Xで〜という声がありました」「Xでよく見る言葉です」 | 「〜という人が多くいます」「〜と言う人がいます」「よく聞く言葉です」。表示回数・「何万回」「2万回以上」は削除 |
| B. 発信者の属性つき | 「精神科医の人が X で〜と書いていました」「社労士の人が X で〜」 | 属性ごと落として、内容だけを地の文に。例:「患者さんの給料がいくらかなんて、知らないよ」→「医師は、患者の給料がいくらかまでは知りません。」/「社労士の人が X で『障害者雇用や合理的配慮を受けながら働いている人は、厚生 3 級で認められることがある』」→「障害者雇用や合理的配慮を受けながら働いている人が厚生 3 級で認められることは、実際にあります。」 |
| C. 「同じ X にいます」 | 「〜な人と、〜な人が、同じXにいます」 | 「〜な人と、〜な人が、同時にいます」または「どちらの人もいます」 |
| D. 「X を読むと」「X の声を読んでいて」 | 導入・h2 直下 | 「当事者の話を聞いていると」「受給者の話には」 |
| E. h2「Xの声から — …」 | 7 記事すべてにある | 「よくあるつまずき — …」に改題。ダッシュの後ろは残す。例:「Xの声から — 3級の人がつまずくところ」→「よくあるつまずき — 3級の人がつまずくところ」は重複するので「3級の人がつまずくところ — よくある5つ」の形(項目数は数えて入れる) |
| F. 出典の行 | 「- Xの投稿(当事者・社労士…)は匿名の要旨として参照(2026-09-13 収集)」 | 行ごと削除。7 記事すべてにある |
| G. 他者の数字 | koushin-hatarakinagara 22 行目「Xで『精神の更新率は99%』と書いている人がいますが、これは『止まらなかった割合』のことで、だいたい合っています。」 | 「『更新はほぼ通る』と言われることがありますが、統計の側から言えば『止まらなかった割合』が 98.9%(100 − 1.1)ということです。」 と、自サイトの数字で言い直す。「99%」という他者の数字は残さない |

置換のあと、文が「〜という声がありました。」だけで浮いていないか、前後を読み直してください。声を地の文に溶かすほうが自然な箇所は溶かして構いません(kougin の「奇数月にお金がない」は「受給者の間でいちばんよく出る悩みです」にしました)。
