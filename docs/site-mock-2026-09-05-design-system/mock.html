障害年金の初診日がわからないときの調べ方｜証明できない場合も解説

最終確認日 2026年9月3日

この記事の結論

初診日が思い出せなくても、申請はできます。制度には、証明書が取れない人のための手順(参考資料・添付できない申立書・第三者証明)が用意されています。

調べる順番は、いまの病院の記録 → 家族 → 診察券・お薬手帳 → 領収書 → 健康保険の記録 → 初診と思われる病院 → 年金事務所。1〜5は家の中と電話で済みます。

調べる順番 — 上から順にたどってください

障害年金の申請で、最初に立ちはだかり、そして最も多くの人を止めてしまうのが初診日です。昔のことすぎて、いつ・どこに行ったか覚えていない。病院が閉院していて、記録があるか分からない。

→ どこに出せばいい？管轄の年金事務所と、予約のしかた。入力はこの端末の中だけで処理します。
思い出せなくても、あきらめないでください。何月何日まで特定できなくても、請求できる取り扱いがあります。

同じ状況の人が、どうなったか

傷病・請求結論年
うつ病・新規裁定(診察券と薬袋から初診日を認定)結論が変わった令和2〜3
統合失調症・不登校時の受診を初診とする主張認められなかった令和2〜3

うつ病・双極性障害の障害年金

最終確認日 2026年9月2日

この記事の結論

うつ病でも双極性障害でも、障害年金は請求できます。新しく決まった障害年金のうち70.3%が精神の障害によるもの(令和6年度)。10人のうち7人が精神の診断書で申請しています。

数字で見る、うつ病・双極性障害の位置

項目数字
新規に決まった障害年金のうち、精神の障害によるもの70.3%
精神の障害の非該当(不支給)の割合12.1%

精神の障害だけは、国が「障害等級の目安」という表を公表していて、診断書に書かれる2つの欄の組み合わせで目安が決まります。病名では決まりません。

→ 私は何級くらい？受け取った診断書の裏面を、国の目安表に当てはめる。約3分。
不支給の通知を受け取った方は、通知を知った日の翌日から3か月以内に審査請求ができます。期限があるのは、この手続きだけです。
