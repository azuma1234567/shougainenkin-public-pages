# この読者のためのライティング技法集 (2026-09-05)

ライティングの技術そのものは新しく調べるものではない(私が持っている)。ここでやるのは、**この読者に合う技と合わない技を選び分けて、明文化する**こと。
読者像は `user-psychology-seisa-2026-09-05.md`(対象外と言われるのを恐れ、夜ひとりで、余力なく検索している人)。以後、記事・ハブ・一覧・道具の文はすべてこの技法集に従う。指示書より優先。

## §1 使う技(この読者に効く)— 12

| # | 技 | やること | 良い例(サイトの実文) |
|---|---|---|---|
| 1 | **結論ファースト(直答)** | 読者の問いに、最初の 1 文で Yes/No か数字で答える。理由は後 | 「初診日が思い出せなくても、申請はできます。」(shoshinbi-wakaranai リード) |
| 2 | **読者の状況を先に言い当てる** | 冒頭 200 字に、読者が今いる場面を 2〜3 個、読者の言葉で。「あなたはこうでしょう」ではなく、場面を並べる | 「昔のことすぎて、いつ・どこに行ったか覚えていない」(同 本文冒頭の箇条書き) |
| 3 | **PREP を段落単位で** | 1 段落 = 主張 → 理由 → 例 → 主張。段落の 1 文目だけ読めば筋が通る | 「働いていること自体は、対象外の理由になりません。ガイドラインは〜と書いています。」(hatarakinagara) |
| 4 | **見出しは文にする** | 「初診日」ではなく「初診日が2つ候補にあるときの考え方」。見出しだけ拾い読みしても記事になる(レイヤーケーキ) | shoshinbi-wakaranai の h2 全部 |
| 5 | **数字 → 翻訳の 1 文** | 統計を出したら、必ず読者の生活の単位に直す | 「70.3%」→「10人のうち7人が精神の診断書で申請しています」 |
| 6 | **具体 → 抽象 → 具体** | 制度の説明は、実例(裁決 ID)で挟む。抽象だけの段落を作らない | 「同じ状況の人が、どうなったか」の節 |
| 7 | **対の語で不安を閉じる** | 脅威語(不支給・打ち切り・対象外)は単独で置かず、同じ文か次の文で道を示す | 「『打ち切り』と呼ばれるものの多くは支給停止で、受給権は残ります」 |
| 8 | **順番を渡す** | 「何をすればいいか」は必ず番号つきの順番で。順番自体が安心になる | 「調べる順番は、いまの病院の記録 → 家族 → 診察券…」 |
| 9 | **止まり所を置く** | 長い記事には「ここまで読めば、今日は十分です」の 1 行を、答えが出た直後に | 実例ページの「自分と同じ争点の3件だけ読めば十分です」 |
| 10 | **架空の例は架空と言う** | ペルソナの例は「この記事のための架空の例です」と明記。信頼を守る | 「アキさんの初診日調査シート」 |
| 11 | **一歩だけ渡して終える** | 末尾は「次にすること 1 つ」+ 道具 1 つ + 次に読む 3 本。3 つ以上の行動を並べない | /hajimete「最初の一歩は、ひとつだけ」 |
| 12 | **社会的証明は数字で、権威は出典で** | 「多くの人が」ではなく「146,225件」。「専門家によれば」ではなく資料名+確認日 | 全記事の「出典」節 |

## §2 使わない技(一般のウェブライティングでは常套だが、この読者には逆効果)— 8

| # | 技 | なぜ使わない |
|---|---|---|
| 1 | **煽り → 解決(PASONA の Agitation)** | 不確実さに弱い読者は、煽られた不安を解決の段まで保持できず、途中で閉じる。信頼も失う |
| 2 | **損失回避の脅し**(「知らないと損」「〇〇円を失う」) | 脅威語への注意バイアスで、脅しだけが残る。期限は「始める理由」としてだけ書く(事後重症は翌月分から) |
| 3 | **希少性・緊急性**(「今すぐ」「今だけ」) | 制度に「今だけ」は無い。嘘になる |
| 4 | **クリックさせる見出し**(「〜の真実」「衝撃の」) | 見出しが内容の要約でなくなり、拾い読みが壊れる。Google の「人のための内容」にも反する |
| 5 | **断定の誇張**(「必ず」「絶対」「9割通る」) | 検証できない数字は書かない、が既存ルール。誇張は不支給になった読者への裏切り |
| 6 | **「あなたは〜な人」の決めつけ** | 判定・診断の語感。読者の状況は「場面」で並べ、断定しない |
| 7 | **感情語の連打**(「つらいですよね」「大丈夫です」の反復) | 1 回は共感、2 回目から空洞。共感は場面の描写でやる(§1-2) |
| 8 | **CTA の反復**(道具リンクを節ごとに) | 余力の無い読者には判断の回数が負担。道具は「その道具が答えになる箇所」に 1 回、末尾に 1 回 |

## §3 記事の型(読ませるページ)

```
h1(問いの形か、答えの形)
リード = 4 点の結論(1 画面目で直答が終わる)
冒頭 200 字 = 読者の場面 2〜3 個(§1-2)
─ 止まり所 ─
h2 × 6〜10(それぞれが文。見出しだけで筋が通る)
  各 h2 の中: PREP 段落 × 2〜4、必要なら番号つき手順、実例 1〜2
  2,000 字ごとに「ここまでの要約」1 段落(箱)
同じ状況の人がどうなったか(裁決 3〜4 件、通った例と通らなかった例を両方)
よくある質問(6〜8 問。画面の Q/A と JSON-LD が一致)
まとめ(箇条書き 5〜7)
次にすること 1 つ + 道具 1 つ + 次に読む 3 本
「今日はここまでで大丈夫です」
出典
```

## §4 一覧の型(選ぶページ)

- **一言は「当てはまる側」から書く**。否定で始めない。
  - 直す例: 「糖尿病そのものは対象になりにくい病気。合併症か…」→ 「合併症があるか、インスリンを使っても血糖が安定しないなら対象です。糖尿病そのものだけでは、原則、等級に該当しません。」
- 群名は「見る場所の違い」で。「精神・発達」「内部の病気」でよいが、群メモで「診断書の 2 欄で決まる」「検査値と生活の制限度で決まる」を必ず添える。
- 件数は比較のためだけ。黒、小さく。

## §5 文の規則(全ページ)

| 項目 | 規則 |
|---|---|
| 一文 | 40〜50 字まで。読点は 2 つまで |
| 一段落 | 3 文まで。段落の 1 文目が主張 |
| 漢字 | 目安 3 割。「事」「物」「時」「為」は開く。専門語は初出で言い換え(「障害認定日(初診日から1年6か月後)」) |
| 主語 | 「あなた」は使わない。「〜する人」「〜のとき」で場面を指す |
| 敬体 | です・ます。命令形は使わず「〜してください」 |
| 太字 | 本文の 1 割以下。文の途中の太字は禁止(既存ルール) |
| 数字 | 半角、3 桁区切り、単位は全角(件・円・%は半角 %)。出典に無い数字は書かない |
| 語の順 | 支給 → 非該当、継続 → 停止、できた → できなかった |
| 単独禁止の語 | 不支給 / 対象外 / 却下 / 打ち切り / 無理 / 通らない(必ず対の語と) |
| 使わない語 | 判定 / 診断 / 勝率 / 攻略 / 必勝 / 裏技 / 真実 / 衝撃 |
| 出典 | 資料名 + 発行元 + 確認日。URL は本文に出さない(既存ルール) |

## §6 離脱が起きる 5 か所と手当て

| 場所 | 起きること | 手当て |
|---|---|---|
| 冒頭 10 秒 | 自分の問いへの答えが見えない | リードの 1 点目を直答に。h1 を問いか答えの形に |
| 見出し直後 | 見出しと本文の 1 文目が噛み合わない | h2 の直後の 1 文は、h2 の答え |
| 長い段落 | 4 文以上・太字だらけ | 3 文で切る。太字を外す |
| 専門語 | 「事後重症」「認定日」が説明なく出る | 初出で括弧の言い換え。用語ページへリンクは 1 回 |
| 答えが出た直後 | 続きを読む理由が無い | 止まり所 + 次の一歩(§1-9, 11)。ここで「読み終えた満足」を作る |
