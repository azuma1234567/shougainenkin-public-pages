## §0 意味の色(共通トークン。`platform.css` の `:root` に足す)

| トークン | 文字 / 背景 | 意味 | 使う場所 |

| `--c-ok` | `#1a7f4b` / `#e9f6ee` | できる・あきらめなくていい・通った | 安心の注記の左罫線、実例「結論が変わった」のバッジと左罫線 |

## §1 /hajimete — 目的: 初めての人が「もらえる？ いくら？ まず何を？」の 3 つに答えを得て、次へ進む

### 1-1 いまの問題
- 「確認 1〜3」の 3 列が縦に長く、高さが揃わない。1 枚のカードが説明・箇条書き・注記・リンクを全部抱えている(原則 §1-1 に反する)。
- 金額が段落の中に埋まっていて、いくらなのかが一目で分からない。
- 8 セクションが同じ重さで、いま自分がどこにいるか分からない。

### 1-2 直す形
1. **ヒーロー**: h1 + intro はそのまま。その下に、このページの骨組みを **3 つの問いの帯**として出す(タイルではなく、問い→答え→リンクの 3 列。数字は黒):
   - もらえる？ → 「確認することは 3 つ」 → #checks
   - いくら？ → 「障害基礎年金 2級で年 847,300円」 → #money
   - まず何を？ → 「初診日を思い出す」 → #first
   これが目次を兼ねる(sticky にしない。1 回見せれば足りる)。
2. **なに？**: 定義の 1 文を 20px。3 つのチェックは箇条書きのまま(いまの形でよい。3 行で収まっている)。「どのくらいの人が」の注記もそのまま。**変えない**。
3. **もらえる？**(3 列): 各カードを「番号 / h3 / 説明 1 文 / 箇条書き 3 つまで / 安心の注記(`--c-ok` 左罫線) / リンク」に揃え、下端を揃える。納付要件の 4 つ目は `<details>`「もう1つ」。文は削らない。
4. **いくら？**(3 列はそのまま): 各カードの**先頭に数字を 1 つ**、原則 §1-2 の組版で。
   - 障害基礎年金: **847,300円**(単位小)/ 補足「2級・年額。1級は 1,059,125円」
   - 障害厚生年金: **635,500円** / 補足「3級の最低保障・年額。上乗せは給料と加入期間で変わる」
   - 上乗せ: **5,620円** / 補足「月額・2級。1級は 7,025円」
   既存の本文はその下にそのまま。値は `AMOUNTS_2026`。
5. 「急ぐ理由」の注記(翌月分から)を `--c-danger` の左罫線に。
6. 以降(確かめる / 時間と最初の一歩 / 4つの言葉 / 誤解 / 不安)は**変えない**。「最初の一歩」の青い面塗りパネルはページ唯一の面塗りとして残す(ここが `#first`)。
7. JSON-LD: `FAQPage` を「よくある不安」6 問で(画面と一致)。

## §2 /jitsurei — 目的: 自分と同じ争点の 3 件を見つける

### 2-1 いまの問題
- ヒーローの段落が長く太字が多い。説明カード 2 枚のうち左は下半分が空白。
- 結果(通った/通らなかった)が小さなバッジだけ。このページの唯一の主役なのに弱い。
- **争点で絞れない**。サイドバーに争点の棒が出ているのに、押しても何も起きない。
- ページ送りが前/次だけ。

### 2-2 直す形
1. **ヒーロー**: h1 + 2 文。その直下に**争点の横棒 4 本**(原則 §1-3)を置く — これがこのページの「地図」。各棒がそのまま**絞り込みのリンク**(`?filter=issue-…`)。右端に実数(黒)。棒の色は `--platform-primary`(操作できるものなので青でよい)。サイドバーの棒はここへ移す(重複させない)。
   棒の下に 1 文: 「収録 N件のうち、結論が変わったのは N件。全件、原文 PDF つき。」(N は `SAIKETSU_CASES` から。黒)。
2. **読み方**: 3 つの小タイル 1 行(番号つき)。「2 段階の不服申立て」は `<details>` に畳む(文は削らない)。
3. **絞り込みバー**(sticky): 結果(全件 / 結論が変わった / 認められなかった)・争点 4 つ・病気(精神・発達)。`rejected` と `issue-*` を新設。既存の `filter=mental` `first-visit` `accepted` と `disease` は**互換維持**。チップの文字は黒、選択中だけ青。結果の 2 つは `--c-ok` / `--c-warn` の**バッジ様式**(意味の色)。
4. **カード**: 左罫線 5px を結果の色に。バッジ 13px 太字。`h3` = 病名(18px)、下に請求種別(小)。要旨。下段に争点チップ + 「裁決の原文(PDF) →」。`id={item.id}` は維持。年(`r07`→令和7年)を meta に。
5. **ページ送り**: 番号つき(1 2 3 … 8 / 次へ)。`aria-current="page"`。
6. **サイドバー**: 「不支給の通知を受け取った方へ」(`--c-danger` 左罫線)と「申請全体の数字を見る」(/suuji へ)。棒は 1 に移したので無し。
7. JSON-LD: 表示中のカードを `ItemList`(`url` = `/jitsurei#<id>`)。
