## §1 検査6(楕円が字を含む)— 判定式が間違っている。(a) でも (b) でもない

報告の「rx ≧ 半幅×√2 **かつ** ry ≧ 半高×√2」は、**十分条件であって必要条件ではない**。
中心を共有する楕円が長方形を含む条件は、角の1点だけで決まる:

```
(a / rx)² + (b / ry)² ≤ 1        a = 字の半幅, b = 字の半高
```

√2 の式は「rx と ry を独立に見た場合」の安全側の近似で、実際より 1.4 倍厳しい。
これで測り直すと、**153件のうち大半は初めから合格**している。例:

| 欄 | a | b | rx | ry | (a/rx)²+(b/ry)² | 判定 |
|---|---|---|---|---|---|---|
| main-back:sections.0.reasons.4 | 1.86 | 1.65 | 2.6 | 2.6 | 0.91 | **○(既に含んでいる)** |

### 1-1 やること

1. `verify-moushitatesho-layout` の検査6を上の式に置き換える。マージンは右辺 `≤ 0.94`(=半径換算で約3%の余裕)。
2. それでも落ちる欄だけ、**両半径を同じ倍率 k で広げる**。
   `k = 1.03 × √( (a/rx)² + (b/ry)² )`、新 rx = k·rx、新 ry = k·ry(0.01mm に丸める)。
   縦横比を変えないので、印字に対する楕円の見え方(横長・縦長)は今のまま。
3. 広げたあと、各楕円について次を確認する(これが「隣とぶつからない」の正しい形):
   - **同じ組の他の選択肢の字の中心が、楕円の外にある**(どれを囲んだか一目で分かる)
   - 楕円が、隣の**欄の枠線**と、その欄に自分たちが書く文字の矩形に**入らない**
   隣の選択肢の字の縁に少しかかるのは**可**とする。元号の 昭和/平成/令和 は 9.2mm 間隔に 9.15mm 幅の字が並んでいて、字を含む楕円は幾何的に必ず隣にかかる。手で○を書いたときと同じ。
4. 上の 3 のどれかが満たせない欄が出たら、その欄**だけ**を止めて報告する(勝手に位置を動かさない)。

## §2 検査1と `max` — 描画インクで測り、5サンプル全部を対象にする

`max` を除外したのは、はみ出した文字のグリフが PDF の content stream に残るため。
`.mt-paper-text` は `overflow:hidden` なので、**紙に出るインクは枠の内側だけ**になっている。検査2で 300dpi の画素を正にしたのと同じ理由で、検査1も**描画された画素**で測る。そうすれば `max` も対象にできる。

- 検査1を画素ベースに変える。判定は「スロット矩形の外に、そのスロット由来のインクが無い」。
- 5サンプル全部を対象にする。`max` で落ちたら、それは clip が効いていないということなので報告。
- 印刷画面(`.mt-print-overflow`)に、**収まらなかった欄の一覧**が出ることを確認する(入力画面だけでなく印刷の直前にも見えること)。既に出ているなら現状のままでよい。RESULT に一行書く。
