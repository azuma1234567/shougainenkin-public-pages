# トップページ — ヒーローに水彩イラストを置く(2026-09-15)

画像は `public/img/top/` に置いてある(この指示と同時に入れた)。
- `hero-1600.webp`(1600×900、54KB)/ `hero-800.webp`(800×450、18KB)/ 元絵 `hero-src.png`(1672×940)
- 絵柄はアプリの申立書カードの絵と同じ手。場面は「家で、ベッドにもたれて床に座り、スマホで調べている人」。

## 1. 置き方
- `app/page.tsx` のヒーローを2列にする: 左に h1・リード・「まだ何も始めていない方は」リンク、右に画像。6枚と検索はその下(いままでどおり)。
- 900px 未満は1列: h1 → リード → **画像** → 6枚。画像は幅いっぱい、`aspect-ratio: 16/9`、角丸 14px。
- 900px 以上: 画像の列幅は 44%。左右の縦位置は中央ぞろえ。画像の `max-width` は 720px。

## 2. `next/image`
```tsx
<Image
  src="/img/top/hero-1600.webp"
  alt="家でベッドにもたれて座り、スマートフォンで障害年金の手続きを調べている人。床には書きかけの書類とペン"
  width={1600} height={900}
  priority
  sizes="(max-width: 899px) 100vw, 44vw"
/>
```
- `priority` を付ける(ヒーローの画像は LCP になる)。他の画像に `priority` を付けない。
- `alt` は上の文のまま。空にしない(飾りではなく、ページの内容を伝える絵として扱う)。
- `next.config` の `images` はいじらない。ローカルのファイルなので最適化はそのまま効く。
- 800 の方は `next/image` が自動で出す `srcset` に任せる。手で `<picture>` を組まない。

## 3. 背景と余白
- ヒーローの背景グラデーション(`p-hero`)は残す。絵の左端が白っぽいので、背景と自然につながる。
- 絵に枠線を付けない。影も付けない(水彩なので浮く)。

## 4. 検証
1. `typecheck` `build` `prelaunch:check`(全 ○)、`verify:site-graph`
2. Lighthouse(モバイル)で `/` の LCP が **2.5 秒以内**。要素が画像になっていること。変更前の LCP も同じ条件で測って `docs/verification/top-2026-09-15/lighthouse-before.json` / `-after.json` に残す
3. 390px で: h1 → リード → 画像 → 6枚 の順。横スクロール無し
4. 1400px で: 左に文、右に画像。画像は縦中央ぞろえ。リード文より高くてよい
5. `alt` が指定どおり
6. 画像のリクエストが 1 本で、モバイルでは 800 系の幅が選ばれている(DevTools の Network で確認)
7. OG 画像(`lib/seo.ts` の `OG_IMAGE`)は変えない
