## §2 ページ本文(全文。この順・この文面で)

`<h1>` 社労士事務所の掲載のご案内

`meta-line`: 最終更新日: {SITE_LEGAL_UPDATED} ／ 現在の掲載料: 無料

### 2-1 導入(h2 なし、h1 直下の段落2つ)

「{SITE_NAME}」は、障害年金の申請を考えている人とその家族が読むサイトです。読者は、申請の流れ、必要書類、診断書の頼み方、自分で申請するか専門家に頼むかを、このサイトで確認してから相談先を探します。

このページは、障害年金を扱う社会保険労務士・社会保険労務士法人に向けた掲載のご案内です。掲載は現在無料です。営業の電話やメールは行っていません。掲載を希望される事務所が、このページから申し込む形にしています。

### 2-2 h2「掲載の6つの特徴」

番号付きの6項目。各項目は太字の見出し1行＋説明2文。

1. **読者は制度を理解してから相談に来ます。** 当サイトの読者は、8つのステップ、必要書類、診断書の依頼のしかたを読んだうえで相談先を探します。「障害年金とは何か」から説明する時間が減ります。
2. **原稿は運営者が作ります。** 事務所の情報を6項目お送りいただければ、当サイトの型に合わせて運営者が下書きを作ります。事務所の作業は、下書きを確認して返信する1通だけです。
3. **年金事務所のページとつながります。** 都道府県ごとの一覧は、当サイトの「年金事務所を探す」と相互にリンクします。提出先を調べている人が、同じ地域の事務所を見つけます。
4. **順位づけをしません。** 一覧は更新日の新しい順です。おすすめ・ランキング・口コミ・星は置きません。有料の掲載枠を設けた場合も、一覧の順序は変えません。
5. **毎月、数字をお送りします。** 事務所ページの閲覧数、電話番号のタップ数、事務所サイトへのクリック数を、毎月1日にメールでお知らせします。数字が小さいうちからお送りします。
6. **紹介料・成果報酬はありません。** 当サイトは相談者と事務所の仲介・斡旋をしません。相談者は事務所へ直接連絡します。相談件数や受任に連動する費用は、いまも将来も設定しません。

### 2-3 h2「掲載料」

現在、掲載料は無料です。無料掲載の期間は、掲載開始から最低6か月です。

無料掲載に含まれるもの: 事務所ページ1枚の作成と公開、都道府県一覧への掲載、原稿の下書き作成、掲載内容の通常の更新、毎月の数字の報告。

将来、有料の掲載枠を設ける場合は、次の内容を事前にご案内します。金額、開始日、契約期間、支払方法、更新方法、掲載終了の方法。ご案内のうえで、記録が残る方法(メールまたはウェブ上の同意操作)で明示の同意をいただきます。同意なく有料に切り替えて請求することはありません。同意されない場合は、有料期間が始まる前に掲載を終了できます。先に掲載いただいた事務所には、優先してご案内します。

有料化した場合の対価は、情報掲載・原稿作成・サイト運営の役務です。相談者の紹介、問い合わせ件数、面談件数、受任、報酬額、支給結果に連動する費用は設定しません。

### 2-4 h2「掲載する内容」

表(2列: 項目／内容)。

| 項目 | 内容 |
|---|---|
| 事務所名・代表者名 | 社会保険労務士の氏名。法人の場合は障害年金を担当する社労士の氏名 |
| 社労士登録番号 | 運営者が全国社会保険労務士会連合会または都道府県会の公開情報で確認してから掲載します |
| 所在地 | 都道府県・市区町村まで。番地は任意 |
| 対応地域 | 都道府県(複数可)と、全国(オンライン・郵送)対応の有無 |
| 相談のしかた | 来所／電話／オンライン／出張、初回相談の無料・有料、土日祝・19時以降・当日の対応 |
| 対応できる相談 | 下の9分類から該当するもの |
| 得意な障害の種類 | 精神／知的・発達／内部／外部(肢体・視覚・聴覚) |
| 料金の型 | 着手金の有無、成功報酬の計算方法、不支給のときの費用、審査請求まで含むか。金額は任意 |
| 連絡先 | 電話番号、メールアドレス、事務所サイトのURL(最低1つ) |
| 一言 | 200字まで。事務所の言葉のまま載せます。運営者は添削しません |
| 更新日 | 掲載日と、内容を直した日。自動で表示します |

段落: 「対応できる相談」の9分類は、当サイトで読者が困りごとから探す入口と同じ分け方です。読者は困りごとのページから、その相談に対応できる事務所の一覧へ進みます。

9分類(箇条書き): 申請の前の相談(対象になるか、何から始めるか)／初診日・受診歴の確認／診断書・申立書の準備／働きながらの申請／家族からの相談／精神の障害・発達障害／身体の障害・内部の病気／不支給になったあと(審査請求・再請求)／更新・支給停止のあと

### 2-5 h2「載せないもの」

段落: 次の内容は、事務所からの希望があっても掲載しません。読者に誤解を与えないためと、社会保険労務士の広告に関する指針に沿うためです。

箇条書き: 受給率・受給実績の件数(運営者が検証できないため)／「必ず」「確実」「100%」など、支給や等級を約束する表現／「全国No.1」「最安」など、他の事務所との比較／他の事務所を批判する表現／相談者の不安をあおる表現／口コミ・体験談・星の評価

### 2-6 h2「掲載までの流れ」

番号付き5項目。

1. **申込み。** 下のフォームから6項目をお送りください。フォームは事務所のメールソフトを開き、入力内容を本文にした状態で運営者宛てのメールを作ります。そのまま送信してください。
2. **確認。** 運営者が社労士登録番号と所属会を公開情報で確認します。確認できない場合は掲載できません。
3. **下書き。** 運営者が事務所ページの下書きを作り、メールでお送りします。申込みから5営業日以内です。
4. **承認。** 下書きを確認し、直す点があれば返信してください。「これでよい」の返信をもって公開します。
5. **公開と報告。** 公開したURLをお知らせします。以後、毎月1日に前月の数字をお送りします。内容の修正はいつでもメールで受け付けます。

### 2-7 h2「掲載事務所へのお願い」

段落: 掲載後、次の点にご協力ください。

箇条書き: 掲載内容を正確で最新の状態に保つこと(変更はメールでご連絡ください)／対応できない相談を「対応できる」と表示しないこと／相談者に、支援の範囲・費用・契約条件を依頼の前に説明すること／障害年金の支給や等級を保証する説明をしないこと／診断書について、医師に事実と異なる記載や特定の等級に合わせた記載を求めないこと／相談で知った病歴・生活状況などの情報を、事務所の責任で適切に管理すること／長期間問い合わせに対応できない場合は運営者へ連絡すること／当サイトの名前を使って営業しないこと

### 2-8 h2「申込みフォーム」

§3 のフォーム。フォームの上に段落1つ:

入力内容は当サイトのサーバーには送られません。「メールを作成する」を押すと、事務所のメールソフトが開き、入力内容が本文に入った状態で運営者宛てのメール({CONTACT_EMAIL})が作られます。メールソフトが開かない場合は、「本文をコピーする」で本文を写し、{CONTACT_EMAIL} へお送りください。

フォームの下に `small-note`: 関連: /ads(広告掲載規約) ／ /tokushoho ／ /privacy ／ 掲載中の一覧: /sharoushi(公開後にリンク。未公開の間はこの一文を出さない)

### 3-2 ボタン2つ

- **メールを作成する**(主ボタン): `mailto:{CONTACT_EMAIL}?subject=...&body=...` を `window.location.href` で開く。件名は `【掲載申込み】{事務所名}（{所在地の都道府県}）`。本文は 3-3 の形式。`encodeURIComponent` で符号化し、改行は `%0D%0A`。
- **本文をコピーする**(副ボタン): 3-3 の本文を `navigator.clipboard.writeText`。成功したら「コピーしました。{CONTACT_EMAIL} へ貼り付けて送ってください」を2秒表示。失敗したら本文を `<textarea readonly>` に出して手動コピーできるようにする。

`mailto:` のURLが 1,800 文字を超える場合は、本文を「フォームの入力内容は下の『本文をコピーする』で取得してください」の1行に置き換え、コピー用の textarea を自動で開く(長いURLを扱えないメールソフトがあるため)。

## §4 `/ads` の変更(規約ページ)

1. 「掲載のご案内」の節(h2)を短くする。掲載枠3種の箇条書き(専門家一覧・記事内・バナー)を削り、次の2段落に置き換える:
   - 「{SITE_NAME}」では、障害年金を扱う社会保険労務士事務所の情報を、読者が相談先を選ぶ判断材料として掲載しています。現在募集している掲載枠は、専門家一覧ページの事務所ページのみです。記事内の枠とバナーは募集していません。
   - 掲載の特徴、掲載料、掲載する内容、申込みの方法は「[社労士事務所の掲載のご案内](/ads/sharoushi)」にまとめています。
2. 「料金」「お申込み」の h3 は削除(案内ページへ移す)。規約本文(1〜14)は残す。
3. 規約 第5条 の4つ目の項目を次に差し替える: 「無料掲載の場合、本条は適用されません。運営者が無料掲載を有料掲載へ切り替える場合は、金額、開始日、契約期間、支払方法、更新方法、掲載終了の方法を事前に案内し、記録が残る方法で広告主の同意を得ます。同意がない場合、有料期間の開始前に掲載を終了します。」
4. 規約 第1条 の「掲載枠」の定義は「専門家一覧ページ、記事内の枠、バナーなど」のままでよい(将来の枠を規約で縛らない)。
5. 第4条の3つ目(「掲載内容を本サイトの表記ルールに合わせて整えることがあります」)の直後に1文追加: 「運営者が下書きを作成した場合も、公開前に広告主の確認と承認を得ます。」
6. `SITE_LEGAL_UPDATED` を実装日に更新する(規約本文を変えるため)。`lib/constants.ts` のコメントどおり、アプリ側 `LEGAL_VERSION` は動かさない。
