# サイト全体のデザイン精査 (2026-09-05)

CSS 2 ファイル(4,417 行)の棚卸し、本番 6 ページの実測(計算済みスタイル・高さ・リンク数・太字数)、コントラスト計算から。
これは「どのページをどう直すか」の前に、**サイト全体に何が起きているか**を数で押さえるメモ。順序: このメモ → `user-psychology-seisa` → `page-types-seisa` → `design-seisa` → `writing-techniques` → 各指示書。

## §0 結論

サイトには**2 つの世代のデザインが同居**している。
- **旧世代**(`globals.css` の `--green/--bg/--text`、見出しは明朝 Zen Old Mincho、h1 26px): コラム 47 本、誤解 48 本の一部、法務ページ。
- **新世代**(`platform.css` の `--platform-*`、見出しはゴシック Zen Kaku Gothic New、h1 36px): トップ、ハブ 44 本、道具 5 本、実例、数字、はじめて、申請の流れ。

同じサイトの中で、**記事は明朝の h1 26px、ハブはゴシックの h1 36px**。読者は「病気から探す → うつ病ハブ(ゴシック)→ コラム(明朝)」と移動するたびに別のサイトに来たように見える。東さんが「色が単一」と感じた原因の半分はこれで、**色ではなく「型が 2 つあって、どちらも中では単調」**という状態。

数で言うと: 色 114 種、文字サイズ 98 種、角丸 24 種、影 26 種、最大幅 51 種、CSS 変数 65 個(4 系統: `--green*` / `--platform-*` / `--mt-*` / `--jc-*`)。

## §2 色

### 2-1 主色が 2 つある
- `--green: #0273ad`(旧・リンク)と `--platform-primary: #0284c7`(新・ボタン)。**わずかに違う青が 2 つ**。ボタンとリンクで色が違うのは、意図なら可だが、トークン名が `green` なのは事故の元。
- 道具ごとの色 `--jc-*` が 5 色(青・緑・橙・紫・青緑)。記事の中の道具カードで**紫の箱**が出る(madoguchi)。意味の色(緑=通った/黄=注意/赤=期限)と衝突する: 「緑の箱」が「金額の道具」なのか「安心」なのか読者に分からない。

### 2-2 コントラスト(WCAG AA、白地)
| トークン | 値 | 比 | 判定 | 使われている場所 |
|---|---|---|---|---|
| `--platform-faint` | #8aa5b6 | **2.58** | NG(小さい字は 4.5 必要) | パンくず、日付、カードのメタ、注 |
| `--platform-meta` | #6e8ba0 | **3.58** | NG | 結果件数、メタ行 |
| `--platform-subtle` | #5b7a90 | 4.53 | ぎりぎり | 注 |
| `--platform-muted` | #4a6a80 | 5.73 | OK | 説明文 |
| 白文字 on `#0284c7` | — | **4.10** | NG(ボタンの文字 14〜16px) | 「無料アプリ」「調べる」「はじめる」 |
| リンク #0273ad | — | 5.17 | OK | |

→ **メタ情報とボタンの文字が AA を満たしていない**。夜にスマホで読む読者(深層心理 §1-A)に、いちばん効く欠陥。

## §3 文字

- 本文 17px / 行送り 1.9〜1.95: 良い(デジタル庁 1.5 倍以上)。**変えない**。
- 本文の 1 行: コラム 760px ≒ 全角 44 字、ハブ 728px ≒ 43 字: 良い(40 字目安)。
- 見出し: 2 書体(明朝/ゴシック)+ 3 段階の h1(26 / 36 / 40px)。**1 書体・1 スケールに統一する**。
- 文字サイズ 98 種は、px と rem と clamp が混在しているため。スケールを 8 段に固定する(§5)。

## §5 統一の設計(デザインシステムの最小形)

`platform.css` の `:root` に 1 か所で定義し、旧トークンは**別名として残して段階的に消す**(一気に消すと 47 本が崩れる)。

### 5-1 色(11 個で足りる)
| 役割 | 値 | 備考 |
|---|---|---|
| 文字 | #1e3a4d | いまの `--platform-text` |
| 見出し・数字 | #14425e | 数字は黒(= これ) |
| 説明 | #4a6a80 | 5.73 |
| メタ・注 | **#4f6f87** | 5.31(faint/meta/subtle を**これ 1 つに**統合) |
| 罫線 | #dcebf5 | |
| 帯・箱の背景 | #eef6fc | |
| 主色(ボタン・強調) | **#0273ad** | 5.17。`#0284c7` は廃止(白文字が AA 未達) |
| 主色・濃 | #015d8c | hover |
| 意味・通った | #1a7f4b / #e9f6ee | 数字には塗らない |
| 意味・注意 | #b7791f / #fdf5e6 | |

- 道具の 5 色(`--jc-*`)は**廃止**。道具カードは主色の枠 + 道具のアイコン(文字)で区別する。

### 5-2 文字(8 段)
| 段 | px | 用途 |
|---|---|---|
| h1 | 30(モバイル 26) | 全ページ共通。書体は**ゴシック(Zen Kaku Gothic New)に統一**。明朝はやめる |
| h2 | 22 | |
| h3 | 18 | |
| 数字・大 | 28 | タイル |
| 本文 | 17 / 1.9 | 変えない |
| 小(カード説明) | 14.5 | |
| メタ | 13 | 12.5 以下を作らない |
| 注 | 12.5 | 最小。これより小さくしない |

明朝をやめる理由: 2 書体のうち、道具・ハブ・トップの全部がゴシックで、明朝はコラムだけ。読者の移動経路(ハブ → コラム)で書体が変わるのは損。明朝の「読み物らしさ」は、行送りと余白で出す。

### 5-3 形
- 角丸: 8(チップ・ボタン)/ 14(カード)/ 999(丸)の 3 つだけ。
- 影: 1 つだけ(`0 1px 3px rgba(20,66,94,.06)`)。ホバーで枠色を主色に。
- 罫線: 1px `#dcebf5`。
- カードの padding: 20px 22px。カード間: 14px。
- コンテナ: 読ませるページ 760px、選ぶページ 1200px。

### 5-4 部品の統一(1 部品 1 実装)
- 結論の箱、表、FAQ、更新日の言い方、目次、道具カード、パンくず を**それぞれ 1 つの実装**にし、コラムとハブの両方がそれを使う。
- 更新日は「最終確認日 2026年9月3日」に統一(確認日 = 出典を確認した日、という意味がサイトの信頼の根)。
- FAQ は**見出し + 段落**(アコーディオンをやめる。技法集 §2: 本文を隠さない。ただし件数が多い /gokai 一覧などは可)。

## §7 検証(2 の指示書に入れる)
- 全ページで、文字色の AA 未達が 0(faint/meta/ボタン白文字)。スクリプトで CSS の色を総当たり。
- `#0284c7` `--jc-*` `--green` の参照が 0(別名を経由する形でのみ残す)。
- h1 が全ページで同じ書体・同じサイズ(Playwright で 8 ページの computed style を比較)。
- 色の種類が 114 → 20 以下、文字サイズ 98 → 12 以下、角丸 24 → 3、影 26 → 1(棚卸しスクリプトを `scripts/verify-design-tokens.mjs` として残す)。
- コラム 1 本とハブ 1 本を並べたスクリーンショットで、見出し・箱・表・更新日が同じ見た目。
