# 社労士紹介サイトの競合分析（2026-09-16 再調査）

前回（09-01 の platform-strategy / media-platform-ads-strategy）は「弁護士ドットコム型を障害年金でやれるか」の視点だった。今回は「障害年金の社労士を探せるサイト」を実際に一つずつ開いて、運営者・掲載数・課金・法的な立て付けを揃えて比べた。当サイトの v0 計画（docs/sharoushi-keisai-v0-2026-09-04-plan.md）と料金設計メモ（docs/sharoushi-keisai-model-jukuwork-2026-09-16.md）の前提確認が目的。

## 1. 結論（5点）

1. 障害年金に絞った「社労士を探す」掲載型サイトは、実質 **2つしかない**。咲くや障害年金相談室（2020〜、Web会社運営・弁護士監修・有料広告掲載・約20事務所）と eNENKIN.net（2026年7月〜、社労士法人が自ら運営・無料掲載・9/16時点で掲載はダミー2件のみ）。残りは社労士事務所自身のサイトが「全国対応」を名乗って検索上位を占めている構図。
2. 社労士向けの課金は法規制（社労士法23条の2・27条）で **3型に収斂** している。①定額掲載（弁護士ドットコム・比較ビズ・咲くや）②応募課金（ミツモア：案件に応募する時にポイント消費、成約手数料なし）③会員制NPO（障害年金支援ネットワーク：社労士が会員として運営し電話相談→紹介）。税理士ドットコム型の成約手数料（年間報酬の50〜72%）は税理士法では可能でも社労士では使えない。当サイトの「固定の掲載料のみ」は業界の標準形で、奇抜ではない。
3. 価格の相場は **月1.4〜2万円**。弁護士ドットコムが月2万円＋初月事務手数料5万円（問い合わせ平均7.6件/月、2026年10月に改定予定）、比較ビズは旧料金で月約1.4万円（現在は要問合せ）。塾ワークの月1.75〜2.5万円とも一致する。v0 で想定した月1〜3万円は妥当。
4. どこも **数字を出していない**。掲載事務所あたりの閲覧数・タップ数を公開しているサイトはゼロ。咲くやは「累計訪問数 767万」をヘッダーに出すだけ、eNENKIN は「問い合わせ件数・相談件数を保証しない」と規約で明記。v0 §3 の月次レポート（閲覧・電話タップ・サイトクリックを毎月送る）は、それだけで差別化になる。
5. eNENKIN の本業は **社労士向けのサイト制作（sr-site.jp）** で、掲載サイトはその集客装置の可能性が高い（フッターに【広告】として自社制作サービスを掲載、運営は社労士法人じんざいポータル・大阪梅田）。しかも規約で「相談者が当法人を選んで直接契約する場合はこの限りではない」と、自らも受任すると書いている。掲載社労士から見れば競合が運営するサイトで、中立ではない。ここが当サイトの当事者運営との最大の差。

## 3. 法的な立て付けの比較（当サイトの設計確認）

| 項目 | 咲くや | eNENKIN | ミツモア | 当サイト v0 |
|---|---|---|---|---|
| 相談者→社労士の連絡 | 事務所へ直接（電話・メール） | 直接（サイト内フォームでも送信先は社労士） | プラットフォーム内チャット | 直接（電話・メール・サイトの3ボタン） |
| 課金の対価 | 広告掲載 | 情報掲載・ページ制作（有料化時） | 応募（ポイント） | 情報掲載（固定） |
| 成果連動 | 不明（非公開） | しないと明記 | しない（成約手数料なし） | しない |
| 順位づけ・おすすめ | 「オススメ 障害年金に強い社労士」枠あり | なし | 相談者が選ぶ | しない（更新日順） |
| 実績・受給率の表示 | 事務所の申告どおり | 集計方法の明示を条件に許容 | 口コミ・評価あり | 載せない |
| 数字の開示 | 累計訪問数のみ | なし | 社労士側の管理画面 | 月次レポートを事務所へ送る |

当サイトの「掲載のみ・斡旋なし・成果報酬なし・順位づけなし」は、eNENKIN が規約で書いていることとほぼ同じ。違いは (a) 運営者が社労士でも Web会社でもなく申請者側であること、(b) 数字を送ること、(c) 年金事務所・意思決定ページ（/erabu）・実例91件など「依頼するか決める前の材料」を先に持っていること。

## 4. 各社から借りるもの・借りないもの

**借りる**
- 咲くやのフラグ検索（当日相談可／出張／無料／電話／土日祝／19時以降）。v0 の絞り込みは「都道府県×障害の種類×来所/オンライン」だが、相談者が実際に気にするのは「今日話せるか」「土日か」「無料か」。フラグを6つ足す。
- eNENKIN の掲載審査項目（登録番号・所属会・個人情報の管理体制・広告表現）と「支給結果を保証しない」「診断書に事実と異なる記載を求めない」の掲載社労士向けルール。/ads の第3条に足す。
- eNENKIN の「相談分野」の切り方（申請前／初診日・通院歴／診断書・書類／働いている人／家族から／精神・発達／身体・内部／不支給後／更新・支給停止後）。当サイトの悩みハブ（/nayami）と1対1で対応するので、事務所プロフィールの「対応できる相談」をこの9分類にすると、ハブ→社労士一覧の導線が自然につながる。
- 弁護士ドットコムの有料会員の中身（注力分野・料金表・解決事例の追加掲載）。有料枠は「上に出す」ではなく「書ける項目が増える」で設計すると、一覧の順位を変えない方針と両立する。

**借りない**
- 咲くやの「オススメ」枠と「〜を見たとお伝えください」（前者は順位づけ、後者は仲介に近づく）。
- ミツモアの応募課金。相談内容をプラットフォームが受けて社労士に見せる構造は、当サイトでは相談フォームを持たない方針（v0 §7）と矛盾する。参考にとどめる。
- 税理士ドットコム型の成果報酬（使えない）。

## 5. 市場の上限の再確認

- 障害年金を主業務にする社労士事務所は、咲くや約20・支援ネットワーク約250・eNENKIN募集中、Xで発信している社労士十数名、「障害年金専門」を名乗るサイト数百、が重なり合った集合。掲載候補として現実的なのは **全国で200〜300事務所**。
- 月2万円×100事務所＝年2,400万円が、この型の現実的な天井（09-03 の ipo-feasibility-review と同じ結論）。咲くやが6年で約20事務所という事実は「集客力があっても掲載枠は簡単には埋まらない」ことを示す。
- 一方で、掲載型サイトが2つしかなく、片方はダミー、片方は6年で20件という状況は、参入の余地でもある。勝負は掲載数ではなく「社労士に依頼するか決める直前の人」をどれだけ集めて事務所に届けられるか（v0 §6 の判断ライン：事務所あたり月間閲覧50件、タップ月100件）。

3. 事務所プロフィールの「対応できる相談」を /nayami の分類に揃える。
4. 候補リスト作りの出所に、咲くやの約20事務所と支援ネットワークの会員（公開分）を加える（リストは repo に置かない）。
