## 1. A-5-6 は基準のほうを直す(判定を書き換える)

「3行まるごと」を求めたのはこちらの誤り。1行に **どこでもらうか・文書料・待ち・詰まり** を
載せているのはこの道具の値打ちそのもので、3行に収めるにはそれを削ることになる。順序が逆。

**新しい基準 A-6'**(これで ○ とする):

- 375×812 …「共通の書類」の見出しと **3件の名前**、**1件目の行はまるごと** 見える。
- 375×667 …「共通の書類」の見出しと **2件の名前**、**1件目の行はまるごと** 見える。

報告の実測(812で名前3件・まるごと2件 / 667で名前2件・まるごと1件)は、この基準を満たしている。
`docs/shorui-tool-design-2026-09-02.md` の完了条件も、この文言に書き換えること。

そのうえで、読みやすさのために2つだけ直す。

### 1-1. 待ちの文を短くする(数字を落とす)

`lib/shorui.ts` の `waitText`:

```
- "すぐには出ません。経験として、依頼から1か月近くかかることもあると語られています"
+ "その場では出ません。日数は病院に聞いてください。"
```

「1か月近く」はこちらで確認できていない数字だった。確認できない数字は書かない、が先。
落としたぶん、聞く先を書く。`scripts/verify-shorui/verify.mjs` の6番の assert も
新しい文言に合わせる(**文書料の文は変えない**。金額0件の検査もそのまま)。
`docs/shorui-tool-design-2026-09-02.md` §2-3 と §88 付近の記述も、この形に書き換える。

### 1-2. 一覧の1行目の上端を ≤300px にする(375px)

いまは 334px。≤520px のときだけ、h1 の下余白・`sr-lead` の行間と余白・`sr-top` の余白・
一覧カードの見出しの余白を詰めて 300px 以下にする。**文章は減らさない**(字を小さくするのも無し)。
余白だけで届かなければ、届いた値をそのまま報告して構わない。

## 2. A-3「本来請求」— 分岐は変えない。注記を1行足す

報告のとおり、`honrai` は `jigo`・`mitei` と同じ扱いで、`when` を増やすのは
「既存の分岐は1行も変えない」と両立しない。**分岐は変えない。** 代わりに次の2つ。

### 2-1. 「する」を選んだときの注記に1文足す

いまの「診断書が2通になります。」の文に続けて、次の1文を足す(表示だけ。分岐ではない):

> 障害認定日から1年たっていない場合は、1通で足りることがあります。年金事務所で確認してください。

診断書は1通ごとに文書料がかかる。多めに出す側の誤りでも、財布には効く。断定せずに、
確認先を書いて逃がす。

### 2-2. 到達しない値を型から消す

`honrai` は選択肢から外れて到達しない値になった。`ShoruiAnswers` の `kata` から `honrai` を消し、
`scripts/verify-shorui/verify.mjs` の5番の `["honrai","jigo","mitei"]` を
`["jigo","mitei"]` にする。**`when` の `=== 'sokyuu'` は触らない。**
型から消したことで型エラーが出る箇所があれば、そこは報告だけして直さずに止めること。

## 3. B-5-6 は並びのほうを直す(カードの中身の順番)

前の指示 B-2 で「住所・電話・アクセス・機構ページ」の順と書いたのはこちらの誤り。
この道具で人がすることは **電話で予約を取る** ことなので、電話が名前のすぐ下に来るのが正しい。

```
名前(md-n) → 電話(md-tel-row) → 〒住所・アクセス(md-a) → 取得日(md-source) → 機構ページ(md-lk)
```

`tel:` リンク・電話の注記・取得日の文言は変えない。並べ替えるだけ。
`docs/madoguchi-tool-design-*.md` に並びの記述があれば、そこも書き換える。

選び終わったあとも、都道府県と市区町村の選択欄が高さを取り続けているのが、答えが下に

- ≤520px では、選択欄が出ている状態のとき **都道府県と市区町村を横に並べる**(いまは縦)。
- 印刷では、選んだ地名(`東京都 新宿区`)が紙に出ること。選択欄は紙に出さない。
