#### #3 h2「大前提:医師は「知っていること」しか書けない」末尾に追加
```
もう一つの大前提は、医師の側にも機構からの依頼が来ている、ということです。日本年金機構の「障害年金の診断書を作成する医師の方へ」というページには、こう書かれています。

> この障害等級を適切に決定するためには、作成される診断書の内容ができる限り詳細かつ具体的に記載されていることが重要です。

記載要領の冒頭も同じで、「作成していただく診断書の内容ができるかぎり詳細かつ具体的に記載されていることが大変重要になります」と医師に求めています。あなたがメモを渡すのは、医師がこの依頼に応えるための材料を渡すことです。頼む側と書く側の目的は、最初から一致しています。
```

#### #4 h2「「頼めない」の正体を分解する」冒頭に追加
```
先に、制度の側の事実を一つ。障害年金の診断書は、医師が「書いてあげる」特別な書類ではなく、日本年金機構が様式と記載要領を定め、医師に作成を依頼している書類です。文書料が発生する、医療機関の通常業務の一つです。「頼めない」は、ほとんどの場合、制度の側の事情ではなくこちらの気持ちの側にあります。それを分解します。
```
