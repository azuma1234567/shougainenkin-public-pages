# 「私は何級くらい？」(/dougu/mitate) をゼロから作り直す — Codex 指示書 (2026-09-03)

## なぜ作り直すか(運営者の指摘)
- 最初の画面が「共用のパソコンを使っています」というセキュリティの質問。**ここで離脱する。**
- 全体が安っぽく見える(色・箱の多さ)。
- iPhone アプリを移植した作りのままで、**初めてサイトに来て「私、もしかして障害年金もらえるのかな？」と軽い気持ちで触る人**に合っていない。
- アプリの要素は捨てて、ゼロベースで。

## 変えないもの(検証済みの中身)
- `lib/mitate.ts` の計算(平均・丸め・目安表の引き方)と `data/mitate.ts` の目安表30セル・総合評価の引用25件(原本と一字一致)。**ロジックと数値は1行も変えない。**
- 判定しない。主語は「国のガイドラインでは」。確率・予測・「あなたは◯級」を書かない。
- 入力をサーバーへ送らない。
- `scripts/verify-mitate/` の検査(目安表・引用・禁止語)は残し、画面の変更に合わせて更新する。

## 誰のために作るか
**初めて来た人。診断書は持っていない。「私はもらえるのかな」と思って、軽い気持ちで押した。** 疲れていて、長い文は読めない。役所の言葉を知らない。
診断書を持っている人は二番目。入口の小さなリンクから同じ流れに入る。

---

## §1 流れ(画面の順番)

```
0 入口        … 見出し + 3つの安心 + 「はじめる」。質問はしない
1〜7 生活の7項目 … 1画面1問。ふつうの言葉で
8 全体の程度   … 1問
9 診断名(任意) … 飛ばせる
10 結果
```
**「はじめる」を押す前に何も聞かない。** 障害の種類・診断書の有無・共用PC・加入していた制度、の4問は入口から消す。

---

## §2 各画面の文言(このまま使う)

### 画面0 入口
h1: **「私は、障害年金の対象になるのかな」と思ったら**

リード:
```
精神の障害の審査では、国が公表している「等級判定ガイドライン」の目安表が使われます。
診断書に書かれる、毎日の生活の7つの項目と、全体の程度の組み合わせで、目安が決まります。
ここでは、その表にあなたの毎日を当てはめてみます。
```
3つの安心(横並びのチップ、色は使わない):
```
約3分 ／ 判定ではありません ／ 入力はこの端末の中だけ。送信も保存もしません
```
ボタン: **はじめる**

その下に小さく:
```
診断書をもう持っている方は、書かれた内容をそのまま写せます →
```
(→ `?mode=shindansho`。§4)

### 画面1〜7 生活の7項目
画面上部に細い進捗バー(1/8 〜 8/8)。1問目の上にだけ1行:
```
調子のいい日ではなく、ふつうの日を思い浮かべて答えてください。
```

| # | 質問(大きく) | 正式名(小さく、灰色) |
|---|---|---|
| 1 | 食事は、自分で用意して食べられていますか | 適切な食事 |
| 2 | 入浴や着替え、洗濯は、自分でできていますか | 身辺の清潔保持 |
| 3 | お金の管理と買い物は、自分でできていますか | 金銭管理と買い物 |
| 4 | 通院と薬は、自分で続けられていますか | 通院と服薬 |
| 5 | 人と話したり、用件を伝えたりできていますか | 他人との意思伝達及び対人関係 |
| 6 | 危ないことを避けたり、困ったときに助けを求めたりできますか | 身辺の安全保持及び危機対応 |
| 7 | 役所や銀行の手続き、近所づきあいなどはできていますか | 社会性 |

選択肢(4つ。**数値の対応は変えない**。正式な文言は選択肢の下に小さく):
| 値 | 表示 | 正式(小さく) |
|---|---|---|
| 1 | ひとりでできる | できる |
| 2 | だいたいできるが、ときどき助言や手助けがいる | おおむねできるが時には助言や指導を必要とする |
| 3 | 助言や手助けがあればできる | 助言や指導があればできる |
| 4 | 助言や手助けがあっても、できない・しない | 助言や指導をしてもできない若しくは行わない |

各画面の下に小さく「**わからない・答えたくない**」(飛ばす。回答した項目だけで平均を出す。既存の挙動)。
選ぶと自動で次へ。「戻る」は左上に小さく。

### 画面8 全体の程度
質問: **全体として、いまの生活はどれに近いですか**

| 値 | 表示 | 正式(小さく) |
|---|---|---|
| 1 | 病気はあるが、社会生活はふつうにできている | (1) 精神障害を認めるが、社会生活は普通にできる |
| 2 | 家の中のことはできるが、外の社会生活には手助けがいる | (2) 家庭内での日常生活は普通にできるが、社会生活には援助が必要 |
| 3 | 家の中の簡単なことはできるが、ときどき手助けがいる | (3) 家庭内での単純な日常生活はできるが、時に応じて援助が必要 |
| 4 | 身のまわりのことにも、多くの手助けがいる | (4) 日常生活における身のまわりのことも、多くの援助が必要 |
| 5 | 身のまわりのことがほとんどできず、いつも手助けがいる | (5) 身のまわりのことはほとんどできないため、常時の援助が必要 |

### 画面9 診断名(任意)
質問: **診断名に近いものはありますか**(総合評価の注記を選ぶために使う)
```
うつ病・双極性障害 ／ 不安障害・適応障害 ／ 統合失調症 ／ 発達障害 ／ 知的障害 ／ その他・わからない
```
「飛ばす」を大きめに。飛ばしたら共通の注記だけ出す。

### 画面10 結果

**見出し(大きく1つ)** — 既存の `mitateLookup` の結果で分岐:
- 目安あり: `国の目安表では、この組み合わせは「2級または3級」のところにあります。`(等級の文字列は表の値そのまま)
- 空欄: `国の目安表では、この組み合わせに目安が定められていません。`

**その下に1行(必ず)**:
```
これはあなたの等級ではありません。実際は、医師が診断書に書く内容と、働き方や生活の実態を合わせて、国が判断します。
```

**「これが意味すること」**(3行、結果で分岐):
- 1級 / 2級 / 1級または2級:
  ```
  国の表の上では、障害年金の対象になりうる位置です。
  次に必要なのは、初診日(その症状で最初に医師にかかった日)と、診断書を書いてもらえる医師です。
  初診日が国民年金でも厚生年金でも、1級・2級は対象です。
  ```
- 3級 / 2級または3級 / 3級または3級非該当:
  ```
  初診日に厚生年金に入っていたなら、3級があります。
  初診日が国民年金のときは3級が無いので、2級に当たるかどうかが分かれ目になります。
  分かれ目は、診断書に生活の実態がどれだけ書かれているかです。
  ```
- 空欄:
  ```
  表に目安が無いのは、対象外という意味ではありません。
  7項目の答えと全体の程度の組み合わせが珍しい、ということです。
  申請するなら、医師に生活の実態を伝えて、診断書の記載を整えてもらうところからです。
  ```

**「もし申請するなら、次に」**(3つのリンク。カードではなく行):
```
→ はじめての方へ(/hajimete)
→ 初診日がわからないとき(/nayami/shoshinbi-karute)
→ 申請の流れ(/shinsei)
```
`mode=shindansho` のときは代わりに:
```
→ 何をそろえればいい？(/dougu/shorui)
→ 申立書を、自分で書きたい(/dougu/moushitatesho)
→ 診断書で困ったとき(/nayami/shindansho-komatta)
```

**「あなたの答えは、表のここ」** — 目安表(6行×5列)全体を出し、該当セルを強調。既存のまま。表の上に1行「行が7項目の平均、列が全体の程度です」。

**「診断書では、ここも見られます」** — 総合評価の引用。**最初は3件だけ**、「もっと見る」で最大6件。引用は原文のまま(既存の検査を通す)。画面9を飛ばした場合は共通の引用のみ。

**静かな1行(黄色い箱にしない。灰色の文で)**:
```
この結果は、あなた自身の答えから出しています。実際の審査は医師の診断書をもとに行われるので、違う結果になることがあります。
```
`mode=shindansho` のときはこの行を出さず、代わりに「診断書の記載をそのまま当てはめた結果です。」

**ボタン2つ**(小さく、結果の最後):
```
この結果を、この端末に残す      印刷する
```
「残す」を押したときだけ localStorage に書く。**押さなければ何も保存しない。** 共用PCの質問は無くす。「残す」の下に小さく「共用のパソコンでは押さないでください」。

**出典** — 既存のまま。

---

## §3 消すもの
- 入口の4問(障害の種類・診断書の有無・共用PC・制度)
- 「はじめに」の節
- 「数字で見る実際」の節 → 結果の末尾に1行リンク「→ 数字で見る障害年金(/suuji)」だけ残す
- 「ガイドライン自身の留保」の節 → §2 の静かな1行と、総合評価の引用に吸収
- モードBの黄色い注記(5か所) → §2 の静かな1行(1か所)に置き換え
- 「判定平均 2.71」「7項目中7項目」のような数字の表示 → 結果の見出しからは消す。表の該当セルの強調で足りる。数字は表の下に小さく1行(「7項目の平均 2.7 × 程度(3)」)

---

## §4 診断書を持っている人の道(`?mode=shindansho`)
同じ画面1〜8を使う。違いは3つだけ:
- 入口の見出しの下に「診断書の裏面の欄を、そのまま写してください」
- 選択肢は**正式な文言を大きく**、ふつうの言葉を小さく(§2 の逆)
- 結果の「もし申請するなら」と静かな1行が §2 のとおり切り替わる
既存の「モードA」の挙動(数値の扱い)はこれと同じなので、内部のモード判定は残してよい。

---

## §5 見た目
- 色は **サイトの primary(#0284c7)1色**と灰色だけ。緑の帯・黄色の箱・グラデーションは使わない。
- 質問の文字は 22px(モバイル 20px)、選択肢は全幅のカード、高さ 56px 以上、余白を広く。1画面に見えるのは質問1つと選択肢だけ。
- 進捗バーは上端に 3px。
- 結果の見出しは白いカードに上辺 3px の primary。
- 目安表は薄い罫線、該当セルだけ primary の薄い背景。
- フォントはサイトの見出しフォント(`--font-platform-heading`)を質問と結果の見出しに。

---

## §6 検証(番号つきで全部○×。×は直さずに報告)
1. 「はじめる」の前に、質問が1つも無い
2. 「共用」という語が、入口〜画面9に出ない(結果の「残す」ボタンの下だけ)
3. 「残す」を押さない限り localStorage に書き込みが無い(Playwright で確認)
4. 7項目の値の対応(1〜4)と程度(1〜5)が既存と同じ。`verify:mitate` の目安表30セル・引用25件・禁止語0が通る
5. 既存の検算(判定「2・2・3・3・3・3・3」+程度(3) → 平均2.71 → 「2級又は3級」)が同じ結果
6. 結果の見出しに「あなたは」「相当」「通りそう」「もらえそう」「可能性」が無い
7. 画面1〜9が1画面に質問1つ。375px で横スクロールなし
8. キーボードだけで最後まで到達
9. `mode=shindansho` で正式文言が大きく出て、結果のリンクが切り替わる
10. 総合評価の引用が最初3件、「もっと見る」で最大6件
11. ネットワーク送信0件(回答を含むもの)
12. 印刷 A4 2枚以内
