**Q. 審査の状況は、ねんきんネットなどインターネットで確認できますか？**
A. 2026年9月13日時点で、ねんきんネットの機能一覧（年金見込額・年金記録・電子版ねんきん定期便・各種通知・届書の電子申請・持ち主不明記録の検索）に、障害年金の請求の審査状況を確認する機能はありません。審査の状況を知りたいときは、提出した年金事務所か、ねんきんダイヤル（0570-05-4890）に電話して、基礎年金番号と提出日を伝えて聞いてください。

**Q. 周りの人より遅い気がします。自分だけ遅いのは不支給のサインですか？**
A. 違います。期間は人によって幅があり、初診日の照会や記載内容の確認が入ると長くなります。年間45万件を超える診査を1か所（障害年金センター）で行っているため、順番待ちも起きます。遅いこと自体は結果と関係ありません。3か月を過ぎたら、上の窓口で状況を確認してください。
