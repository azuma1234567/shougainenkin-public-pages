## 印刷(2026-09-03 に条件を変更)

設計書 §13-13 の「A4 1枚」は #10「目安表の全体を常に表示する」と両立しなかった。
目安カード(判定平均・目安・目安表・制度の違い)だけで **247.9mm** あり、A4の印字領域は
**273mm**(297mm − 上下12mm)しかない。1枚に詰めるには表を畳むか字を潰すしかないため、
**表を残して A4 2枚以内**に条件を変えた。

- 印刷に載せる: 目安(目安表を含む) / 総合評価で動きうること / 留保 / 出典
- 印刷から落とす: 「数字で見る実際」「ここからできること」(画面用の導線)
- 目安表と各引用に `break-inside: avoid`
