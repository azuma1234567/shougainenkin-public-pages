# 金額の説明ルールの締め直し — 確認記録(2026-09-13)

発端: 新記事の 635,475円(3級の最低保障の誤り。公式は 635,500円)が、「月額に近い値」の規則で無関係な式に拾われて「説明済み」になり、検査で見えなかった(702c205 で訂正)。

## 何を変えたか

- `scripts/lib/amounts-derive.mjs`
  - 年額の和は「基準額(1・2級、3級最低保障、その Old)1つ + 加算(子・配偶者・給付金×12)1〜3個」か「加算だけ2〜3個」に限る。基準額どうしの和、Old と今年度の混在、×1.25、所得の線を材料にする和は使わない。
  - 加算には制度の制約: 子の1・2人目は2つまで、3人目以降はその後にだけ。配偶者加給は1つ。給付金は基準額と同じ級を1つだけ。3級の最低保障と障害手当金には加算なし。
  - 月額(÷12・÷12×2)は、段落に「月」「か月」「÷12」があるときだけ。一致は「1・10・100円で四捨五入/切り捨て/切り上げ」した値に限り、「約」などがあるときだけ 1,000円の四捨五入も許す(±100円の一律の許容はやめた)。粗い単位から当てて、丸め方を式に付記する。
  - Old の額は「昭和31年」「以前生まれ」「前年度」の段落でだけ、和・月額の材料にする(単独の値はどこでも通る)。
  - 「差」の段落だけ、基準額どうしの差(1級−2級 など)。
  - 障害手当金は一時金なので月額の元にしない。
  - `REFERENCE_AMOUNTS`(制度の額)と `STATISTICS`(統計値)は値そのものだけ通す(4番目の引数 `extra` で渡す)。
  - `contextAround`: 段落に加えて、表のセルなら見出し行を足す(Markdown の表と、`amountTextFromHtml` で平文にした HTML の表)。`amountTextFromHtml`: `<main>` を段落・箇条書き・表の行ごとに改行し、見出しセルに ⟨th⟩ を付ける。
- `data/amounts.ts`
  - `REFERENCE_AMOUNTS`: 国民年金保険料 17,920(令和8年度)、特別障害者手当 30,450(令和8年度。令和7年度 29,590 は previous)、利用者負担上限 9,300 / 37,200、特別障害給付金 1級相当 58,650・703,800、2級相当 46,920・563,040(令和8年度。令和7年度は previous)。年度・出典(URL)・確認日つき。計算機・画面表示からは参照しない。
  - `STATISTICS`: 工賃実績 B型 24,141 / A型 91,451(令和6年度)、B型 22,649 / A型 86,752(令和5年度)。`KOUGIN_REFERENCE`(道具の目安の表示)はここから値を読む。
- `scripts/lib/amounts-assumed.mjs`: 工賃+年金の概算(95,000 / 112,000 / 144,000 / 98,000)、丸めた例示(91,000、X の引用 24,000)、試算例(dougu/kingaku の 300,000 と 493,290 = 300,000 × 5.481/1000 × 300月)を式つきで宣言。
- 呼び出し側
  - `verify-columns.mjs` 検査6: metaTitle・title・description も対象に。文脈は `contextAround`。件数・人数(〜件、〜人 など)が続く数は金額として拾わない。宣言は slug が一致するときだけ、式より先に見る。
  - `prelaunch-check.mjs` A-8: `amountText`(行ごとの本文)と `<title>`・description を対象に。宣言はそのページの slug/パスが一致するときだけ式より先、他は式の後ろ。
  - `verify-gokai.mjs`・`verify-gokai-bodies.mjs`: `extra` を渡すだけ。
- 単体検査 `scripts/verify-amounts-rule.mjs`(`npm run verify:amounts` で繰上げの検査と一緒に走る)。
