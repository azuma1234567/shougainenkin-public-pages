### 検査6の判定式を直した(2026-09-04 指示書2 §1)

前回は「rx ≧ 半幅×√2 **かつ** ry ≧ 半高×√2」で見ていたが、これは**十分条件であって必要条件ではない**。
中心を共有する楕円が長方形を含む条件は、角の1点だけで決まる:

```
(a / rx)² + (b / ry)² ≤ 1      a = 字の半幅, b = 字の半高
```

√2 の式は実際より約1.4倍厳しく、153件が落ちていた。正しい式で測り直すと、直す必要があるのは
**元号と受診の系統だけ**だった。広げた倍率 k = 1.03·√((a/rx)²+(b/ry)²) は、指示書2 §1-2 の見込みとほぼ一致した。

| 欄 | 旧 rx / ry | 見込みの k | 実際の k | 新 rx / ry |
|---|---|---|---|---|
| 本紙 発病日・初診日 元号 | 5.2 / 3.0 | 1.257 | 1.257 → 微調整 | **6.6 / 3.8** |
| 本紙 期間行 元号 | 4.4 / 2.7 | 1.227 | 1.227 | **5.4 / 3.31** |
| 本紙 受診した | 9.3 / 2.8 | 1.123 | 1.119 → 1.014 の2段 | **10.56 / 3.18** |
| 本紙 受診していない | 15.5 / 2.8 | 1.172 | 1.170 → 1.009 の2段 | **18.31 / 3.31** |
| 本紙 障害認定日 元号 | 5.3 / 3.0 | 1.281 | 1.282 | **6.79 / 3.85** |
| 本紙 手帳 種類(身/精/療/他) | 2.4 / 2.4 | (表に無し) | 1.156 → 1.004 | **2.78 / 2.78** |
| 本紙 手帳 元号 | 4.4 / 2.7 | (表に無し) | 1.227 | **5.4 / 3.31** |
| 続紙 期間行 元号 | 2.5 / 1.5 | (表に無し) | 1.030 | **2.58 / 1.55** |
| 続紙 受診した / していない | 5.8・9.7 / 1.9 | (表に無し) | 1.165 / 1.201 | **6.76 / 2.21・11.65 / 2.28** |

発病日・初診日の元号だけ、k を当てても 0.01mm 丸めで動かず判定に届かなかったので rx 6.6 / ry 3.8 にした。

**しきい値について。** 指示書2 §1-1 は「右辺 ≤ 0.94」だが、同じ §1-1 の k = 1.03·√q で広げた楕円は
ちょうど q = 1/1.03² = 0.9426 に着地するので、0.94 では k を当てても永遠に届かない。
「半径換算で約3%の余裕」を素直に数式にした **1/1.03² = 0.9426** を使った(差は 0.0026)。

### 検査の作り方を設計から変えたところ(理由つき)

設計 §9-2 は「印字の矩形を PDF のオブジェクト一覧から採る」だったが、**01.pdf は
クリップされて描画されない図形を content stream に持っている**。年・月・日の空欄の中にも
黒い塗り図形(35点・23点の閉パス)の記述があり、オブジェクト一覧で判定すると
「空欄に数字を置いたら印字と衝突」という偽の結果になる。実際に描画すると空欄は白紙。

そこで検査2は **公式PDFを300dpiで描画した画素**を正にした(`scripts/verify-moushitatesho/ink.py`)。
人が紙で見るものと同じ。検査4の中心も、実文字がある欄(元号・年月日・続紙の全欄)は
実文字の矩形を、無い欄(01.pdf 裏面のアウトライン見出し)は楕円の内側のインクを使っている。

`official-glyphs.json` は記録として残してあるが、上の理由で衝突判定には使っていない。

## 検査6が × の理由(判断が要る)

長方形の字を楕円で**丸ごと**囲むには `rx ≧ 半幅×√2`、`ry ≧ 半高×√2` が要る。
設計 §4 の半径は、字の半幅・半高よりは大きいが √2 倍には足りない。

| 例 | 字の大きさ | §4 の rx / ry | 丸ごと含むのに必要 |
|---|---|---|---|
| 本紙 期間行「受診していない」 | 28.6 × 3.7mm | 15.5 / 2.8 | 20.24 / 2.63 |
| 本紙 発病日「平成」 | 9.15 × 4.94mm | 5.2 / 3.0 | 6.47 / 3.49 |

つまり §4 の楕円は、字の**中央の帯は覆うが四隅が少しはみ出す**。手で○を書いたときと同じ見え方で、
中心のずれは全件 ±0.5mm 以内(検査4は○)。**設計 §4 の数値と §9-2 の「完全に含む」が両立しない。**
数値を勝手に変えないため、× のまま報告する。
