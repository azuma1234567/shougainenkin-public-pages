### /hajimete

  まず何を？→初診日を思い出す)。目次を兼ね、sticky にしない。金額は `AMOUNTS_2026` から。
- 「なに？」は**変えていない**(定義の1文だけ大きくした)。箇条書きも「どのくらいの人が」の注記もそのまま。
- 「もらえる？」の3列を、番号 / h3 / 説明1文 / 箇条書き3つ / 安心の注記(`--c-ok` の左罫線)/ リンク に
  そろえ、下端を合わせた。納付要件の4つ目は `<details>`「もう1つ」に畳んだ(**文は削っていない**)。
- 「いくら？」に金額タイル4枚。**数字は黒**(`--c-heading`)。既存の3カードの本文はそのまま下に残した。

### /jitsurei
- ヒーローに**収録の内訳の帯**。左から「結論が変わった」→「認められなかった」
  (`user-psychology-seisa §4` の順)。帯の中に割合(65% / 35%)、凡例に名前と実数
  (結論が変わった 59件 / 認められなかった 32件)を**直接**書いた。
  その下に「収録 91件のうち、結論が変わったのは 59件。全件、原文 PDF つき。」
- 「読み方」は3つの小タイル(番号つき)。「2段階の不服申立て」は `<details>` に畳んだ(文は削っていない)。
- **絞り込みバー**(sticky)を3群に。結果(全件 / 結論が変わった / 認められなかった)・争点4つ・病気。
  `rejected` と `issue-*` を新設。チップの文字は黒、選んだものだけ青。結果の2つはバッジ様式(意味の色)。
- **カード**: 左罫線5px を結果の色に。バッジ、病名(h3)+ 要旨の1文目(小)、要旨、争点チップ + 原文PDF、
  meta に年(`r07`→令和7年)。`id={item.id}` は維持。
- **ページ送り**を番号つきに(1 2 3 … 8 / 次へ)。`aria-current="page"`。
- サイドバー: 争点の棒(押すと絞り込める)・不支給の通知(`--c-danger` の左罫線)・申請全体の数字。
- 表示中のカードを `ItemList` で出す。

### 帯グラフの色(利用者の指定)
`/suuji` と `/jitsurei` の帯・棒は、design-system 追補で登録した **`--chart-1`〜`--chart-4`**
(主色の色相200を明度で4段)を使い、**どの区分にもラベルか数値を直接**書いた。

| 場所 | 区分 | 直接書いたもの |
|---|---|---|
| /suuji 帯グラフ | 1級・2級・3級・非該当 | 帯の中に割合、凡例に名前と実数 |
| /jitsurei ヒーローの帯 | 結論が変わった・認められなかった | 帯の中に割合、凡例に名前と実数 |
| /jitsurei 争点の棒4本 | 障害の程度・初診日・診断書・納付要件 | 棒の脇に名前と件数 |

意味の色(`--c-ok` / `--c-warn` / `--c-danger`)は、左罫線・バッジ・チップだけに使い、
グラフと数字には塗っていない。

## 指示書と違えたところ(優先順位に従った)

1. **「いくら？」は金額タイル4枚**にした。改訂2 §1-2-4 は「3列カードの先頭に数字を1つ」だが、
   `design-seisa §5` が「『いくら？』の金額タイル 4 枚は**残す**」とし、site.html の
   /hajimete ボードもタイル4枚。優先順位に従って seisa と site.html を採った。数字は黒。
2. **/jitsurei の争点の棒はサイドバーに残した**。改訂2 §2-2-1 は「ヒーローへ移す」だが、
   site.html の /jitsurei ボードは**ヒーローが結論の帯・サイドバーが争点の棒**で、
   `user-psychology-seisa §4` も「帯は『結論が変わった』を左に」と帯を前提にしている。
   ヒーローは帯、サイドバーは棒(押すと絞り込める)にした。
3. /jitsurei のリードは**4文のまま**(改訂2 §2-2-1 は2文)。§3「本文の文は変えない」を優先。
   /hajimete の導入も3文のまま。
4. 定義の1文は「20px」の指定だが、8段の文字サイズに20pxが無いので `--fs-h2`(22px)に寄せた。
