verify:hubs は 2 本に分かれる。verify-hub-content(サーバー不要)と verify-hub-map(origin を引数で渡す)。
node --import ./scripts/lib/ts-alias.mjs scripts/verify-hub-content.mjs → exit 0
node scripts/verify-hub-map.mjs http://localhost:3210 → exit 0
(npm run verify:hubs は verify-hub-map が localhost:3000 固定なので、検証サーバー 3210 では個別に実行した)
