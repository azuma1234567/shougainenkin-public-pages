## モックから変えたところ(4点)

1. **制度が未選択のときの理由文**。モックは `seido:null` の初期状態で報酬比例部分に「初診日が国民年金のため、報酬比例部分はありません」、配偶者加給に「障害基礎年金に配偶者の加算はありません」と出る。まだ何も選んでいない人に事実でないことを言うので、未選択のあいだは「初診日に入っていた制度を選ぶと計算します」「—を選ぶと分かります」に差し替えた(§2-1「受給できるかを判定しない」)。制度を選んだあとの文言はモックのまま。
2. **未実装の道具へのリンク**。`/dougu/mitate`(等級の目安)と必要書類チェックリストはまだ無いので、404 を作らないようリンクにせず「準備中」と出す(`/dougu` の一覧と同じ扱い)。実装後にリンクへ戻す。
3. **モバイルの文字サイズ**。年額の 40px を `clamp(28px,8vw,40px)`、月額の 20px を `clamp(17px,4.6vw,20px)` にした。モックはデスクトップ基準で、375px では 4,385,728円 が横にはみ出すため(§0.5「375pxで崩れないことは実装側で担保」)。
4. **数値欄の下限**。モックには無い `min={0} step={1}` を付け、欄の段階で0以上の整数に丸める。加入月数にマイナスが入ると 300月みなしの式が `× 300 ÷ (負の月数)` になり、「300月として計算しています」と出しながら0円を返すため。§4の式そのものは変えていない。

- `/dougu` の noindex と `lib/published-links.ts` の `UNPUBLISHED_PATHS` はそのまま。`app/dougu/page.tsx` 冒頭のコメントにある「道具が入ったら外す」作業は、申立書ツールの検証と合わせて別に判断する。`/dougu/kingaku` も申立書ツールと同じく noindex で入っている。
