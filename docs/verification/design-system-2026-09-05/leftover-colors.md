# 寄せなかった色の一覧(2026-09-05)

指示書 `docs/design-system-2026-09-05-instructions.md` §1-2 の
「判断に迷うものは残して報告」。**勝手に決めずに残した色**をここに全部書く。

画面の CSS(`app/globals.css` + `app/platform.css`)に直接書かれた色は
**109種 → 10種**になった(2026-09-05 の追補で図表の色をトークンにして 15 → 10)。
白(`#fff`)とトークンの定義を除くと、残りは次の2群。

## 1. 図表の色(4) — **2026-09-05 追補で決着**

`--chart-1` 〜 `--chart-4` として、許容一覧に「図表の色」で登録した。
主色 `#0273ad` の**色相(200)を明度で4段**にしたもの。

| トークン | 値 | 使い場所 |
|---|---|---|
| `--chart-1` | `hsl(200 92% 22%)` | /suuji 1級・更新の継続 / /jitsurei 障害の程度 |
| `--chart-2` | `var(--c-primary)` | 2級・増額改定 / 初診日 |
| `--chart-3` | `hsl(200 62% 62%)` | 3級・減額改定 / 診断書 |
| `--chart-4` | `hsl(200 47% 84%)` | 非該当・支給停止 / 納付要件 |

区分の「多い/少ない」ではなく、**並び順を濃さで表すためだけ**に使う。
意味の色(`--c-ok` `--c-warn` `--c-danger`)とは混ぜない。

**色だけに意味を持たせない**ため、どの区分にもラベルか数値を直接書く:
- /suuji の帯グラフ: 帯の中に割合(10.9% / 53.9% / 22.1% / 13.0%)、下の凡例に名前と実数。
  帯の中の文字は濃い2段が白(9.50 / 5.18)、淡い2段が `--c-heading`(4.74 / 7.53)で AA を満たす。
- /jitsurei の棒グラフ: 棒の脇に争点名と件数。

色数の上限は 11 → **16**(11色 + 図表4段 + `--c-warn-text`)に更新した。
`node scripts/verify-design-tokens.mjs` は `--chart-1`〜`4` が定義されているかも見る。

## 2. 濃い地の上に重ねる白の透過(6) — 色ではなく「重ね方」

| 値 | 使い場所 |
|---|---|
| `rgba(255,255,255,0.1)` | `.site-nav a:hover` / `.site-footer a:hover` |
| `rgba(255,255,255,0.08)` | `.site-footer a:hover` |
| `rgba(255,255,255,0.16)` | フッターの区切り線 |
| `rgba(255,255,255,0.25)` | フッターの設定ボタンの枠 |
| `rgba(255,255,255,0.7)` | サイト名の hover の下線 |
| `rgba(255,255,255,.13)` | `.shinsei-app` のラベルの地 |

いずれも「白を N% 重ねる」指定で、パレットの色ではない。
トークン化するなら `--overlay-1 〜 3` のような別系統になるので、残した。

## 4. 印刷 CSS の色(17) — §5 で「触らない」と決めた領域

`@media print` / `@page` / `.mt-paper*` の中にある色は、指示書 §5 のとおり
1つも触っていない。棚卸しでも別に数えている(`node scripts/verify-design-tokens.mjs`)。

`#000000` `#111111` `#333333` `#999999` `#bbbbbb` `#e6e6e6` `#8db4c9` `#21455b33`
`#f0c9c4` `#6b2d26` `#f0e2bd` `#fdf3dd` `#6b5316` `#eef7fc` `#fdf1ef` `#b3261e` ほか。

## 5. `--c-warn` を文字に使わない(2026-09-05 追補で決着)

指示書 §0 の `--c-warn: #b7791f` は、**文字として使うと白地 3.64・帯地 3.33** で
AA(4.5)に届かない。

| 候補 | 白地 | 帯地 | 注意の地(#fdf5e6) |
|---|---:|---:|---:|
| `#b7791f`(§0 の値。左罫線とバッジの地に使う) | 3.64 | 3.33 | 3.36 |
| **`#8b6a1f`(`--c-warn-text`。文字に使う)** | **5.02** | **4.60** | **4.64** |

**決めたこと**: `--c-warn` は §0 の値のまま。**`color:` には使わない**(左罫線・バッジの地・
枠線だけ)。文字は `--c-warn-text` を使う。`verify-design-tokens.mjs` が
`color: var(--c-warn)` の数を数え、0でなければ×にする。

参考: `--c-ok`(#1a7f4b)は白地 5.02、`--c-danger`(#b3261e)は 6.54 で、
どちらも文字に使って問題ない。文字色で足りないのは注意の色だけ。
