## 公的資料との照合

1. **事後重症請求の期限** — 日本年金機構「障害厚生年金の受給要件・請求時期・年金額」で「65歳の誕生日の前々日までに提出」と照合。本文の「65歳に達する日の前日（=誕生日の前々日）まで」と一致。
2. **はじめて2級** — 日本年金機構「国民年金・厚生年金保険 障害認定基準」第1章第7節で「65歳に達する日の前日までの間」と照合し、本文と一致。
3. **60〜65歳の未加入期間の特例** — 日本年金機構の受給要件で「日本国内に住んでいる60歳以上65歳未満で年金制度に加入していない期間」と、別途保険料納付要件が必要なことを照合。本文と一致。
4. **65歳以後の組み合わせ** — 日本年金機構「年金の併給または選択」「障害年金と他の年金の調整」で、障害基礎年金＋老齢厚生年金、障害基礎年金＋遺族厚生年金が選べることを照合。本文と一致。
5. **繰上げ後の制限** — 日本年金機構「年金の繰上げ受給」で、繰上げ請求日以後は事後重症などによる障害基礎・厚生年金を請求できないことを照合。本文と一致。
6. 学生納付特例の休学時と国民健康保険料の扱いは、原稿どおり断定せず、窓口確認の案内を維持した。
