## §1 なぜ作るか
Search Console の実測で、**このサイトのクリックの67%が申立書まわりの2記事**です(`docs/metrics/baseline-2026-09-02.md`)。人が詰まっているのは制度の理解ではなく**書類の実務**だと、数字が言っています。

競合の「必要書類一覧」は全部**静的な記事**です(`docs/feature-gap-analysis-2026-09-02.md`)。読んだ人は「で、自分の場合はどれ?」で止まります。20歳前かどうか、配偶者や子がいるか、さかのぼるかで、必要な書類は変わります。

あわせて「**年金事務所へ行く日の持ち物**」を同じ紙に載せます。「相談 持ち物」が Search Console で **11〜12位**。あと少しで1ページ目です。

## §2 絶対条件
1. 入力をサーバーへ送らない。AIを使わない。
2. **文書料の金額を断定しない。**病院ごとの自由料金で、公的な統計がありません。「病院ごとに決まっています」と書く。
3. **待ち日数を断定しない。**「経験として語られている」形で書く(サイトの既存の書き方に合わせる)。
4. **「これで全部です」と言わない。**最後に必ず「年金事務所で最終確認してください」を置く。制度は変わり、窓口で追加を求められることがあります。
5. 様式番号・正式名称は、**日本年金機構の公式ページから転記して照合する**(§6)。

## §3 質問(7問。すべて任意、飛ばせる)

| 1 | 初診日に入っていた制度 | 国民年金 / 厚生年金 / わからない |

## §4 分岐ルール
```
常に:            年金請求書 / 病歴・就労状況等申立書 / 診断書 / 基礎年金番号がわかるもの
                 受取先の口座がわかるもの / 本人確認書類
Q5=違う or 不明 → 受診状況等証明書
Q5=違う かつ カルテが無いと分かっている → 受診状況等証明書が添付できない申立書 + 参考資料 + 第三者証明
Q3=遡及        → 診断書が2通(障害認定日ころ・現在)
Q6=子がいる    → 戸籍謄本 / 住民票 / (高校生の子)在学証明書か学生証の写し
Q6=配偶者      → 戸籍謄本 / 住民票 / 配偶者の所得を証明するもite
                 ※ ただし加算は障害厚生年金1・2級のみ。Q1=国民年金なら「加算はつきませんが、書類が要る場合があります」と注記
Q2=20歳前      → 本人の所得を確認する書類(所得制限があるため)
Q7=はい        → 第三者行為事故状況届 ほか
Q1=厚生 かつ 共済の加入歴がありそう → 年金加入期間確認通知書
Q4             → 診断書の様式が決まる(§6で照合)
```

## §5 出力(1枚の紙になること)
1. **そろえる書類**(チェックボックスつき)。各項目に:
   - どこでもらうか(病院 / 年金事務所・市区町村 / 自分で書く / 役所)
   - お金がかかるか(**金額は書かない**。「病院ごとに決まっています」等)
   - すぐ出ないもの(診断書は「経験として、依頼してから1か月近くかかることもあると語られています」)
   - よくある詰まり(1行)
2. **年金事務所へ行く日の持ち物**
3. **窓口で聞くこと**(定型リスト。§7)
4. **印刷ボタン**。A4 1枚。チェックボックスは空欄で印刷される(手で書き込める)
5. チェック状態は localStorage に保存。「共用のパソコン」なら保存しない

## §6 様式の照合(必ず実行)
`https://www.nenkin.go.jp/shinsei/jukyu/shougai/` 配下の公式ページから、次を転記して照合する。**モックの値は暫定**です。
- 年金請求書の様式番号と正式名称
- **診断書8種の様式番号と、どの障害に使うか**(モックでは番号を書いていない。ここを埋める)
- 受診状況等証明書 / 同・添付できない申立書 / 第三者証明 の正式名称
- 各様式のダウンロードURL(**公式へ直リンクする。PDFを自サイトに置かない**——古い様式が残る事故を防ぐため)
違いがあればすべて報告すること。

## §7 窓口で聞くことの定型リスト(そのまま実装)
- 私の初診日は、この日で問題ありませんか
- 納付要件は満たしていますか(記録を見てもらう)
- 診断書はどの様式になりますか
- さかのぼる請求と、いまの請求の**両方の形で出せますか**
- この書類で、足りないものはありますか
- 提出したあと、結果はいつごろ、どう届きますか
- 年金生活者支援給付金の請求書は入っていますか

## §8 完了条件(○×で報告)
1. `/dougu/shorui` が動く。`/dougu` から行ける。
2. 7問すべて飛ばせる。飛ばすと「共通の書類」だけが出る。
3. §4 の分岐がすべて動く(7パターンを手で確認して報告)。
4. **国民年金 × 配偶者あり** のとき、「加算はつきません」の注記が出る。
5. **遡及**を選ぶと、診断書が2通になる。
6. 文書料の**金額が1つも書かれていない**(grep で確認)。
7. 様式のリンクが**すべて機構の公式URL**を向いている。自サイトにPDFを置いていない。
8. 印刷でA4 1枚に収まり、チェックボックスが空欄で出る。
9. 「年金事務所で最終確認してください」が結果と印刷物の両方に出る。
10. チェック状態が保存され、再訪で復元される。「共用のパソコン」なら保存されない。
11. ネットワーク送信0件。モバイル375pxで横スクロールなし。

## 執筆メモ(サイトに載せない)
- 文書料を書かないのは、公的な統計が無く、病院ごとに数千円の幅があるため。数字を書くと必ず「違った」が起きる。誠実宣言と、この道具の信用の両方に関わる。
- 様式PDFを自サイトに置かないのは、様式が改定されたときに古いものが残るため。機構へ直リンクするのが唯一の正しい方法。
- 「窓口で聞くこと」を入れたのは、この道具のいちばんの価値がここだから。書類を並べるだけなら記事でできる。**窓口で何を聞けばいいか分からないまま行って、聞かずに帰ってくる**のが、いちばん多い損失。
