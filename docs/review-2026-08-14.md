### P1-1. `・` `□` で始まる行が、1行に連結されて表示されている（10記事60箇所）

**症状** — `MarkdownArticle.tsx` は空行までを1段落とみなし、`paragraphLines.join(" ")` で
**半角スペースを挟んで連結**する。そのため、原文で改行して書いた `・` や `□` の行、
住所、週ごとのタイムラインが、すべて1本の長い段落として描画されている。

例（`teishutsusaki-yuusou`）— 宛名の3行が1行につながる:

```
〒◯◯◯-◯◯◯◯ ◯◯県◯◯市◯◯町◯-◯-◯ 氏名 ◯◯ アキ
```

**修正方針** — 原文側を直す。`・` `□` で始まる連続行は Markdown の `- ` リストに変換する。
`**ア.**` `**4月第3週**` のような見出し付きの列挙は、`- **ア.** …` の形にする。
`MarkdownArticle.tsx` 側で `<br />` を挿入する対応は取らないこと。
現在 618 箇所ある「太字の見出し行 + 本文」の連結（`**1. 電話と外出の回数**⏎本文`）は
半角スペースで繋がるのが正しい挙動で、そちらまで改行されてしまうため。

**受け入れ基準** — 下のリスト（付録A）の60箇所がすべて `- ` リストになっていること。
変換後に、リスト項目の先頭に `・` が二重で残っていないこと。

### P2-1. 横スクロールする表に、スクロールできることを示す手がかりがない

**症状** — `.article-table-wrap` は `overflow-x: auto` だが、視覚的な手がかりが何もない。
`8337e36` の修正後も、3列以上の表（17件）はスマホで横スクロールが必要なまま。
またスクロール領域が `tabindex` を持たないため、**キーボードだけでは中身を読めない**（WCAG 2.1 の
「キーボード操作可能」に抵触する）。

**修正方針** — `components/MarkdownArticle.tsx` の `.article-table-wrap` に以下を付ける。

```tsx
<div
  className="article-table-wrap"
  role="region"
  aria-label="表(横にスクロールできます)"
  tabIndex={0}
>
```

あわせて `app/globals.css` に、右端が切れていることが分かる手がかりを足す
（右端のグラデーション、または表の直前に「→ 横にスクロールできます」の注記）。

**受け入れ基準** — 3列以上の表で、Tabキーでスクロール領域にフォーカスが当たり、
矢印キーで横スクロールできること。フォーカスリングが見えること。

## 付録B. 文体の判定スクリプト

```python
import re, json, glob, os

def load(path):
    t = open(path, encoding='utf-8').read()
    m = re.search(r'const content = ("(?:[^"\\]|\\.)*");', t, re.S)
    if m:
        return json.loads(m.group(1))
    m = re.search(r'const content = `(.*?)`;\n', t, re.S)
    return m.group(1)

for f in sorted(glob.glob('content/columns/*.ts')):
    t = load(f)
    sents = [s for s in re.split(r'(?<=。)', t)
             if s.strip() and not s.strip().startswith(('#', '|', '-', '>'))]
    polite = sum(1 for s in sents
                 if re.search(r'(です|ます|ません|でした|ましょう|ください|ませんか)。$', s.strip()))
    print(f"{os.path.basename(f)[:-3]:32} です率 {polite / len(sents) * 100:3.0f}%")
```
