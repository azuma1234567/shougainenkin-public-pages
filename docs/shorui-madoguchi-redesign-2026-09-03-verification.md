### A-3 の報告: 「本来請求」を選択肢から外した件

`kata` を見ている分岐は次の2か所だけで、どちらも `=== 'sokyuu'` である。

- `data/shorui.ts:93` `shindansho2` の `when: (s) => s.kata === 'sokyuu'`
- `lib/shorui.ts:55` `showSokyuuNote = (s) => s.kata === "sokyuu"`

つまり **`honrai` は `jigo`・`mitei` と完全に同じ扱い(診断書1通)** で、`sokyuu`(2通)とは違う。
`scripts/verify-shorui/verify.mjs` の5番も `["honrai","jigo","mitei"]` で2通目が出ないことを検査していて、これは今も通る。

指示書 A-3 は「違えば『する』の中で分ける」とあるが、**分けるには `when` を増やすことになり、
「既存の分岐は1行も変えない」と両立しない。** そこで今回は分けず、次の状態にした。

- 選択肢から「本来請求」を外しただけ。`ShoruiAnswers` の型からは消していないので、`honrai` は**到達しない値**になった。
- 認定日に近い時期に請求する人が「する」を選ぶと、診断書が2通の表示になる(実際には1通で足りることがある)。
  逆に「しない」を選ぶと1通の表示になる。**どちらを選んでも書類が足りなくなる向きの誤りは出ない**が、
  「する」側は多めに出る。画面には「これで全部とは限りません。最後は年金事務所で確認してください。」が常に出ている。

**分岐を変えてよいなら**、`kata` に「認定日から1年以内」の値を足して `shindansho2` の `when` を分けるのが素直。
判断は azuma に委ねる。

### A-5-6 が × の理由

上の余白ではなく、1行の高さが原因。ヘッダー・h1・1行の説明・カードの見出しを詰めて、
一覧の1行目の上端は 359px → **334px** まで下げた(≤520px の詰めも入れた)。それでも1行が 150〜250px ある。

内訳(375px、診断書の行): 名前17 + 様式リンク16 + どこでもらうか・文書料・待ちの3点85 + 「種類を選ぶと様式が決まります」22 + 詰まり46。
このうち **文書料と待ちの断り書きは設計書 §2-2/§2-3 の絶対条件**(verify:shorui の6番が見ている)で、落とせない。

断り書きか詰まりの1行を畳まないと届かない。**指示書に無い畳み方を勝手に足さず、× のまま報告する。**
