# 「いくらもらえる？」(/dougu/kingaku) を答えが先に見える形に作り直す — Codex 指示書 (2026-09-03)

## なぜ作り直すか(運営者の指摘)
上から見ていくと「入力」の大きなカードで、6問(等級→制度→子→配偶者→平均標準報酬額→加入月数)に答えたあと、下にやっと「計算の結果」。**数字が見えるまで、知らない項目に答えながらスクロールする。** 平均標準報酬額と加入月数は、ほとんどの人が知らない。全部同じ青で、どこが答えか分からない。

## 変えないもの
- `lib/kingaku.ts` の計算(§4 の式・300月みなし・1.25倍・3級最低保障・給付金)と `data/amounts.ts`。**1行も変えない。**
- 設計書 §7 の但し書き4つ(概算・従前額保障 / 4月改定と令和8年度 / 他制度との調整 / 非課税と扶養)は必ず出す。
- 未入力の報酬比例は「—」(0円にしない)。3級に基礎年金・子の加算・配偶者加給が無いこと。国民年金×3級を選べないこと。
- `verify:kingaku` の12項目は通し続ける(画面の変更に合わせて更新)。

## 誰のために作るか
「働けない間、いくら入るのか」を知りたい人。**まだ申請していないので等級は分からない。自分の平均標準報酬額も知らない。** 知っているのは、会社員だったか・子どもがいるか・配偶者がいるか、だけ。

## §2 文言(このまま使う)

### 答えの箱(常に最上部)
- 数字: 年額を大きく(28〜40px)、月額をその横に。「約」は月額だけ。
- 1行の説明は状態で変わる:
  - 国民年金・単身・2級(既定): 「障害基礎年金 2級・単身の場合(いちばん多いケース)」
  - 会社員(厚生年金)で報酬比例未入力: 「障害基礎年金 2級 + 障害厚生年金。**給与からの上乗せは、下で計算すると足せます**」
  - 3級 + 会社員 + 報酬比例未入力: 「3級は障害厚生年金だけです。給与からの上乗せを下で計算してください(最低保障 年635,500円)」→ 合計は「—」のまま(既存 §9-7)
  - 「わからない」を選んだとき: 「初診日に入っていた制度で変わります。まず国民年金の額を出しています」
- 等級の切替の下に小さく: 「まだ分からない方は2級で見てください。新しく決まる人の53.9%が2級です(令和6年度)」

### 3問
| 質問 | 選択肢 | 内部 |
|---|---|---|
| 初診日のとき、会社員でしたか(厚生年金) | はい / いいえ / わからない | seido = kousei / kokumin / null(既定の表示は kokumin と同じ計算で、説明だけ変える) |
| 18歳までの子ども | いない / 1人 / 2人 / 3人以上 | kids 0/1/2/3(3人以上は3で計算し、「4人目以降は1人81,300円ずつ増えます」を1行) |
| 65歳未満の配偶者 | いる / いない | spouse。**「はい(会社員)」のときだけ表示**。国民年金のときは質問自体を出さない(加算が無いため。内訳の行に理由は出る) |

3級を選んだとき、「会社員でしたか」の「いいえ」を選べなくする(既存 §9-3)。その場合の1行: 「3級は厚生年金だけの等級です」。

### 折りたたみ「給与からの上乗せを計算する」
- 会社員「はい」のときは**最初から開いておく**。「いいえ」「わからない」のときは閉じて、見出しだけ。
- 中身は既存の入力(平均標準報酬額・加入月数・平成15年3月以前の分)。ラベルから「5.」「6.」の番号を消す。
- 「平均標準報酬額が分からない」は折りたたみではなく、入力欄の直下の1行にする(§1 の文言)。

### 「知っておくこと」(灰色の文、4行、既存の §7 の内容をそのまま)

## §3 消すもの
- 「入力」という見出しと、その大きなカード
- 項目の番号「1.」〜「6.」
- 黄色の警告箱(`kg-warnbox`) → 灰色の1行
- 「計算の結果」という見出し(答えが最上部にあるので不要)

## §4 見た目
- `/dougu/mitate` と同じ: primary(#0284c7)1色と灰色。答えの箱だけ白地に上辺 3px の primary。数字は見出しフォント。
- 3問はチップ(既存の `kg-chips`)。選択中は primary の枠、他は灰色。
- 内訳の表は薄い罫線。0円の行は灰色。
- 375px で、**答えの数字が最初の画面内に見える**(スクロールなしで年額が見えること)。
- 数字は `aria-live="polite"` で、選択を変えたときに読み上げられる。

## §5 検証(番号つきで全部○×。×は直さずに報告)
1. ページを開いた直後に、何も選ばなくても年額 847,300円・月 約70,600円 が出ている(2級・単身の既定)
2. 375px で、スクロールせずに年額が見える
3. 3問の並びが 会社員→子ども→配偶者。配偶者は会社員「はい」のときだけ
4. 等級の切替の下に 53.9% の1行がある
5. 会社員「はい」で折りたたみが開き、報酬比例未入力のあいだは内訳の報酬比例が「—」、答えの説明が「上乗せは下で計算すると足せます」
6. 120月・30万円・2級 → 報酬比例 493,290円(既存の検算)
7. 3級で「いいえ」が選べない。3級・国民年金の組み合わせが作れない
8. 3人以上を選ぶと3人で計算され、「4人目以降は…」の1行が出る
9. `verify:kingaku` の12項目が○
10. 「1.」「入力」「計算の結果」「kg-warnbox」が無い
11. 回答内容を含む送信0件。金額の直書き0件(data/amounts.ts 経由)
12. キーボードだけで3問と等級を切り替えられる。数字の変化が aria-live で伝わる
