## リード(直答)
「65歳を過ぎたら、障害年金は関係ない」。これは誤解です。障害年金の受給に年齢の上限はありません。65歳以降も、厚生年金に加入して働いている間に初診日があれば、障害認定日による請求ができます。

ただし、**期限がある手続きと、取り返しのつかない決断**がこの年代に集中します。事後重症請求は65歳の誕生日の前々日まで。「はじめて2級」の請求も65歳に達する日の前日まで。そして、老齢年金の繰上げをすると、その日以後は事後重症などによる障害年金を請求できなくなります。

このページは、65歳前後の「時計」を1本にして見せるためのものです。調子が悪くて長く読めない日は、「65歳前後の時計」の表と、「1年前からの順番」だけ読んでください。

## 65歳前後の時計

| 時期 | できること・期限 |
|---|---|
| 60〜65歳 | 年金制度に加入していない期間の初診日でも、日本国内に住んでいれば障害基礎年金を請求できる特例あり(納付要件は必要) |
| 65歳の誕生日の**前々日**まで | **事後重症請求の期限**。いまの状態で請求する方法は、ここで閉じる |
| 65歳に達する日の前日まで | 「はじめて2級」(先の障害と新たな障害を合わせて初めて2級に該当した場合の請求)の期限 |
| 老齢年金を繰上げした日 | その日以後、事後重症などによる障害年金は請求できなくなる。**繰上げの前に、障害年金の可能性を確認する** |
| 65歳以降 | 厚生年金に加入中の初診日なら、障害認定日による請求は引き続き可能 |
| 65歳到達時 | 老齢年金の受給権ができる。自動では切り替わらず、「年金受給選択申出書」で組み合わせを選ぶ |

## 数字で見る、65歳の選択

| 何の数字か | 数字(令和8年度) |
|---|---|
| 障害基礎年金 2級 | 年 {{basicGrade2}}円。老齢基礎年金の満額と同じ額 |
| 障害基礎年金 1級 | 年 {{basicGrade1}}円(2級の1.25倍) |
| 老齢基礎年金 | 満額から、未納・免除の期間に応じて減る。全額免除の期間は、納付した期間の2分の1で計算(平成21年4月以降) |
| 障害年金の税 | 非課税。老齢年金は雑所得として課税 |
| 事後重症請求の期限 | 65歳の誕生日の前々日 |
| 3級の失権 | 3級にも該当しない状態が3年続き、かつ65歳に達したとき |

同じ「基礎年金」でも、障害基礎年金は等級ごとの定額で、老齢基礎年金は納付の記録で決まります。免除の期間が長かった人ほど、この差は大きくなります。だから、どちらが多いかは人によって違い、試算が要ります。

→ 障害年金の金額(/dougu/kingaku)

## 65歳からの組み合わせ
公的年金は「1人1年金」が原則ですが、65歳以降は例外として、支給目的の異なる年金の組み合わせが一部認められています。

| 組み合わせ | 65歳から |
|---|---|
| 障害基礎年金 + 老齢厚生年金 | 受けられる |
| 障害基礎年金 + 遺族厚生年金 | 受けられる |
| 障害厚生年金 + 老齢厚生年金 | 受けられない(どちらかを選ぶ) |
| 障害厚生年金3級 と 老齢年金 | 受けられない(どちらかを選ぶ。3級には障害基礎年金が無いため) |
| 老齢基礎年金 + 障害厚生年金 | 受けられない |

つまり、障害年金を受けると老齢年金と縁がなくなる、わけではありません。どの組み合わせが有利かは納付記録によって人それぞれなので、65歳が近づいたら年金事務所で試算してもらうのが確実です。選択はあとから変更もできます。

## 受給中の人が65歳で選ぶこと — 手取りで比べる

障害年金を受けている人が65歳になると、老齢年金の受給権が生まれます。自動では切り替わりません。「年金受給選択申出書」で組み合わせを選びます。選ぶときの物差しは2つです。

1. **額**: 障害基礎年金(1級 {{basicGrade1}}円・2級 {{basicGrade2}}円、令和8年度)と、老齢基礎年金(納付記録で決まる)のどちらが多いか。老齢厚生年金は、障害基礎年金と併せて受けられます
2. **税**: 障害年金は非課税(国民年金法25条・厚生年金保険法41条2項)、老齢年金は雑所得として課税されます。額が同じなら、非課税の側が手取りで多くなります。住民税・国民健康保険料・介護保険料も、所得を基準に決まるものがあります

年金事務所では、組み合わせごとの見込額を出してもらえます。予約のときに「障害と老齢の組み合わせで、どれが有利か知りたい」と伝えます。選択は後から変更できます。

## 3級の人の「65歳の壁」— 戻せない線が1本だけある

障害厚生年金3級の人、または更新で3級にも該当しないと判断された人に、1本だけ戻せない線があります。**3級にも該当しない状態が3年続き、かつ65歳に達すると、障害年金の受給権は失われ、以後は復活できません**(国民年金法・厚生年金保険法の失権の規定)。

- 65歳になる前に状態が悪化しているなら、支給停止事由消滅届で再開を求めておきます。→ 支給停止からの復活(/columns/shikyuu-teishi-fukkatsu)
- 3級で受けている人は、更新の診断書で実態が伝わるよう、記録を続けます。→ 更新の仕組みと備え(/columns/koushin-kakuninhodo)
- 3級の障害厚生年金を受けている人(過去に同じ支給事由の障害基礎年金の受給権を持っていた人を除く)は、65歳以上になると額改定請求ができません

## 65歳以降の更新と、働くこと

- 更新(障害状態確認届)は、有期認定なら65歳以降も続きます。年齢で自動的に打ち切られる制度ではありません
- 65歳以降も、厚生年金に加入して働いている間に初診日がある傷病なら、障害認定日による請求ができます
- 働いている人が65歳で老齢厚生年金を受け始めると、給与との調整(在職老齢年金)が老齢厚生年金にかかることがあります。障害年金には給与による調整はありません
- 20歳前傷病の所得制限は65歳以降も続きます(前年所得で10月分から翌年9月分)

## 結論を分けた実例

**事後重症の支給は、請求した月の翌月分から(維持)**
統合失調症の方が、事後重症で決まった障害基礎年金について、制度の施行時までさかのぼった支給を求めた事例です。審査会は、事後重症による支給の開始は請求月の翌月であり、さかのぼって支給することはできないとして退けました。事後重症請求は「請求した日」から先にしか動きません。65歳の前々日という期限が重いのは、このためです。→ [この事案](/jitsurei?case=h30_r01-16_02)

**繰上げの前に確認すべき理由**
繰上げ後の障害年金を争った公開裁決は、当サイトの事例集にはありません。だからこそ、繰上げの前に年金事務所で確認する、が唯一の防ぎ方です。

→ 実例を読む(/jitsurei)

## 65歳が近い人の、1年前からの順番

| 時期 | やること |
|---|---|
| 1年前 | 年金証書で「次回診断書提出年月」と等級を確認する |
| 繰上げを考えたとき | **先に**障害年金の可能性を年金事務所で確認する(繰上げ後は事後重症などの請求ができなくなる) |
| 65歳の誕生日の前々日まで | 事後重症請求・「はじめて2級」を出す |
| 65歳になる年 | 組み合わせごとの見込額を試算してもらい、年金受給選択申出書を出す |
| 65歳以降 | 更新の周期と記録は続ける |

## 同じ道を歩いた人が、つまずいたところ

### 繰上げを先に決めてしまう
60代前半で収入が減り、老齢年金の繰上げを検討する人は多い。でも持病があって将来悪化の可能性があるなら、繰上げは障害年金という選択肢を失う決断です。順番は、先に障害年金の可能性を確認してから。

### 「高齢で発症したから対象外」と思う
見られるのは年齢ではなく、初診日にどの制度に加入していたかです。65歳以降も働いていて厚生年金に入っているなら、その間の初診日は障害厚生年金の対象です。

### 遺族厚生年金が丸ごと上乗せされると思っている
配偶者が亡くなった場合、65歳までは障害年金と遺族厚生年金はどちらかの選択です。65歳以降は「障害基礎年金+遺族厚生年金」の組み合わせが可能になります。想定より少なく感じることがあるので、世帯の設計は試算してから。

### 法定免除のまま放置する
障害基礎年金1・2級を受けている間、国民年金保険料は法律上免除されます。ただし免除期間は将来の老齢基礎年金が全額納付より少なく計算されます。納付を続けることも、あとから追納することもできます。65歳以降の生活をどう組むかで選ぶ話です。

## よくある質問
**Q. 障害基礎年金は、未納が多いと減りますか。**
減りません。老齢基礎年金は納付実績で額が変わりますが、障害基礎年金は等級ごとの定額です。納付要件さえ満たしていれば、免除・猶予の期間が多くても受け取る額は同じです。

**Q. 65歳を過ぎても更新はありますか。**
有期認定なら続きます。年齢を理由に自動で打ち切られる制度ではありません。

**Q. もう繰上げをしてしまいました。障害年金は一切だめですか。**
繰上げは取り消せません。繰上げの日以後は、事後重症や「はじめて2級」による請求ができなくなります。ただし、障害認定日が繰上げより前にあり、その時点で等級に該当していたなら、障害認定日による請求(さかのぼる請求)はできます。年金事務所で、認定日請求の形で出せるかを確認してください。

**Q. 障害年金が止まったままです。65歳から老齢年金はもらえますか。**
もらえます。障害年金の支給停止と、老齢年金の受給権は別です。65歳になれば、納付記録に応じた老齢年金の権利ができます。

**Q. 65歳以降、働いていると障害年金は減りますか。**
減りません。給与による調整(在職老齢年金)がかかるのは老齢厚生年金です。障害年金にはありません。20歳前傷病の所得制限だけは、65歳以降も続きます。

**Q. 3級で受けています。65歳を過ぎて悪化したら、2級にできますか。**
65歳以上になると、3級の障害厚生年金を受けている人(過去に同じ支給事由の障害基礎年金の受給権を持っていた人を除く)は額改定請求ができません。悪化が見えているなら、65歳になる前に額改定請求を出しておく。これが、この年代の「戻せない線」の1つです。

## 次の一歩
65歳が近いなら、いちばん先にやることは、年金事務所での試算の予約です。「障害年金と老齢年金の組み合わせで、どれが有利か知りたい」と伝えれば通じます。繰上げを考えている方は、その前に。
